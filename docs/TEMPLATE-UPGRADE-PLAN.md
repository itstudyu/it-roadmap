# 템플릿 개선 계획 — "읽으면 이해 100%"

2026-08-16, `template-upgrade` 브랜치. **계획만 있고 아직 아무것도 고치지 않았다.**

어떻게 만든 계획인가: 검수 에이전트 5명(학습과학 / 초보자 통독 2 / 도해 문법 / 도해 품질)이
템플릿과 실제 노트 40여 편을 읽고 28건을 제기했고, 회의론자 3명(학습 효과 / 구현 비용 / 설계
정체성)이 전건을 반대 심문해 **24건이 생존**했다. 아래는 생존안을 작업 단위로 묶은 것이다.
증거 숫자는 전부 실측(grep · 코드 인용 · 블라인드 테스트)이고 심문에서 재검증됐다.

## 핵심 발견 다섯 (전체를 관통하는 것)

1. **확인 질문이 회상 연습의 절반만 한다.** 질문 681개 전부에 답 확인 경로가 없다.
   템플릿 예시(156행)에는 `→ 층 도해` 포인터가 있는데 실제 노트에서는 0개다.
   답이 접힌 패널 안에 있는 경우가 많아, 유저는 틀린 자기 답을 굳히거나 질문을 건너뛴다.
2. **`<` 표기 하나가 네 가지 뜻으로 쓰인다.** 흐름 221블록 중 212블록이 `<` 를 쓰는데
   응답 · 루프 재시작 · 루프 탈출 · 병렬 구독자로 갈라졌고, 렌더러는 그 위에 무조건
   "여기서부터 돌아오는 길"을 새긴다 — 아무것도 안 돌아오는 자리에 거짓 문장이 그려진다.
3. **순환을 그릴 표기가 없다.** IT 개념의 큰 갈래 하나가 "한 바퀴 돈다"인데(이벤트 루프,
   에이전트 루프, Circuit Breaker, Scrum) 흐름은 직선뿐이다. 42블록이 루프를 직선으로 편다.
4. **대조의 강제 ✕/✓ 가 트레이드오프에서 틀린 판정을 찍는다.** 세션 vs JWT 같은 대등한
   비교에서 왼쪽이 자동으로 ✕ 를 받아, 같은 노트의 🚫 흔한 오해가 지우려는 오해를
   그림이 2초 만에 심는다.
5. **본문 `[[링크]]` 가 죽어 있다.** ui.js 가 `[[Hallucination]]` 을 이탤릭으로 강등시킨다.
   선행 용어에 막힌 독자를 구할 유일한 장치가 화면 맨 아래 🔗 관련 용어뿐이다.

## 1묶음 — 도해 문법: 표기 둘 추가, `<` 오용 정리

바뀌는 곳: `tools/build.py` `js/ui.js` `css/app.css` `tools/check_template.py` `docs/TERM-TEMPLATE.md`

| 항목 | 내용 |
|---|---|
| `@` 반복 표기 [17] | 흐름 마지막 줄 전용 접두. `@ 다시 1로 :: 목표에 닿을 때까지`. 렌더는 기존 `.dia__turn` 디바이더 재사용 + 회전 표시 — 세로 한 폭에 줄 하나 추가라 390px 무해, Obsidian 평문으로도 읽힌다. 명백한 순환 17블록이 즉시 혜택. |
| `\|=\|` 중립 대조 [23] | 칸 이름 줄이 `세션 방식 \|=\| JWT 방식` 이면 ✕/✓ 없이 동색 렌더. diaCompare 분기 몇 줄. "있고 없고"는 기존 `\|\|` 유지. |
| `<` 전수 감사 [18] | 212블록을 감사해 셋으로 처방: 진짜 응답 → 유지, 루프 재시작 → `@`, 탈출·병렬 → `<` 제거(일반 마디). 1차 대상은 반복 언어가 있는 42블록(스크립트로 추림). |
| `+` 병렬 표기 | **도입 안 함** — 심문 3명 전원 기각. 병렬 구독자는 마디 하나로 묶는 게 정답 [20]: `구독자들 :: 재고·배송·알림이 같은 소식을 저마다 받는다. 순서도 없고 서로 모른다`. 대상은 Pub-Sub · Event-Driven · Message Queue 3편뿐. |

## 6묶음 — 템플릿 문서 규칙 추가 (`docs/TERM-TEMPLATE.md` 만)

- **그림 자리 개방** [11][26]: 모양-섹션 표에서 🖼️ 자리에 세 모양 모두 허용. 규칙:
  "그림 자리에는 개념의 형태를 담는다. 개념을 고르는/확인하는 절차는 개념이 아니다 —
  작동 원리로 보낸다. 판정법: 그림만 보고 정의 첫 문장이 복원되는가." 현재 그림 자리는
  흐름 217 / 층 10 / 대조 0 의 단일문화인데, 규칙을 어기고 층을 쓴 10편이 오히려 제일 좋다.
- **층 반증 테스트** [7][24]: "이웃한 두 층을 맞바꿔도 그림이 안 틀리면 층이 아니다.
  `=` 줄이 집합어로 시작하면 목록이다." + "상태 전이는 층이 아니라 흐름(`@`)으로" [19].
- **이름 해부** [2]: 정의 규칙에 조건부 한 줄 — 이름이 곧 구조인 경우(RAG = 검색으로-보강한-생성
  = 파이프라인 순서)만 이름을 쪼개 풀어준다. 체크리스트에 사람용 항목 추가. 기계 검사는
  기각됨(한국어 본문에 영단어가 원래 안 나와 모범 예까지 오탐 — 실측 57편 걸림).
- **과잉 적용 오해** [5]: "대안이 있는 기술형 단어는 오해 중 하나로 과잉 적용(X 가 항상 낫다 꼴)을
  겨눈다." 이미 다수 노트의 관행이라 소급 비용 낮음.
- **규모 앵커** [13]: 체크리스트 한 줄 — "빠르다/느리다가 핵심 주장이면 어림수 앵커 하나(초·배·회).
  절대치보다 부패하지 않는 비율(배) 우선." 숫자 1개 이하 노트가 86/227편(38%).
- **✕ 칸 자기검사** [23]: "✕ 를 받는 왼쪽 칸에 장점이 한 줄이라도 있으면 그 대조가 아니다 —
  중립 표식 `|=|` 을 쓰거나 그 줄을 ✅ 장단점으로 옮긴다."

## 8묶음 — 대규모 스윕 (규모가 커서 분리, 별도 진행 판단)
