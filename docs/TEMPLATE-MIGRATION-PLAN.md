## 절대 어기면 안 되는 것

1. **H1 제목을 바꾸지 않는다.** 단어 id 가 `{권}--{제목slug}` 이고 그게 학습 기록의 열쇠다.
   제목을 손대면 그 사람의 진도가 사라진다. 파일 이동·개명도 같은 이유로 금지.
2. **폴더를 옮기지 않는다.** 권이 바뀌면 id 가 바뀐다.
3. 검증에서 **이행 전후 id 목록을 대조**한다. 하나라도 달라지면 실패로 본다.
4. 원본 Markdown 의 형식을 임의로 파괴하지 않는다. 도해는 Obsidian 평문으로도 읽혀야 한다.

## 5단계 — 콘텐츠 판단 (병렬 12~15 · 가장 큰 덩어리)

권 하나에 에이전트 하나. **폴더가 서로 겹치지 않아 파일 충돌이 없다.**
보안(34)·네트워크(30)·AI(27) 는 둘로 쪼개 15개까지 늘린다.

각 에이전트가 자기 권의 노트마다 여섯 가지를 본다:

1. **확인 질문 3개에 `→ 답 위치`** — 답이 실제로 있는 섹션을 짚는다.
   답이 노트 안에 없으면 **그게 이번 이행의 진짜 수확이다.** 질문을 바꾸거나 내용을 채우고
   무엇을 고쳤는지 기록한다. (687개 전체가 대상)
2. **흐름의 `<` 감사** — 진짜 응답만 남긴다. 순환이면 `@`, 탈출·병렬이면 `<` 를 뗀다.
   (214블록 중 반복 언어 포함 60블록이 1차 후보)
3. **대조 감사** — 두 선택이 다 정당하면 `\|=\|`. 판정 기준: **✕ 를 받는 왼쪽 칸에
   장점이 한 줄이라도 있으면 그 대조가 아니다.**
4. **그림 자리 감사** — "개념을 고르는 절차" 가 대표 그림이면 개념의 형태로 바꾼다.
   판정법: 그림만 보고 정의 첫 문장이 복원되는가. (지금 그림 자리는 흐름 219 / 층 10 / 대조 0)
5. **층 반증 테스트** — 이웃한 두 층을 맞바꿔도 안 틀리면 층이 아니다.
   대조로 바꾸거나 본문 불릿으로 되돌린다.
6. **선행 용어** — 도해 마디가 노트 밖 용어를 전제하면 반 구절로 풀거나 `[[링크]]` + 관련 용어 등재.

**에이전트 규칙 (프롬프트에 못 박는다)**
- H1·파일명·폴더를 건드리지 않는다.
- 편마다 `python3 tools/check_template.py <파일>` 을 돌려 통과를 확인하고 넘어간다.
- 고칠 게 없으면 고치지 않는다. 억지로 `@` 나 `\|=\|` 를 넣지 않는다.
- 자기 권의 결과를 `logs/migration-<권>.md` 에 남긴다 — 무엇을 왜 바꿨는지, 답이 없던 질문 목록.

## 순서와 병렬 요약

```
0. 루틴 처리 [사용자]        ─ 00:00 KST 전에 결정
1. worktree 만들기 [직렬]    ─ 5분
2. 문법 구현 [병렬 4]        ─ ui.js / build.py / check_template.py / screens.js+app.css
   └ 합류: 목업 열림 + 전수 검사 통과
3. 본보기 2편 + 문서 [직렬]  ─ DNS·HTTP → TERM-TEMPLATE → ROUTINE-PROMPT → mockups 정리
4. 실제 사례 대시 [직렬]     ─ 스크립트 1회, 226편
5. 콘텐츠 판단 [병렬 12~15]  ─ 권별 1 에이전트, 폴더가 겹치지 않음
   └ 합류: 전수 검사 + id 대조
6. 검증·커밋·병합 [직렬]
```

병렬이 되는 자리는 2단계(파일 분리)와 5단계(폴더 분리) 둘이고,
그 둘이 전체 시간의 대부분이다. 3·4단계는 짧고 앞뒤 의존이 있어 직렬로 둔다.

- 단어 추가·삭제·이동. 이번 이행은 **형식만** 바꾼다.
