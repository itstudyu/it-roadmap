# Linux (리눅스)

## 📝 정의

Linux는 **누구나 뜯어보고 고칠 수 있는 운영체제**다.

소스가 공개돼 있어서 누구든 가져다 자기 쓰임에 맞게 조립할 수 있다. 그래서 Ubuntu, Debian, CentOS처럼 같은 뿌리에서 갈라진 배포판이 여럿 나와 있고, 서버와 개발 환경에서 널리 쓰인다.

### 비유
설계도가 공개된 자동차. 뼈대는 같지만 만드는 곳마다 다르게 꾸며 내놓아서 차종이 여럿이다.

### 예
공유기 설정을 만지거나 회사 서버에 붙었을 때 뜨는 검은 바탕에 흰 글자 화면이 대개 이것이다.

## 🖼️ 그림으로 보기

```도해
층: 배포판마다 무엇이 다른가
기본 구성 :: 무엇을 미리 깔아두었나. 가장 많이 갈린다
패키지 관리 :: `apt` 냐 `yum` 이냐. 명령이 다르다
기본 도구 :: 셸과 명령어 묶음. 대체로 비슷하다
커널 :: 리눅스 그 자체. 어느 배포판이든 같다
= 배포판이 다르다는 건 커널이 다른 게 아니라 포장이 다른 것이다
```

## ⚠️ 해결하는 문제

```도해
대조: 서버 운영체제를 사서 쓰면 어떻게 되나
사서 쓰는 쪽 || 리눅스로
대수 늘리기 :: 대당 값을 낸다 || 값이 안 붙는다
고치기 :: 만든 곳에 요청 || 직접 고친다
구성 :: 주는 대로 쓴다 || 덜어내고 쓴다
= 서버를 수십 대씩 늘리는 쪽에서 차이가 커진다
```

서버는 한 대로 끝나지 않는다. 부하가 늘면 열 대, 백 대로 늘리는데 운영체제 값이 대당 붙으면 그만큼 그대로 쌓인다.

리눅스는 그 값이 붙지 않고, 필요 없는 것을 덜어낸 채로 만들 수 있다. 화면 없이 명령만으로 다룰 수 있어서 원격으로 붙어 관리하기에도 맞는다.

## ⚙️ 작동 원리

Ubuntu는 설치와 문서가 갖춰져 있어 처음 쓰기에 무난하고, Debian은 바뀌는 속도가 느린 대신 안정적이다. CentOS 계열은 기업 서버에서 오래 쓰였고, Arch는 필요한 것만 직접 골라 쌓는 쪽이다.

포장이 달라도 안쪽에서 벌어지는 일은 같다.

```도해
흐름: 터미널에 명령을 치면 무슨 일이 일어나나
사용자 :: `ls` 를 입력한다
셸 :: 입력을 해석하고 실행할 것을 찾는다
커널 :: 프로그램 대신 디스크와 메모리를 다룬다
하드웨어 :: 실제로 읽어온다
< 셸 :: 결과를 화면에 되돌려준다
= 사람은 셸에 말하고, 하드웨어를 실제로 만지는 건 커널이다
```

그래서 명령도 배포판이 달라도 대체로 통한다.

```bash
ls          # 목록 보기
cd          # 폴더 이동
mkdir       # 폴더 만들기
top         # 지금 돌고 있는 프로세스
sudo apt    # 관리자 권한으로 패키지 관리 (Ubuntu 계열)
```

## 📊 비교

| 항목 | Linux | Windows |
|---|---|---|
| 비용 | 라이선스 값이 없다 | 값을 낸다 |
| 주로 쓰는 곳 | 서버, 개발 환경 | 개인 컴퓨터 |
| 명령줄 | 여기서 거의 다 한다 | 화면 조작이 중심 |
| 구성 바꾸기 | 필요한 것만 골라 쌓는다 | 정해진 범위 안에서 |

## 💡 실제 사례

- **원격 서버 관리** — 화면 없이 명령만으로 다룰 수 있어서 접속해서 관리하는 서버에 얹는다.
- **개발 환경 맞추기** — 배포되는 서버가 리눅스면 개발도 같은 환경에서 하는 편이 낫다. 컨테이너 안도 대개 리눅스다.
- **오래된 기기 되살리기** — 필요한 것만 골라 깔 수 있어서 사양이 낮은 컴퓨터에도 올린다.

## 🚫 흔한 오해

- **리눅스는 운영체제 이름이다** — 정확히는 커널 이름이다. 그 위에 도구와 설정을 얹어 묶은 배포판이 실제로 우리가 설치하는 것이다.
- **리눅스는 검은 화면에서 명령만 치는 것이다** — 그래픽 화면을 갖춘 배포판도 많다. 서버에서 화면을 안 쓰는 것뿐이다.
- **무료니까 돈이 안 든다** — 라이선스 값이 없는 것이지 쓰는 비용까지 없는 건 아니다. 다룰 줄 아는 사람이 있어야 하고, 문제가 나면 직접 해결해야 한다.

## 🚨 주의사항

- **`rm` 은 되돌릴 수 없다.** 휴지통을 거치지 않고 바로 지운다. 특히 `sudo` 를 붙이면 막아주는 것이 없다.
- **`sudo` 를 습관처럼 붙이지 않는다.** 관리자 권한으로 실행하면 실수도 그만큼 크게 번진다.

## 📝 정리

리눅스는 소스가 공개된 커널이고, 그 위에 도구를 얹어 묶은 것이 배포판이다. 라이선스 값이 붙지 않고 필요 없는 것을 덜어낼 수 있어서 서버를 여러 대 굴리는 쪽에서 자리를 잡았다. 배포판이 달라도 커널과 기본 명령은 같아서 하나를 익히면 대체로 통한다.
