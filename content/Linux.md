# Linux (리눅스)

## 📝 정의
Linux는 **오픈소스 운영체제**입니다. 서버와 개발 환경에서 널리 사용됩니다.

### 핵심 특징
- 오픈소스: 무료
- 안정성: 서버에 적합
- 커스터마이징: 자유로운 수정

## 💡 주요 배포판

- **Ubuntu**: 가장 인기
- **CentOS**: 서버용
- **Debian**: 안정적
- **Arch**: 고급 사용자용

## 🎯 기본 명령어

```bash
# 파일/디렉토리
ls        # 목록
cd        # 이동
mkdir     # 폴더 생성
rm        # 삭제

# 시스템
sudo      # 관리자 권한
apt       # 패키지 관리 (Ubuntu)
top       # 프로세스 확인
```

## 📊 Linux vs Windows

| 특성 | Linux | Windows |
|------|-------|---------|
| 비용 | 무료 | 유료 |
| 사용 | 서버, 개발 | 일반 사용자 |
| CLI | 강력 | 약함 |
