# Object (객체)

## 📝 정의

Object는 **데이터와 그 데이터를 다루는 기능을 한 덩어리로 묶은 것**이다.

자동차 정보를 브랜드, 모델, 연식 변수로 흩어 두면 자동차가 늘어날 때마다 변수도 함께 늘어난다. 객체로 묶으면 자동차 하나가 값 하나가 되고, 속도를 바꾸는 일도 그 안의 기능이 맡는다.

### 비유
붕어빵과 붕어빵 틀. 틀이 클래스이고 그 틀로 구워낸 빵 하나하나가 객체다. 하나를 베어 먹어도 다른 빵은 그대로다.

## 🖼️ 그림으로 보기

```도해
흐름: car = Car("Tesla") 를 실행하면 무슨 일이 일어나나
클래스 :: 어떤 값과 기능을 가질지 적어둔 설계도
생성 :: 메모리에 새 자리를 하나 잡는다
초기화 :: 넘긴 값으로 그 자리를 채운다
객체 :: 값과 기능을 가진 실체가 하나 생긴다
< 변수 car :: 그 자리를 가리키게 된다
= 설계도는 하나지만 그걸로 만든 실체는 얼마든지 생긴다
```

## ⚠️ 해결하는 문제

```도해
대조: 자동차 정보를 코드로 다루면 어떻게 되나
변수로 흩으면 || 객체로 묶으면
자동차 두 대 :: 변수 여덟 개 || 객체 두 개
기능 호출 :: 값을 매번 넘긴다 || car.drive()
관계 :: 이름 규칙에만 있다 || 구조에 있다
= 흩어진 값과 그 값을 다루는 기능을 한자리에 두는 것이다
```

값을 변수로 흩어 두면 어느 변수와 어느 변수가 한 짝인지는 이름 규칙에만 남는다. `car1_brand`와 `car1_model`이 같은 자동차라는 것은 코드가 아니라 사람이 아는 사실이다.

기능도 마찬가지다. 자동차를 움직이는 함수는 브랜드, 모델, 속도를 매번 인자로 받아야 한다. 객체는 값과 기능을 같은 자리에 두어서 이 전달을 없앤다.

## ⚙️ 작동 원리

클래스는 설계도라서 코드에만 있고, 객체는 실행할 때 메모리에 자리를 잡는다. 그래서 클래스는 하나여도 객체는 여러 개가 생기고 서로 영향을 주지 않는다.

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

car1 = Car("Tesla")
car2 = Car("BMW")

car1.brand = "Audi"
print(car2.brand)   # BMW. car1 을 바꿔도 그대로다
```

변수에 담기는 것은 객체 자체가 아니라 그 자리를 가리키는 표시다. 이 성질에서 실수가 자주 나온다. 다른 변수에 대입하면 새 객체가 생기는 것이 아니라 같은 자리를 함께 가리키게 된다.

## 💡 실제 사례

- **장바구니** — 담긴 상품 목록과 총액 계산을 한 객체에 두면, 담기와 빼기와 합계가 모두 그 안에서 끝난다.
- **게임 캐릭터** — 체력과 공격력이 값이고 공격과 회복이 기능이다. 캐릭터가 몇이든 같은 설계도로 만든다.
- **화면 요소** — 버튼 하나가 객체다. 표시할 글자를 갖고 있고 눌렸을 때 할 일도 자기가 안다.

## 🚫 흔한 오해

- **객체와 클래스는 같은 말이다** — 다르다. 클래스는 코드에 적힌 설계도이고 객체는 실행 중에 메모리에 생긴 실체다. 클래스 하나로 객체를 몇 개든 만든다.
- **객체를 다른 변수에 넣으면 복사된다** — 복사되지 않는다. 같은 자리를 함께 가리키게 되므로 한쪽에서 내용을 바꾸면 다른 쪽에서도 바뀌어 보인다.
- **값이 같으면 같은 객체다** — 기본 비교는 같은 자리를 가리키는지를 본다. 값이 같아도 따로 만든 객체는 다르다고 나오고, 값으로 비교하려면 비교 방법을 직접 정해줘야 한다.

## 🚨 주의사항

- **기본값에 목록을 넣지 않는다.** 그 목록이 객체마다 새로 생기지 않고 하나를 함께 쓰게 되는 언어가 있다.
- **참조가 서로를 가리키게 두지 않는다.** 두 객체가 서로를 붙잡고 있으면 정리 시점이 늦어지거나 순회 코드가 무한히 돈다.

## 📝 정리

Object는 값과 그 값을 다루는 기능을 한 덩어리로 묶은 실체다. 클래스는 설계도고 객체는 실행 중에 생긴 것이며, 변수에 담기는 것은 객체 자체가 아니라 그 자리를 가리키는 표시다.

## ❓ 이해했는지

- 같은 클래스로 만든 객체 하나를 고쳤는데 다른 객체는 왜 그대로인가?
- `b = a` 로 넘긴 뒤 `b` 의 내용을 바꿨더니 `a` 도 바뀌었다면 무슨 일이 일어난 것인가?
- 좌표가 똑같은 두 점 객체를 비교했는데 다르다고 나오는 이유는?

## 🔗 관련 용어

- [[Class]] — 객체를 만들어내는 설계도
- [[Variable]] — 객체가 있는 자리를 가리키는 이름
- [[Function]] — 객체 안에 들어가면 메서드가 된다
- [[Dictionary]] — 값만 묶는 쪽. 객체는 여기에 기능까지 넣는다
- [[Memory]] — 객체가 실제로 자리를 잡는 곳
