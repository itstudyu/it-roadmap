# Function (함수)

## 📝 정의

Function은 **이름을 붙여 다시 부를 수 있게 묶어둔 코드**다.

같은 코드를 여러 곳에 복사해두면 형식을 한 번 바꿀 때 복사본을 전부 찾아 고쳐야 한다. 함수는 그 코드를 한 자리에 두고, 필요한 곳에서는 이름만 부른다.

### 비유
요리 레시피. 재료를 넣으면 정해진 과정을 거쳐 같은 요리가 나온다.

## 🖼️ 그림으로 보기

```도해
흐름: `greet("Alice")` 라고 쓰면 무슨 일이 일어나나
호출 :: 함수 이름과 값을 적어 부른다
전달 :: "Alice" 가 파라미터 name 에 담긴다
본문 :: name 을 써서 정해진 일을 한다
반환 :: `return` 이 결과를 부른 자리로 보낸다
< 호출한 곳 :: 그 자리에 결과값이 놓인다
= 값을 넣고 결과를 받는다. 안에서 무슨 일이 있었는지는 몰라도 된다
```

## ⚠️ 해결하는 문제

```도해
대조: 같은 코드를 여러 곳에 복사해두면 어떻게 되나
함수 없이 || 함수로
형식 변경 :: 전부 찾아 고침 || 한 곳만 고침
공식 실수 :: 복사본마다 다름 || 한 번에 고쳐짐
읽기 :: 코드를 다 봐야 || 이름으로 안다
= 같은 일을 한 자리에 모으면 고칠 자리도 한 곳이 된다
```

인사말을 찍는 네 줄을 사용자마다 복사해두면, 인사 형식을 바꾸려는 순간 복사본을 전부 찾아야 한다. 하나를 빠뜨리면 어떤 사용자만 옛 형식으로 인사받는다.

계산식은 더 나쁘다. 원의 넓이를 세 군데에서 각각 적어두면 공식을 잘못 적은 자리가 어디인지 찾을 때까지 결과가 조용히 틀린다. 함수는 그 식을 한 곳으로 모아 고칠 자리를 하나로 만든다.

## ⚙️ 작동 원리

```python
def circle_area(radius):          # 이름과 파라미터
    PI = 3.14159
    return PI * radius * radius   # 결과를 밖으로 보낸다

area = circle_area(5)             # 호출한 자리에 결과가 놓인다
```

`radius` 는 값을 받을 자리고, 부를 때 넣는 `5` 가 실제 값이다. 기본값을 정해두면 그 자리를 비우고 부를 수도 있다.

```도해
층: 함수 안에서 만든 값은 어디까지 살아 있나
지역 :: 함수 안에서만. 끝나면 사라진다
반환값 :: return 으로 건넨 것만 밖에 남는다
전역 :: 파일 전체에서 보인다. 아무나 고칠 수 있다
= 밖으로 나가는 길을 return 하나로 좁혀두는 편이 안전하다
```

## 📊 비교: 함수 vs 메서드

| | 함수 | 메서드 |
|---|---|---|
| 있는 곳 | 독립적으로 | 클래스 안에 |
| 부르는 법 | `greet()` | `user.greet()` |
| 자기 자신 | 없다 | `self` 로 받는다 |
| 예 | `len()` | `list.append()` |

## 💡 실제 사례

- **입력 검증** 이메일 형식을 보는 함수를 하나 두고 회원가입, 주문, 문의에서 같이 부른다.
- **단위 변환** 섭씨를 화씨로 바꾸는 식을 함수에 넣어두면 식이 틀려도 고칠 곳은 한 군데다.
- **함수를 인자로 넘기기** 목록에 무엇을 적용할지 함수로 넘겨서 같은 반복문을 여러 용도로 쓴다.

## 🚫 흔한 오해

- **함수는 반드시 값을 돌려줘야 한다** — 화면에 찍기만 하고 끝나는 함수도 있다. `return` 이 없으면 비어 있다는 값이 돌아올 뿐이다.
- **함수 안에서 바깥 변수를 바꿔도 된다** — 그 함수만 봐서는 무엇이 바뀌는지 알 수 없게 된다. 고장 원인을 찾기 어려워지는 흔한 이유다.
- **리스트를 넘겨도 원본은 안전하다** — 숫자나 문자열과 달리 리스트는 함수 안에서 고치면 밖의 것도 같이 바뀐다.

## 🚨 주의사항

- **한 함수는 한 가지 일만 한다.** 저장하고 메일 보내고 로그까지 남기는 함수는 그중 하나만 쓰고 싶을 때 방법이 없다.
- **함수가 한 화면을 넘어가면 나눌 때가 된 것이다.** 이름을 지으려는데 "그리고"가 들어가면 이미 두 가지 일을 하고 있다.

## 📝 정리

Function은 같은 일을 한 자리에 모아 이름을 붙인 코드 묶음이다. 값을 받아 처리하고 결과를 돌려주며, 부르는 쪽은 안에서 무슨 일이 일어나는지 몰라도 된다.
