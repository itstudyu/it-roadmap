# Scope (스코프)

## 📝 정의

Scope 는 **이름 하나가 그대로 통하는 글의 구역**이다.

Python 문서는 스코프를 "이름 묶음에 곧바로 닿을 수 있는 글의 구역" 이라고 적는다. 곧바로 닿는다는 말은 앞에 아무것도 안 붙이고 이름만 불러도 찾아진다는 뜻이다. MDN 은 같은 것을 다른 각도에서 말한다 — 구역은 겹겹이 쌓일 수 있고, 안쪽은 바깥쪽 이름에 닿지만 그 반대는 안 된다.

### 이름
scope :: 보이는 범위
= 망원경(telescope)의 뒤 절반과 같은 말이다. 이름 하나가 보이는 범위를 가리킨다

### 비유
교실 안에서만 통하는 별명처럼, 문을 나서면 같은 이름을 불러도 아무도 돌아보지 않는다.

### 예
함수 안에서 만든 이름을 바깥에서 불렀다가 그런 이름이 없다는 오류를 본 그 순간이다.

## 🖼️ 그림으로 보기

```도해
층: 이름 하나를 부르면 어디서부터 찾나
지금 이 블록 :: 여기서 만든 이름. 가장 가까워서 먼저 잡힌다
바깥 함수들 :: 나를 감싼 함수의 이름. 가까운 쪽부터 본다
파일 전체 :: 이 파일 어디서나 통하는 이름
언어가 준 이름 :: 아무도 안 만든, 처음부터 있던 이름
= 안에서 밖으로 차례로 찾고, 끝까지 없으면 그때 없는 이름이 된다
```

## ⚠️ 해결하는 문제

```도해
대조: 이름이 모두 한 구역에 있으면 무슨 일이 생기나
이름이 다 한 통 || 구역으로 나누면
같은 이름 :: 나중 것이 덮는다 || 따로따로 산다
이름 짓기 :: 겹칠까 봐 길어진다 || 짧게 지어도 된다
남의 이름 :: 어디서든 고친다 || 안쪽은 못 건드린다
= 이름이 통하는 범위를 좁혀 두면, 짧은 이름을 마음 놓고 다시 쓸 수 있다
```

이름이 전부 한 통에 들어 있으면, 어딘가에서 같은 이름을 한 번 더 쓰는 순간 앞의 것이 덮인다. 덮였다는 사실은 아무도 안 알려주고, 겹칠까 봐 이름은 점점 길고 조심스러워진다. 남이 만든 이름에 아무 데서나 값을 넣을 수 있다는 것도 같은 문제의 다른 얼굴이다.

구역을 나누면 이름이 통하는 범위가 그 구역 안으로 좁아진다. 옆 구역에서 같은 이름을 써도 서로 모르고, 안쪽에서 만든 이름은 바깥에서 아예 안 보인다. 그래서 세는 데만 쓰는 짧은 이름을 마음 놓고 여러 군데서 다시 쓸 수 있다.

## ⚙️ 작동 원리

구역은 글에 적힌 자리로 정해진다. Go 명세는 "Go 는 블록을 써서 어휘적으로 범위를 잡는다" 고 적고, 함수 안에서 선언한 이름의 범위가 그 선언이 끝난 자리에서 시작해 이름을 감싼 가장 안쪽 블록의 끝에서 끝난다고 규정한다. Python 문서도 같은 말을 한다 — 구역은 글로 정해지며, 함수의 바깥 구역은 그 함수가 적힌 파일이지 어디서 어떤 이름으로 불렸는지가 아니다.

찾는 순서는 안에서 밖이다. Python 문서는 실행 중 어느 순간에도 곧바로 닿는 구역이 서넛 겹쳐 있다고 적는다. 지금 있는 안쪽, 나를 감싼 함수들, 이 파일 전체, 그리고 언어가 미리 만들어 둔 이름들. 가까운 쪽부터 보고, 끝까지 없으면 그때 없는 이름이 된다.

값을 넣는 쪽에는 규칙이 하나 더 있다. Python 은 따로 밝히지 않는 한 대입이 언제나 가장 안쪽 구역으로 간다고 못 박는다. 바깥 이름을 고치려던 줄이 실은 안쪽에 새 이름을 만들고 있는 사고가 여기서 나온다.

## 💡 실제 사례

- **반복문의 임시 이름** — 세는 데만 쓰는 이름은 그 블록 안에서 끝난다. 옆 반복문에서 같은 이름을 다시 써도 서로 모른다.
- **이름 가리기** — 안쪽에서 바깥과 같은 이름을 만들면 그 구역 동안은 안쪽 것만 보인다. 편할 때도 있고, 바깥 것을 고치려다 새로 만드는 사고의 원인이기도 하다.
- **바깥으로 안 새게 묶기** — 파일 하나 안에서만 쓸 이름을 바깥에서 못 보게 두면, 다른 파일이 그 이름에 기대는 일 자체가 안 생긴다.

## 🚫 흔한 오해

- **어디서 불렀느냐에 따라 보이는 이름이 달라진다** — 아니다. Python 문서는 함수의 바깥 구역이 어디서 어떤 이름으로 불리든 그 함수가 적힌 파일이라고 못 박는다.
- **안쪽에서 바깥 이름에 값을 넣으면 바깥이 바뀐다** — 따로 밝히지 않으면 그 대입은 안쪽에 새 이름을 만든다. 바깥 것은 그대로 남고, 그때부터 그 구역에서는 안 보인다.
- **자주 쓰는 값은 넓은 구역에 둘수록 편하다** — 넓을수록 누가 언제 바꿨는지 뒤져야 할 자리도 넓어진다. 한 줄을 고치려고 확인할 범위가 파일 전체가 된다.

## 📝 정리

**"이 이름이 통하는 글의 구역"** 이라고 읽으면 된다. 구역은 부른 자리가 아니라 적힌 자리로 정해지고, 이름은 안에서 밖으로 차례로 찾다가 끝까지 없으면 없는 이름이 된다. 그래서 짧은 이름을 여러 군데서 다시 쓸 수 있고, 안쪽에서 같은 이름을 만들면 그동안 바깥 것은 가려진다.

## 🧒 열 살에게

너희 반에서만 통하는 별명이 있지? 옆 반에 가서 그 별명을 부르면 아무도 안 돌아봐. 그런데 학교 전체가 아는 이름은 어느 교실에서 불러도 통하지.

## ❓ 이해했는지

- 옆 반복문에서 같은 이름을 다시 써도 서로 안 부딪히는 까닭은 무엇인가 → 해결하는 문제
- 같은 함수를 다른 파일에서 불렀는데 보이는 이름이 안 바뀌는 까닭은 무엇인가 → 흔한 오해
- 이름을 하나 불렀을 때 그 이름을 어디서부터 어디까지 찾나 → 그림
