# Loop (반복문)

## 📝 정의

Loop 는 **같은 코드를 조건이 끝날 때까지 다시 실행하는 구조**다.

몇 번 도는지 미리 아는 경우와 돌아봐야 아는 경우가 있고, 그에 따라 `for` 와 `while` 로 갈린다.

### 비유
세탁기의 헹굼. 물이 맑아질 때까지 같은 동작을 되풀이하고, 조건이 맞으면 멈춘다.

## 🖼️ 그림으로 보기

```도해
흐름: 반복문은 한 바퀴마다 무엇을 하나
조건 확인 :: 더 돌 이유가 있는지 본다
본문 실행 :: 안쪽 코드를 한 번 돌린다
값 갱신 :: 카운터를 올리거나 다음 항목으로 간다
다시 위로 :: 조건을 또 확인한다
탈출 :: 조건이 거짓이거나 break 를 만나면 나온다
< 다음 줄 :: 반복문 아래로 이어진다
= 값이 갱신되지 않으면 조건이 영원히 참이라 빠져나오지 못한다
```

## ⚠️ 해결하는 문제

```도해
대조: 반복문이 없으면 같은 일을 어떻게 하나
붙여넣기로 || 반복문으로
100번 실행 :: 100줄을 쓴다 || 두 줄이면 된다
개수가 바뀌면 :: 코드를 고친다 || 그대로 돈다
실수 :: 한 줄만 틀린다 || 한 곳만 본다
= 몇 번 돌지 모를 때는 붙여넣기로는 아예 쓸 수 없다
```

같은 줄을 다섯 번 붙여넣는 것까지는 할 만하다. 문제는 항목이 몇 개인지 실행해봐야 아는 경우다. 목록의 길이가 매번 다르면 붙여넣기로는 코드를 쓸 방법이 없다.

반복문은 횟수를 코드가 아니라 데이터가 정하게 만든다. 목록이 3개든 3만 개든 같은 두 줄이 돌고, 고칠 곳도 한 군데뿐이다.

## ⚙️ 작동 원리

```도해
층: for 와 while 은 무엇이 다른가
for :: 돌 대상이 정해져 있을 때. 목록, 범위
while :: 언제 끝날지 조건으로만 알 때
break :: 도는 도중에 즉시 빠져나온다
continue :: 이번 바퀴만 건너뛰고 계속 돈다
= for 는 몇 번 도는지 알고 시작하고, while 은 돌아봐야 안다
```

`for` 는 목록이나 범위처럼 순회할 대상을 앞에 두고 시작한다. 항목을 다 돌면 알아서 끝나므로 종료를 따로 챙기지 않아도 된다.

`while` 은 조건이 참인 동안 돈다. 조건에 쓰인 값을 본문 안에서 바꾸지 않으면 영원히 돈다. 서버나 게임처럼 일부러 무한히 도는 경우도 있는데, 그때는 안에서 `break` 로 빠져나올 길을 둔다.

## 💡 실제 사례

- **목록 집계** — 주문 목록을 돌면서 금액을 더해 합계를 낸다.
- **서버 대기 루프** — 무한히 돌면서 들어오는 요청을 하나씩 받아 처리한다.
- **파일 처리** — 큰 파일을 한 줄씩 읽어 돌린다. 전부 메모리에 올리지 않아도 된다.

## 🚫 흔한 오해

- **반복문은 정해진 횟수만큼 돈다** — `while` 은 언제 끝날지 모른 채 돈다. 조건을 바꾸는 코드가 없으면 멈추지 않는다.
- **무한 루프는 항상 버그다** — 서버와 게임은 일부러 무한히 돈다. 안에서 빠져나올 길이 있느냐가 갈림이다.
- **반복문 안에서 목록을 지워도 된다** — 도는 도중에 길이가 바뀌면 건너뛰는 항목이 생긴다. 새 목록을 만들어 담는 편이 안전하다.

## 🚨 주의사항

- **`while` 을 쓸 때 조건을 바꾸는 줄이 있는지 먼저 확인한다.** 카운터를 올리는 줄 하나가 빠져서 멈추지 않는 경우가 가장 흔하다.
- **반복문을 겹치면 비용이 곱해진다.** 목록 두 개를 이중으로 돌면 항목이 10배 늘 때 100배 느려진다.
- **인덱스로 돌 때는 범위를 목록 길이에 맞춘다.** 고정된 숫자를 넣어두면 목록이 줄었을 때 범위를 넘어선다.

## 📝 정리

반복문은 같은 코드를 조건이 끝날 때까지 다시 실행하는 구조다. `for` 는 돌 대상이 정해져 있을 때, `while` 은 언제 끝날지 조건으로만 알 때 쓴다. 조건을 바꾸는 코드가 있는지가 멈추느냐 마느냐를 가른다.

## ❓ 이해했는지

- `while` 문이 멈추지 않는다. 어느 줄이 빠졌는지 어떻게 찾나?
- 짝수만 지우려고 반복문 안에서 목록을 지웠더니 일부가 남았다. 왜 그런가?
- 목록 두 개를 이중으로 도는 코드가 데이터가 늘자 갑자기 느려졌다. 왜 그런가?
