# Compile vs Interpret (컴파일 vs 인터프리트)

## 📝 정의
**Compile**과 **Interpret**는 **코드를 실행하는 두 가지 방식**입니다.

### 핵심 차이

**Compile (컴파일)**:
- 전체 코드를 기계어로 변환
- 실행 파일 생성
- 빠른 실행 속도
- 예: C, C++, Java

**Interpret (인터프리트)**:
- 한 줄씩 즉시 실행
- 실행 파일 없음
- 느린 실행 속도
- 예: Python, JavaScript

## 💡 예시

**컴파일 (C)**:
```bash
# 1. 컴파일 (시간 소요)
gcc program.c -o program

# 2. 실행 (빠름)
./program
```

**인터프리트 (Python)**:
```bash
# 바로 실행 (컴파일 단계 없음)
python script.py
```

## 🎯 장단점

**컴파일**:
- ✅ 빠른 실행
- ✅ 오류 사전 발견
- ❌ 컴파일 시간 필요
- ❌ 플랫폼 종속적

**인터프리트**:
- ✅ 즉시 실행
- ✅ 플랫폼 독립적
- ❌ 느린 실행
- ❌ 런타임 오류

## 📊 비교

| 언어 | 방식 | 실행 속도 |
|------|------|-----------|
| C/C++ | 컴파일 | 매우 빠름 |
| Java | 컴파일 + JVM | 빠름 |
| Python | 인터프리트 | 느림 |
| JavaScript | 인터프리트 | 중간 |
