# Variable (변수)

## 📝 정의

Variable은 **값에 이름을 붙여두는 자리**다.

메모리 어딘가에 값을 담아두고 그 자리에 이름을 걸어둔다. 이후로는 값을 직접 들고 다니지 않고 이름을 불러서 꺼내 쓰거나 바꾼다.

### 비유
이름표를 붙인 상자. 안에 무엇이 들었는지는 상자를 열어봐야 알지만, 이름표만 알면 찾아갈 수 있고 내용물을 바꿔 넣어도 이름표는 그대로다.

## 🖼️ 그림으로 보기

```도해
흐름: 변수 하나는 만들어져서 사라질 때까지 무엇을 겪나
이름 짓기 :: 무엇을 담을지 정하고 이름을 붙인다
값 넣기 :: age = 25 로 메모리 한 칸에 값이 들어간다
쓰기 :: 이름을 부르면 그 칸의 값이 나온다
바꾸기 :: age = 26 으로 같은 이름에 새 값이 들어간다
< 사라짐 :: 쓰이는 범위를 벗어나면 그 칸이 회수된다
= 값을 직접 다루지 않고 이름으로 가리키는 것이 전부다
```

## ⚠️ 해결하는 문제

```도해
대조: 같은 값을 코드 곳곳에 그대로 적어두면 어떻게 되나
숫자를 그대로 || 변수에 담아
값 바꾸기 :: 전부 찾아 고침 || 한 줄만 고침
읽는 사람 :: 무슨 뜻인지 모름 || 이름이 말해줌
계산 결과 :: 다시 계산한다 || 담아두고 쓴다
= 이름을 붙이는 순간 값이 한 곳에 모이고 뜻이 생긴다
```

단가 1000원을 코드 열 군데에 그대로 적어두면 값이 바뀔 때 열 군데를 다 찾아 고쳐야 하고, 한 군데를 놓치면 그 자리만 옛 값으로 남는다. `1000`이라는 숫자만 봐서는 그게 단가인지 수량 제한인지도 알 수 없다.

이름을 붙이면 두 문제가 한 번에 풀린다. 값은 한 곳에만 적히므로 고칠 자리도 한 곳이고, 이름 자체가 그 숫자가 무엇인지 설명해준다. 계산 결과도 마찬가지다. 담아두지 않으면 필요할 때마다 다시 계산해야 한다.

## ⚙️ 작동 원리

```도해
층: 같은 이름이 여러 곳에 있으면 어느 것을 쓰나
지역 :: 함수 안에서 만든 것. 함수가 끝나면 사라진다
전역 :: 파일 어디서나 보인다. 오래 살아남는다
내장 :: 언어가 미리 정해둔 이름들
= 안쪽부터 찾아 나가므로 가까운 이름이 먼 이름을 가린다
```

변수가 보이는 범위를 스코프라고 한다. 함수 안에서 만든 이름은 그 함수 안에서만 보이고 함수가 끝나면 사라진다. 그래서 다른 함수에서 같은 이름을 써도 서로 부딪히지 않는다. 언어에 따라 중괄호 블록 단위로 더 좁게 잡는 선언 방식도 있다.

이름이 값을 가리키는 방식에도 주의할 점이 있다. 숫자나 문자열 같은 것은 이름마다 값이 따로 있지만, 목록이나 객체는 이름이 그 덩어리를 가리키기만 한다. 그래서 한 목록을 두 이름에 담아두고 한쪽을 고치면 다른 쪽에서도 고쳐진 것이 보인다. 따로 두고 싶으면 복사본을 만들어야 한다.

이름 짓는 관례도 언어마다 정해져 있다. 파이썬은 단어를 밑줄로 잇고 자바스크립트는 뒤 단어의 첫 글자를 올려 쓴다. 바뀌지 않을 값은 전부 대문자로 적어 구분한다.

## 📊 비교: 변수 와 상수

| | 변수 | 상수 |
|---|---|---|
| 값 바꾸기 | 된다 | 막혀 있거나 약속으로 막는다 |
| 이름 짓기 | 소문자 위주 | 전부 대문자 |
| 담는 것 | 도중에 변하는 값 | 고정된 값 |
| 예 | 누적 합계, 현재 개수 | 최대 크기, 세율 |

## 💡 실제 사례

- **설정 값 모으기** — 단가와 할인율에 이름을 붙여 위쪽에 모아두면 정책이 바뀔 때 그 줄만 고친다.
- **중간 결과 담기** — 긴 수식을 단계마다 이름을 붙여 나누면 어느 단계에서 틀렸는지 짚을 수 있다.
- **누적하기** — 합계를 담을 이름을 0으로 두고 반복하면서 값을 더해 나간다.

## 🚫 흔한 오해

- **변수에 담으면 그 값의 복사본이 들어간다** — 목록이나 객체는 값 자체가 아니라 그것을 가리키는 표시가 들어간다. 다른 이름에 옮겨 담고 한쪽을 고치면 다른 쪽에서도 바뀌어 보인다.
- **이름은 짧을수록 좋다** — 치기는 편하지만 몇 줄만 지나면 무슨 뜻인지 알 수 없게 된다. 이름을 붙이는 이유 자체가 뜻을 남기는 것이다.
- **대문자로 적으면 못 바꾸는 값이 된다** — 언어에 따라 다르다. 파이썬에서 대문자는 바꾸지 말자는 약속일 뿐 실제로는 바꿀 수 있고, 진짜로 막는 것은 상수 선언 문법이다.

## 🚨 주의사항

- **쓰기 전에 값을 넣어둔다.** 값이 들어간 적 없는 이름을 부르면 그 자리에서 오류가 난다.
- **한 이름을 다른 용도로 재사용하지 않는다.** 위쪽에서 담아둔 것을 아래쪽에서 다른 뜻으로 덮어쓰면 사이에 있는 코드가 어느 쪽을 보는지 알기 어려워진다.

## 📝 정리

Variable은 메모리의 한 자리에 값을 담고 그 자리에 이름을 걸어두는 것이다. 값이 한 곳에 모이고 이름이 뜻을 설명해주기 때문에 고치기 쉽고 읽기 쉬워진다. 보이는 범위는 스코프가 정하고, 목록이나 객체는 값이 아니라 가리키는 표시가 담긴다는 점을 기억해야 한다.

## ❓ 이해했는지

- 목록을 담은 이름을 다른 이름에 옮겨 담고 한쪽을 고쳤더니 다른 쪽도 바뀌었다. 왜 그런가?
- 함수 안에서 만든 이름을 함수 밖에서 부를 수 없는 이유는?
- 단가 1000을 코드 열 군데에 그대로 적어두면 나중에 무슨 일이 생기나?
