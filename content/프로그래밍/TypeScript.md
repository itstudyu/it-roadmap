# TypeScript (타입스크립트)

## 📝 정의

TypeScript는 **JavaScript 에 값의 종류를 적어 두는 언어**다.

적어 둔 종류는 돌리기 전에 안 맞는 자리를 찾는 데만 쓰이고, 실제로 돌 때는 남지 않는다. 요즘 Node.js 는 `.ts` 파일을 받으면 타입 표기를 공백으로 바꿔 지운 뒤 그대로 실행한다 — 타입 검사는 하지 않는다.

### 이름
Type :: 값의 종류
Script :: 그때그때 읽어 돌리는 글
= 붙여 읽으면 "종류를 적어 둔 스크립트". 새 언어가 아니라 표기가 한 겹 얹힌 것이다

### 비유
옮기기 전에만 붙였다가 옮기고 나면 떼어 버리는 이삿짐 상자의 내용물 이름표.

### 예
확장자를 ts 로 바꾸고 함수 옆에 어떤 종류가 오는지 적어 두면, 오타 하나를 돌려 보기 전에 잡아 준다.

## 🖼️ 그림으로 보기

```도해
흐름: 종류를 적어 둔 파일 하나는 어떤 길을 지나 돌아가나
적기 :: 값마다 어떤 종류인지 함께 적는다
타입 검사 :: 적어 둔 종류끼리 안 맞는 자리를 찾는다. 따로 도는 단계다
지우기 :: 종류 표기를 공백으로 바꿔 없앤다
실행 :: 표기가 빠진 JavaScript 만 돌아간다
= 적어 둔 종류는 돌기 전까지만 있고, 실제로 도는 것은 JavaScript 다
```

## ⚠️ 해결하는 문제

```도해
대조: 값의 종류를 적어 두지 않으면 무엇이 달라지나
안 적어 두면 || 적어 두면
안 맞는 값 :: 돌려 봐야 터진다 || 돌리기 전에 걸린다
터지는 자리 :: 사용자 앞에서 || 내 화면에서
고칠 때 :: 무엇이 깨질지 모른다 || 검사기가 짚어 준다
= 도는 방식은 그대로다. 달라지는 것은 어긋난 자리를 언제 아느냐다
```

JavaScript 는 값에 종류를 적어 두지 않는다. 그래서 숫자가 와야 할 자리에 글자가 와도 그 줄이 실제로 돌아가는 순간에야 터지고, 그 순간이 사용자 앞일 수 있다.

TypeScript 는 **종류를 사람이 미리 적어 두게** 해서 그 순간을 앞으로 당긴다. 적어 둔 것끼리 아귀가 안 맞으면 돌리기 전에 검사기가 그 자리를 짚어 준다.

## ⚙️ 작동 원리

지우기는 문자 하나를 지우는 것이 아니라 **공백으로 바꿔** 없애는 것이다. 글자 수가 그대로라 줄 번호와 자리가 안 밀리고, 그래서 원본과 실행본을 이어 주는 별도의 지도가 필요 없다.

지워지지 않는 문법도 있다. `enum` 이나 값을 담은 `namespace` 처럼 **돌아갈 코드를 새로 만들어야** 하는 것들은 지우기만 해서는 못 돌리고 오류가 난다. 불러오기도 마찬가지다 — 종류만 쓰려고 가져오는 자리에는 `import type` 이라고 적어야 지우는 쪽이 그것을 종류로 알아본다. 안 적으면 값으로 알고 그대로 두어, 없는 것을 가져오다 실행 중에 터진다.

## 💡 실제 사례

- **굽지 않고 바로 돌리기** — 스크립트 하나 돌리려고 빌드 단계를 두지 않아도 된다. Node.js 가 표기를 지우고 그대로 실행한다.
- **종류만 가져오기** — 다른 파일에서 종류만 빌려 쓰는 자리에는 `import type` 을 붙여 둔다. 안 붙이면 지운 뒤에 남아서 실행 중에 터진다.
- **패키지로 내놓을 때** — Node.js 는 `node_modules` 안의 TypeScript 파일을 아예 다루지 않는다. 배포하는 쪽은 JavaScript 로 바꿔서 올리라는 뜻이다.

## 🚫 흔한 오해

- **돌아가는 동안 타입을 검사해 준다** — 돌리는 쪽은 표기를 지우고 시작한다. 밖에서 들어온 값이 적어 둔 종류와 다르면 아무도 안 막는다.
- **타입만 적은 것이니 어디서나 그대로 돌아간다** — 표기가 아닌 문법도 섞여 있다. 돌아갈 코드를 새로 만들어야 하는 것들은 지우기만 하는 곳에서 오류가 난다.
- **타입을 붙였으니 이제 안 터진다** — 종류가 안 맞는 것만 잡는다. 계산이 틀렸거나 순서가 뒤엉킨 것은 그대로 지나간다.

## 📝 정리

**"돌리기 전까지만 붙어 있는 그 이름표"** 라고 읽으면 된다. 적어 둔 종류는 실행에 남지 않으므로, 돌리기 전에 검사를 한 번 돌려야 적어 둔 보람이 있다. 밖에서 들어오는 값은 표기와 무관하게 들어오므로 그 자리는 따로 확인해야 한다.

## 🧒 열 살에게

이삿짐 상자마다 안에 뭐가 들었는지 이름표를 붙여 두면 옮기기 전에 잘못 담은 걸 찾을 수 있지? 그 이름표는 짐을 다 옮기고 나면 떼어 버려. 그러니까 짐 자체는 이름표를 붙이기 전이랑 똑같아.

## ❓ 이해했는지

- 종류를 적어 뒀는데 실행 중에 엉뚱한 값이 들어오는 일은 왜 생기나 → 흔한 오해
- 파일을 그대로 돌릴 때 적어 둔 종류 표기는 어떻게 되나 → 그림
- 종류만 빌려 쓰려고 불러오는 자리에 왜 따로 표시를 하나 → 작동 원리
