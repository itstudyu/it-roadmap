# Sprint (스프린트)

## 📝 정의
Sprint는 **정해진 기간 동안 특정 목표를 달성하는 작업 주기**입니다. 보통 1-4주(일반적으로 2주).

### Sprint 구조

**Sprint Planning → 개발 → Daily Standup → Review → Retrospective**

```
Week 1: 월 화 수 목 금
        개 개 개 개 개발

Week 2: 월 화 수 목 금
        개 리 회 다음
        발 뷰 고 준비
```

## 💡 Sprint 목표 예시

**Sprint 1 (2주)**:
```
목표: 사용자 로그인 기능
작업:
- 로그인 UI
- 인증 API
- 세션 관리
- 테스트
```

## 🎯 Sprint Velocity

```
Sprint마다 완료한 Story Point 측정
Sprint 1: 20 points
Sprint 2: 25 points
Sprint 3: 23 points
→ 평균: ~23 points

다음 Sprint 계획에 활용
```
