# North Star Metric (북극성 지표)

## 📝 정의

North Star Metric은 **제품의 가치를 대표하는 지표 하나**다.

팀마다 보는 숫자가 다르면 무엇을 먼저 할지 정하는 자리가 취향 다툼이 된다. 하나를 정해두면 각 기능이 그 숫자를 얼마나 움직이는지로 비교할 수 있다.

### 비유
북극성. 배마다 가는 길은 달라도 같은 별을 보고 방향을 잡는다.

### 예
연말이면 음악 앱이 올해 몇 시간을 들었는지 정리해 보여준다. 그 서비스가 무엇을 세고 있는지가 거기 드러난다.

## 🖼️ 그림으로 보기

```도해
흐름: 지표 하나를 정하면 결정이 어떻게 달라지나
후보 :: 가입자, 매출, 체류 시간이 나란히 있다
기준 :: 사용자가 가치를 느끼는 순간을 고른다
지표 :: 그 순간을 세는 숫자 하나로 정한다
평가 :: 기능마다 이 숫자를 얼마나 움직이는지 본다
결정 :: 가장 크게 움직이는 것부터 한다
= 무엇을 먼저 할지 다투는 대신 같은 자로 재게 된다
```

## ⚠️ 해결하는 문제

```도해
대조: 팀마다 다른 숫자를 보면 어떻게 되나
지표 없이 || 북극성 지표로
목표 :: 팀마다 다름 || 하나로 모임
우선순위 :: 목소리 큰 쪽 || 영향 큰 쪽
성장 :: 숫자만 커짐 || 쓰는 사람이 늚
= 같은 자로 재기 시작하면 논쟁이 비교로 바뀐다
```

한 사람은 가입자를, 한 사람은 매출을, 한 사람은 체류 시간을 늘리자고 한다. 셋 다 틀린 말은 아니라서 회의는 길어지고, 결국 목소리가 큰 쪽이나 만들기 쉬운 쪽으로 정해진다.

숫자가 여러 개면 좋아 보이는 숫자만 골라 보게 되는 문제도 있다. 가입자 100만 명을 달성했는데 실제로 쓰는 사람은 5천 명인 상태에서도 보고할 숫자는 남는다. 지표를 하나로 좁히면 이 회피가 어려워진다.

## 🧱 구성

```도해
층: 북극성 지표는 무엇으로 움직이나
북극성 :: 월간 활성 사용자 같은 숫자 하나
입력 지표 :: 신규 가입, 활성화율, 재방문, 복귀
팀의 일 :: 각 입력 지표를 하나씩 맡아 움직인다
= 북극성은 직접 못 건드린다. 아래를 움직여야 위가 움직인다
```

## ⚙️ 작동 원리

지표를 고르는 기준은 사용자가 실제로 가치를 얻는 순간이다. 음악 서비스라면 가입이 아니라 듣는 시간이고, 숙박 서비스라면 검색이 아니라 예약된 숙박 일수다.

여기에 조건 몇 가지가 붙는다. 매출로 이어져야 하고, 셀 수 있어야 하고, 팀이 움직일 수 있어야 하고, 설명 없이 이해돼야 한다.

## 📊 비교: 제품별 북극성 지표

| 제품 | 지표 | 이유 |
|---|---|---|
| Facebook | 일간 활성 사용자 | 매일 쓴다는 건 가치를 느낀다는 것 |
| Airbnb | 예약된 숙박 일수 | 예약이 곧 제공한 가치 |
| Spotify | 청취 시간 | 듣는 것이 핵심 경험 |
| Slack | 전송된 메시지 수 | 메시지가 곧 협업 |

## 💡 실제 사례

- **기능 우선순위** — 세 기능 중 무엇을 먼저 할지 각각이 지표를 몇 퍼센트 움직이는지로 비교한다.
- **허상 걸러내기** — 가입자는 늘었는데 지표가 그대로면 성장이 아니라는 신호로 읽는다.
- **팀별 분담** — 신규 가입은 마케팅이, 활성화와 재방문은 제품팀이 맡는 식으로 입력 지표를 나눈다.

## 🚫 흔한 오해

- **매출을 북극성으로 삼으면 된다** — 매출은 결과라서 무엇을 고쳐야 할지 알려주지 않는다. 가치를 느낀 순간을 세고, 매출은 그 뒤에 따라오게 둔다.
- **총 가입자 수가 늘면 성장하는 것이다** — 누적 숫자는 줄어들지 않아서 그래프가 항상 오른쪽 위로 간다. 아무도 안 쓰는 상태에서도 모양은 똑같다.
- **정교하게 만든 지표일수록 좋다** — 여러 숫자를 섞은 식은 팀이 이해하지 못한다. 이해되지 않는 지표는 방향을 모으지 못하니 지표 노릇을 못 한다.

## 🚨 주의사항

- **팀이 직접 움직일 수 없는 숫자는 고르지 않는다.** 언론 노출 같은 것은 오르내려도 할 수 있는 일이 없다.
- **특정 기능의 사용률로 좁히지 않는다.** 제품 전체가 아니라 그 기능만 좋아지는 방향으로 결정이 쏠린다.

## 📝 정리

North Star Metric은 제품이 주는 가치를 대표하는 숫자 하나다. 팀마다 흩어진 목표를 한 방향으로 모으고, 기능의 우선순위를 같은 자로 재게 해준다.

## ❓ 이해했는지

- 가입자가 매달 2천 명씩 느는데도 성장으로 보지 않는 경우는 → 실제 사례
- 북극성 지표를 직접 올릴 수 없다면 무엇을 움직여야 하나 → 구성
- 매출을 북극성 지표로 두지 않는 이유는 → 흔한 오해
