# OKR (Objectives and Key Results)

## 📝 정의
OKR은 **목표(Objective)와 핵심 결과(Key Results)를 설정하는 목표 관리 프레임워크**입니다.

### 구조
- **Objective**: 달성하고자 하는 목표 (정성적)
- **Key Results**: 목표 달성 여부를 측정하는 지표 (정량적)

## 💡 OKR 예시

**회사 OKR**:
```
O: 최고의 사용자 경험 제공
KR1: NPS 70점 달성
KR2: 앱 크래시율 1% 이하
KR3: 페이지 로딩 시간 2초 이하
```

**개인 OKR**:
```
O: AI 전문가 되기
KR1: LLM 프로젝트 3개 완성
KR2: AI 논문 10편 읽기
KR3: 기술 블로그 12개 작성
```

## 🎯 좋은 OKR 작성법

**Objective (목표)**:
```
✅ 영감을 주는
✅ 도전적인
✅ 명확한

예: "시장 1위 달성"
```

**Key Results (핵심 결과)**:
```
✅ 측정 가능한
✅ 기한 있는
✅ 도전적이지만 달성 가능한

예: "월 활성 사용자 100만 달성 (Q1)"
```

## 📊 OKR vs KPI

| 특성 | OKR | KPI |
|------|-----|-----|
| 목적 | 도전적 목표 | 현상 유지/측정 |
| 주기 | 분기별 | 지속적 |
| 달성률 | 70% 목표 | 100% 목표 |
