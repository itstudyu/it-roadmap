# Scrum (스크럼)

## 📝 정의
Scrum은 **Agile을 실천하는 구체적인 프레임워크**입니다. Sprint 단위로 개발합니다.

### 핵심 역할
- **Product Owner**: 무엇을 만들지 결정
- **Scrum Master**: 프로세스 관리
- **Development Team**: 실제 개발

### Scrum 이벤트

**1. Sprint Planning (계획)**:
```
목표: 이번 Sprint에서 무엇을?
시간: 2-4시간
결과: Sprint Backlog
```

**2. Daily Standup (일일 미팅)**:
```
매일 15분
- 어제 한 일
- 오늘 할 일
- 장애물
```

**3. Sprint Review (리뷰)**:
```
Sprint 끝: 결과물 시연
이해관계자 피드백
```

**4. Retrospective (회고)**:
```
무엇이 좋았나?
무엇을 개선할까?
→ 다음 Sprint 개선
```
