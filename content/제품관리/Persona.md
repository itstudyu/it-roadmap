# Persona (페르소나)

## 📝 정의

Persona는 **조사한 사용자들을 한 사람으로 좁혀 적어둔 것**이다.

회의에서 "사용자"라고 말하면 사람마다 다른 얼굴을 떠올린다. 인터뷰와 사용 기록에서 반복되는 특징만 모아 이름과 하루 일과가 있는 한 사람으로 만들어두면, 그다음부터는 모두가 같은 사람을 놓고 이야기하게 된다.

### 비유
여러 명의 증언을 모아 그린 몽타주. 실존 인물은 아니지만 특징은 실제에서 나온다.

### 예
어떤 앱은 글씨가 크고 단추가 몇 개뿐인데 어떤 앱은 기능이 빽빽하다. 만들 때 머릿속에 둔 사람이 달라서 갈린 것이다.

## 🖼️ 그림으로 보기

```도해
흐름: 인터뷰 기록이 어떻게 한 사람으로 좁혀지나
수집 :: 인터뷰, 문의 내역, 사용 기록을 모은다
묶기 :: 비슷하게 행동하는 사람끼리 나눈다
고르기 :: 가장 큰 무리를 대표로 삼는다
쓰기 :: 목표, 고충, 하루 일과를 적는다
판단 :: 회의에서 이 사람을 기준으로 정한다
= 여러 명에게서 나온 것을 한 사람의 얼굴로 줄여둔 것이다
```

## ⚠️ 해결하는 문제

```도해
대조: 대상을 사용자들이라고만 부르면 어떻게 되나
페르소나 없이 || 페르소나로
회의 기준 :: 각자 다른 사람 || 같은 한 사람
기능 결정 :: 목소리 큰 쪽 || 이 사람의 고충
겨냥 범위 :: 모두를 겨냥 || 한 무리를 겨냥
= 누구를 위한 것인지 정해야 무엇을 뺄지도 정해진다
```

"사용자가 이걸 원할까요"라는 질문은 끝나지 않는다. 각자 머릿속의 사용자가 다르기 때문에, 서로 다른 사람 얘기를 하면서 같은 단어를 쓰고 있는 것이다. 결론이 안 나면 결국 직급이나 목소리가 정한다.

한 사람으로 좁혀 적어두면 질문이 바뀐다. "이 사람이라면 이 화면에서 무엇을 할까"는 답을 맞춰볼 수 있는 질문이고, 답이 갈리면 무엇을 더 조사해야 하는지도 드러난다.

## 🧱 구성

```도해
층: 페르소나에 무엇이 적혀야 쓸모가 있나
고충과 목표 :: 왜 쓰는지, 어디서 막히는지. 실제로 한 말을 근거로 붙인다
행동 :: 언제 어떻게 쓰는지. 하루 일과
인구통계 :: 나이, 직업, 사는 곳
= 아래만 있으면 명단이고, 위가 있어야 결정에 쓰인다
```

## ⚙️ 작동 원리

만드는 순서는 수집이 먼저다. 인터뷰 같은 대화 기록과 사용 로그 같은 숫자를 함께 본다. 한쪽만으로는 무엇을 하는지는 알아도 왜 하는지는 모른다.

다음은 묶는 일이다. 나이나 직업이 아니라 행동이 비슷한 사람끼리 나눈다. 같은 서른 살이라도 매일 쓰는 사람과 한 달에 한 번 쓰는 사람은 전혀 다른 것을 원한다.

주로 겨냥할 사람 한둘을 정하고, 겨냥하지 않을 사람도 적어둔다. 제외 대상을 적어두면 어디에 힘을 쓰지 않을지가 같이 정해진다.

## 💡 실제 사례

- **기능 순서 정하기** — 후보 기능을 이 사람의 고충에 닿는 것부터 줄 세운다.
- **회의 기준 삼기** — "이 사람이라면 이 단계에서 그만둘까"로 물으면 취향 다툼이 줄어든다.
- **메시지 정하기** — 이 사람이 실제로 쓴 표현을 그대로 안내 문구에 쓴다.

## 🚫 흔한 오해

- **페르소나는 상상해서 만드는 캐릭터다** — 이름과 사진은 지어내지만 특징은 조사에서 나온다. 근거 없이 만들면 팀의 짐작을 사람 모양으로 적어둔 것에 그친다.
- **여러 명 만들수록 촘촘해진다** — 열 명을 만들면 겨냥한 사람이 없는 것과 같다. 결정을 갈라주지 못하는 페르소나는 늘어나기만 한다.
- **나이와 직업을 적으면 페르소나다** — 그건 명단이다. 무엇 때문에 쓰고 어디서 막히는지가 없으면 어떤 결정도 갈리지 않는다.

## 🚨 주의사항

- **한 번 만들고 두면 옛날 사람이 남는다.** 사용자는 바뀌는데 문서는 안 바뀌어서, 몇 해 전 조사로 지금 결정을 하게 된다.
- **팀에서 아무도 이름을 부르지 않으면 안 쓰이는 것이다.** 회의에서 인용되지 않는 페르소나는 만들어둔 파일일 뿐이다.

## 📝 정리

Persona는 조사에서 반복되는 특징을 모아 한 사람으로 좁혀둔 문서다. 나이와 직업이 아니라 무엇 때문에 쓰고 어디서 막히는지가 적혀 있어야 결정을 가른다. 겨냥할 사람을 정하는 일은 곧 겨냥하지 않을 사람을 정하는 일이다.
