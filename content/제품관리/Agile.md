# Agile (애자일)

## 📝 정의
Agile은 **반복적이고 점진적으로 소프트웨어를 개발하는 방법론**입니다. 변화에 빠르게 대응합니다.

### 핵심 원칙
- 개인과 상호작용 > 프로세스와 도구
- 작동하는 소프트웨어 > 문서
- 고객 협력 > 계약 협상
- 변화 대응 > 계획 고수

### Agile vs Waterfall

**Waterfall (폭포수)**:
```
요구사항 → 설계 → 개발 → 테스트 → 배포
(6개월 소요)
→ 중간에 변경 불가
→ 배포 후 문제 발견 😱
```

**Agile**:
```
Sprint 1 (2주): 기능 A
Sprint 2 (2주): 기능 B
Sprint 3 (2주): 기능 C
→ 2주마다 피드백
→ 바로 수정 가능 ✅
```

## 💡 Agile 실천 방법

**Scrum**: 2주 단위 Sprint
**Kanban**: 지속적인 흐름
**XP**: 기술적 실천 (TDD, Pair Programming)
