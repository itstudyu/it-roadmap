# Funnel (퍼널)

## 📝 정의

Funnel은 **사용자가 목표까지 가며 줄어드는 단계별 흐름**이다.

들어온 사람 전부가 끝까지 가지는 않는다. 단계마다 얼마씩 빠져나가는 모양이 깔때기를 닮아서 퍼널이라고 부르고, 어느 칸에서 가장 많이 빠지는지를 보려고 쓴다.

### 비유
깔때기. 위는 넓고 아래는 좁아서 부은 양보다 나오는 양이 늘 적다.

## 🖼️ 그림으로 보기

```도해
흐름: 방문자 1만 명이 구매까지 가면서 얼마나 남나
방문 :: 10000명이 들어온다
상품 조회 :: 3000명이 상세를 본다
장바구니 :: 900명이 담는다
결제 시작 :: 450명이 결제 화면에 들어간다
< 구매 완료 :: 270명이 결제를 끝낸다
= 마지막 숫자보다 어느 칸에서 가장 많이 빠졌는지가 볼 것이다
```

## ⚠️ 해결하는 문제

```도해
대조: 전환율을 하나의 숫자로만 보면 어떻게 되나
전체 수치만 || 단계별로
문제 위치 :: 짐작만 한다 || 칸이 지목된다
개선 순서 :: 전부 손댄다 || 최악부터 손댄다
광고 판단 :: 더 붓기만 함 || 새는 데를 막음
= 같은 2.7% 라도 어디서 새는지 알아야 고칠 수 있다
```

전환율이 낮다는 사실만으로는 할 수 있는 일이 없다. 페이지도 고쳐보고 문구도 바꿔보다가, 정작 사람들이 가장 많이 떠나는 자리는 건드리지 않은 채 끝난다.

단계를 나눠 세면 그 자리가 이름을 갖는다. 방문에서 조회로 30%가 넘어가고 결제 화면에서 60%가 넘어간다는 식으로 적히면, 어느 칸을 먼저 손볼지는 더 이상 취향 문제가 아니다.

## ⚙️ 작동 원리

각 칸의 통과율은 앞 칸 대비로 센다. 전체 전환율은 그 통과율을 전부 곱한 값이라서, 한 칸만 낮아도 앞뒤의 노력이 다 지워진다.

칸 수 자체도 결과를 바꾼다. 칸마다 60%가 통과하는 퍼널이 5칸이면 전체는 7.8%지만, 같은 통과율로 3칸이면 21.6%가 된다. 필요 없는 단계를 없애는 것만으로 숫자가 움직이는 이유가 여기 있다.

단계를 무엇으로 잡을지는 제품마다 다르다. 획득에서 활성화와 유지를 거쳐 수익과 추천까지 보는 방식이 널리 쓰이고, 이커머스처럼 구매 경로가 뚜렷하면 방문에서 결제까지를 그대로 칸으로 삼는다.

## 💡 실제 사례

- **결제 이탈 확인** 결제 화면까지 온 450명 중 절반이 사라지면 결제 절차부터 손본다.
- **가입 폼 개선** 입력 항목을 줄인 화면과 기존 화면을 나눠 보여주고 통과율을 비교한다.
- **광고 판단** 방문자만 늘고 아래 칸의 수가 그대로면 광고를 늘리는 대신 아래를 먼저 고친다.

## 🚫 흔한 오해

- **전환율이 낮으면 사람을 더 데려오면 된다** — 새는 자리를 그대로 두고 위에 더 부으면 광고비만 늘어난다. 아래를 먼저 막는 편이 훨씬 싸게 먹힌다.
- **마지막 칸의 숫자가 전환율이다** — 각 칸의 통과율을 곱한 결과다. 5%짜리 칸 하나가 앞의 모든 노력을 지운다.
- **단계를 자세히 나눌수록 정확하다** — 열 몇 칸으로 쪼개면 칸마다 사람 수가 적어져 무엇이 문제인지 오히려 흐려진다.

## 🚨 주의사항

- **신규와 재방문을 같은 퍼널에 넣지 않는다.** 행동이 달라서 섞어 세면 양쪽 다 흐려진다.
- **기간을 정하고 센다.** 하루 만에 사는 사람과 한 달 뒤에 사는 사람을 한 칸에 넣으면 통과율이 실제보다 낮게 나온다.

## 📝 정리

Funnel은 사용자가 목표까지 가는 길을 단계로 나눠 각 칸의 통과율을 보는 방법이다. 전체 전환율은 칸들의 곱이라서, 가장 많이 빠지는 칸 하나가 결과를 좌우한다.

## ❓ 이해했는지

- 결제 화면까지 온 450명 중 절반이 사라진다면 어느 단계를 먼저 손봐야 하나?
- 방문자를 두 배로 늘렸는데 구매 수가 그대로일 때 무엇을 의심해야 하나?
- 칸마다 60%가 통과하는 퍼널을 5칸에서 3칸으로 줄이면 전체 전환율은 어떻게 되나?
