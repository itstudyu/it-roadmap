# SSL/TLS

## 📝 정의

TLS는 **오가는 데이터를 가리고 상대가 맞는지 확인하는 규약**이다.

HTTPS의 S가 이것이다. SSL은 옛 이름이고 지금 실제로 쓰이는 것은 TLS인데, 부르는 습관이 남아 둘을 붙여 쓴다.

### 비유
봉인된 편지. 엽서는 배달하는 사람이 다 읽지만 봉인된 편지는 받는 사람만 연다. 봉투에 찍힌 인장이 보낸 곳이 맞는지도 알려준다.

### 예
주소창에 주소만 쳐도 앞에 https 가 붙어서 열린다. 그 뒤에 붙은 s 한 글자가 이 규약이 걸렸다는 표시다.

## 🖼️ 그림으로 보기

```도해
흐름: 자물쇠가 걸리기까지 무슨 순서로 오가나
브라우저 :: 어떤 암호 방식을 쓸 수 있는지 알린다
서버 :: 그중 하나를 고르고 인증서를 보낸다
브라우저 :: 인증서를 검사한다. 발급 기관과 도메인과 기간
양쪽 :: 이번 연결에만 쓸 열쇠를 함께 만든다
이후 :: 그 열쇠로 내용을 가려서 주고받는다
= 신원 확인이 먼저고 암호화는 그다음이다
```

## ⚠️ 해결하는 문제

```도해
대조: 카페 와이파이에서 로그인하면 어떻게 되나
HTTP 로 || HTTPS 로
전송 내용 :: 그대로 읽힌다 || 가려져 있다
중간에 끼어들기 :: 알 수 없다 || 인증서로 걸린다
내용 변조 :: 티가 안 난다 || 검사에서 걸린다
= 읽히는 것과 바꿔치기당하는 것을 함께 막는다
```

네트워크는 여러 장비를 거쳐 간다. 가려두지 않으면 그 사이 어디서든 내용을 볼 수 있고, 공용 와이파이에서는 특히 쉽다.

더 큰 문제는 상대가 진짜인지 알 수 없다는 것이다. 가짜 서버가 중간에 앉아 양쪽 말을 옮기면 암호화만으로는 막지 못한다. 인증서가 이 자리를 맡아서, 그 도메인의 주인이 맞다고 제3자가 보증한 문서를 확인한다.

## 🧱 구성

```도해
층: TLS 는 무엇과 무엇 사이에 끼어 있나
HTTP :: 주고받는 내용. 요청과 응답의 양식
TLS :: 그 내용을 가리고 상대를 확인하는 겹
TCP :: 암호문을 순서대로 실어 나르는 연결
IP :: 목적지 컴퓨터까지 찾아가는 주소 체계
= 새 통신 방식이 생긴 게 아니라 HTTP 와 TCP 사이에 한 겹이 낀 것이다
```

## ⚙️ 작동 원리

암호화 방식은 두 가지를 섞어 쓴다. 열쇠 하나로 잠그고 여는 방식은 빠르지만 그 열쇠를 어떻게 건네느냐가 문제고, 열쇠가 두 개인 방식은 안전하게 건넬 수 있지만 느리다.

그래서 처음에만 느린 방식으로 이번 연결에만 쓸 열쇠를 합의하고, 실제 데이터는 그 열쇠로 빠르게 주고받는다.

인증서 검사는 세 가지를 본다. 신뢰하는 발급 기관이 서명했는지, 접속한 도메인과 인증서에 적힌 도메인이 같은지, 유효 기간이 지나지 않았는지다. 하나라도 어긋나면 브라우저가 경고를 띄운다.

## 💡 실제 사례

- **주소창 자물쇠** — 인증서 검사가 통과했다는 표시다. 경고가 뜨는 사이트는 셋 중 하나가 어긋난 것이다.
- **인증서 만료** — 갱신을 놓치면 접속이 통째로 막힌다. 자동 갱신을 걸어두는 이유가 이것이다.
- **HTTP 로 들어와도 HTTPS 로 보내기** — 주소를 그냥 쳐도 서버가 암호화된 쪽으로 돌려보낸다.

## 🚫 흔한 오해

- **HTTPS면 그 사이트는 안전하다** — 안전한 건 오가는 길이다. 피싱 사이트도 인증서를 받을 수 있어서, 자물쇠가 있다는 것과 믿을 만한 곳이라는 것은 다른 얘기다.
- **인증서는 데이터를 암호화하는 열쇠다** — 인증서 자체는 신원을 증명하는 문서다. 실제 암호화에는 연결할 때마다 새로 만든 열쇠를 쓴다.
- **HTTPS를 쓰면 서버 안의 데이터도 보호된다** — 보호되지 않는다. 가려지는 건 오가는 구간뿐이고, 서버에 저장된 값은 따로 암호화해야 한다.

## 🚨 주의사항

- **오래된 버전을 열어두지 않는다.** 낡은 방식이 켜져 있으면 공격자가 그쪽으로 협상을 끌어내릴 수 있다.
- **한 페이지에 HTTP 자원을 섞지 않는다.** 암호화된 페이지 안에 가려지지 않은 요청이 끼면 그 부분이 그대로 노출된다.

## 📝 정리

TLS는 오가는 내용을 가리고 상대가 맞는지 확인하는 규약이다. 인증서로 신원을 먼저 확인한 다음 이번 연결에만 쓸 열쇠를 만들어 데이터를 주고받으며, 지켜주는 범위는 오가는 구간까지다.
