# 암호화 (Encryption)

## 📝 정의

암호화는 **정보를 읽을 수 없는 형태로 변환하는 과정**입니다. 권한이 있는 사람만 복호화하여 원본 정보를 볼 수 있습니다.

### 핵심 개념

- **암호화 (Encryption)**: 평문 → 암호문
- **복호화 (Decryption)**: 암호문 → 평문
- **키 (Key)**: 암호화/복호화에 사용

## 💡 암호화 종류

### 1. 대칭키 암호화

```
동일한 키로 암호화/복호화

평문 --[키]→ 암호문 --[같은 키]→ 평문

장점: 빠름
단점: 키 공유 문제
```

```python
from cryptography.fernet import Fernet

# 키 생성
key = Fernet.generate_key()
cipher = Fernet(key)

# 암호화
message = b"Hello World"
encrypted = cipher.encrypt(message)
print(f"암호화: {encrypted}")

# 복호화
decrypted = cipher.decrypt(encrypted)
print(f"복호화: {decrypted}")  # b"Hello World"
```

### 2. 비대칭키 암호화 (공개키)

```
공개키로 암호화 → 개인키로 복호화

공개키: 누구나 볼 수 있음
개인키: 본인만 가짐

장점: 키 공유 안전
단점: 느림
```

```python
from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

# 키 쌍 생성
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048
)
public_key = private_key.public_key()

# 공개키로 암호화
message = b"Secret Message"
encrypted = public_key.encrypt(
    message,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)

# 개인키로 복호화
decrypted = private_key.decrypt(
    encrypted,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)
print(decrypted)  # b"Secret Message"
```

## 🎯 실전 활용

### 비밀번호 암호화 (해시)

```python
import hashlib
import secrets

def hash_password(password):
    """비밀번호 해시 (단방향)"""
    # Salt 생성 (무작위 값)
    salt = secrets.token_hex(16)

    # SHA256 해시
    password_hash = hashlib.pbkdf2_hmac(
        'sha256',
        password.encode('utf-8'),
        salt.encode('utf-8'),
        100000  # 반복 횟수
    )

    return salt + ':' + password_hash.hex()

def verify_password(stored, password):
    """비밀번호 검증"""
    salt, stored_hash = stored.split(':')

    password_hash = hashlib.pbkdf2_hmac(
        'sha256',
        password.encode('utf-8'),
        salt.encode('utf-8'),
        100000
    )

    return password_hash.hex() == stored_hash

# 저장
hashed = hash_password("mypassword123")
print(f"저장: {hashed}")

# 검증
is_valid = verify_password(hashed, "mypassword123")
print(f"인증: {is_valid}")  # True
```

### 파일 암호화

```python
from cryptography.fernet import Fernet

def encrypt_file(filename, key):
    """파일 암호화"""
    f = Fernet(key)

    with open(filename, 'rb') as file:
        file_data = file.read()

    encrypted_data = f.encrypt(file_data)

    with open(filename + '.encrypted', 'wb') as file:
        file.write(encrypted_data)

def decrypt_file(filename, key):
    """파일 복호화"""
    f = Fernet(key)

    with open(filename, 'rb') as file:
        encrypted_data = file.read()

    decrypted_data = f.decrypt(encrypted_data)

    with open(filename[:-10], 'wb') as file:  # .encrypted 제거
        file.write(decrypted_data)

# 사용
key = Fernet.generate_key()
encrypt_file('secret.txt', key)
decrypt_file('secret.txt.encrypted', key)
```

## 🚨 주의사항

```python
# ❌ 나쁜 예
password = "password123"
# → 평문 저장: 절대 금지!

# ❌ 약한 암호화
import base64
encrypted = base64.b64encode(b"secret")
# → Base64는 인코딩일 뿐, 암호화 아님!

# ✅ 좋은 예
from cryptography.fernet import Fernet
cipher = Fernet(Fernet.generate_key())
encrypted = cipher.encrypt(b"secret")
# → 실제 암호화
```

## 📝 정리

**핵심:**
```
암호화 = 정보 보호
→ 평문 → 암호문
→ 키로만 복호화
```

**종류:**
```
대칭키: 같은 키 (빠름)
비대칭키: 공개키+개인키 (안전)
해시: 단방향 (비밀번호)
```

**활용:**
```
HTTPS: 웹 통신
비밀번호: 해시
파일: AES
통신: TLS/SSL
```
