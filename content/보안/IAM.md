# IAM (Identity and Access Management)

## 📝 정의

IAM은 **누가 어떤 자원에 무엇을 할 수 있는지 정해두는 체계**다.

클라우드 계정 하나 안에 서버, 저장소, 데이터베이스가 전부 들어 있다. 모두가 전부를 만질 수 있게 두면 실수 한 번이 계정 전체로 번진다. IAM은 사람과 서비스마다 닿을 수 있는 범위를 따로 정한다.

### 비유
건물 출입 카드. 카드마다 열리는 층이 다르고, 하나를 잃어버려도 그 카드만 막으면 된다.

## 🖼️ 그림으로 보기

```도해
흐름: 파일 하나를 요청하면 IAM 은 무엇을 보나
요청 :: 개발자가 저장소의 파일을 달라고 한다
인증 :: 누구인지부터 확인한다. 키나 토큰으로
정책 조회 :: 그 신원에 붙어 있는 정책을 모은다
평가 :: 누가, 무엇을, 어디에가 정책과 맞는지 본다
< 결과 :: 맞으면 파일, 아니면 403 을 돌려준다
= 신원 확인과 권한 확인은 다른 단계다. 로그인해도 막힐 수 있다
```

## ⚠️ 해결하는 문제

```도해
대조: 권한을 나누지 않으면 어떻게 되나
IAM 없이 || IAM 으로
실수 범위 :: 계정 전체 || 준 범위까지만
퇴사 처리 :: 공용 키 교체 || 계정만 비활성
외부 연동 :: 키를 코드에 둠 || 임시 자격 발급
= 사고가 났을 때 번지는 범위를 미리 좁혀두는 일이다
```

사용자가 수백 명이고 자원이 수천 개면 누가 무엇에 닿을 수 있는지 손으로 관리할 수 없다. 그렇다고 전부에게 모든 권한을 주면, 잘못 누른 삭제 한 번이나 계정 하나의 탈취가 계정 전체의 사고가 된다.

권한을 안 지우는 것도 같은 문제다. 퇴사자 계정이나 끝난 프로젝트의 키가 살아 있으면, 아무도 쓰지 않는 자격 증명이 계속 열려 있는 상태가 된다. IAM은 이 범위를 한곳에서 정하고 회수할 수 있게 만든다.

## ⚙️ 작동 원리

```도해
층: 권한은 어디에 붙어 있나
사용자 :: 사람 하나. 자기 자격 증명을 갖는다
그룹 :: 사용자를 모아 한 번에 권한을 준다
역할 :: 서비스나 외부에 잠깐 빌려주는 자리
정책 :: 무엇을 허용할지 적은 문서. 위에 붙는다
= 권한은 사람이 아니라 정책에 적히고, 그 정책이 사람이나 역할에 붙는다
```

정책에는 누가, 어떤 행동을, 어떤 자원에, 어떤 조건에서 할 수 있는지를 적는다. 조건에는 IP 주소나 MFA 사용 여부 같은 것도 들어간다.

평가에는 순서가 있다. 아무것도 적혀 있지 않으면 기본이 거부고, 명시적인 Deny가 하나라도 걸리면 다른 곳의 Allow와 상관없이 막힌다.

역할은 사용자와 달리 오래 사는 키를 주지 않는다. 서버나 외부 사용자가 역할을 넘겨받으면 만료 시각이 있는 임시 자격 증명이 발급된다.

## 💡 실제 사례

- **읽기 전용 접근** — 분석팀에 특정 저장소의 조회 권한만 주고 업로드와 삭제는 막는다.
- **서버에서 데이터베이스 접근** — 인스턴스에 역할을 붙여 비밀번호를 코드에 두지 않고 임시 자격으로 접속한다.
- **외부 인력 임시 계정** — 계약 기간 동안 해당 프로젝트 자원만 열어두고, 끝나면 자동으로 비활성화한다.

## 🚫 흔한 오해

- **로그인만 되면 접근할 수 있다** — 로그인은 누구인지 확인하는 데까지다. 무엇을 해도 되는지는 그다음 단계에서 따로 본다.
- **분명 Allow를 줬는데 왜 막히지** — 다른 정책에 Deny가 하나라도 있으면 Allow를 몇 개 붙이든 막힌다. 거부가 항상 이긴다.
- **권한은 넉넉히 주고 나중에 줄이면 된다** — 줄이는 일은 대체로 안 일어난다. 무엇을 실제로 쓰는지 알기 어려워서 넓게 준 권한이 그대로 남는다.

## 🚨 주의사항

- **최소 권한에서 시작한다.** 막힌 것을 열어주는 편이 열려 있는 것을 찾아 닫는 것보다 쉽다.
- **쓰지 않는 계정과 키를 남겨두지 않는다.** 오래된 자격 증명은 아무도 안 보는 사이에 남아 있다가 사고의 통로가 된다.

## 📝 정리

IAM은 누가 어떤 자원에 무엇을 할 수 있는지를 한곳에서 정해두는 체계다. 신원 확인과 권한 확인을 나눠서 처리하고, 권한은 정책 문서에 적혀 사용자나 그룹이나 역할에 붙는다.
