# DAC (Data Access Control)

## 📝 정의

DAC는 **데이터 접근을 제어하고 감시**하는 보안 시스템입니다. QueryPie의 핵심 기능입니다.

### 핵심 개념

- **무엇인가?**: 데이터 접근 제어 + 감시
- **왜 필요한가?**: 권한 관리, 감사 로그
- **누가?**: QueryPie가 제공

## 💡 DAC 동작

```
오퍼레이터 → SQL 쿼리 → DAC
                         ↓
                    권한 확인
                         ↓
                  ┌──────┴──────┐
            허용 ✅          차단 ❌
                  │              │
            DB 실행        에러 반환
                  │
            감사 로그 기록
```

## 🔍 보안 3요소

```
1. 인증 (Authentication)
   "당신은 누구?"
   → 사원증 확인

2. 권한 (Authorization) ← DAC!
   "이 데이터 볼 수 있어?"
   → 권한 확인

3. 감사 (Audit)
   "누가 언제 뭘 봤어?"
   → 로그 기록
```

## 📝 정리

**DAC = 데이터 출입 관리**
- 누가: 권한 확인
- 무엇을: 어떤 데이터
- 언제: 감사 로그
