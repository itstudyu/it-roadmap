# Audit Log (감사 로그)

## 📝 정의

Audit Log는 **누가 무엇을 했는지 남기는 기록**이다.

시스템이 잘 돌 때는 볼 일이 없다. 데이터가 사라졌거나 누군가 민감한 정보를 열어봤을 때, 그때 되돌아볼 것이 있느냐 없느냐가 갈린다.

### 비유
건물 출입 기록. 평소에는 아무도 안 보다가 무슨 일이 생기면 그날 누가 들어왔는지부터 뒤진다.

### 예
계정 설정의 로그인 기록에서 가 본 적 없는 도시와 모르는 기기 이름을 발견하는 그 순간이다.

## 🖼️ 그림으로 보기

```도해
흐름: 데이터가 사라졌을 때 감사 로그로 무엇을 알 수 있나
사용자 :: 급여 기록 하나를 삭제한다
서버 :: 요청을 처리하고 결과를 정한다
감사 로그 :: 시각, 계정, 대상, 결과를 함께 적는다
저장소 :: 고칠 수 없는 곳에 쌓아둔다
조사자 :: 계정과 시간으로 걸러 그 줄을 찾는다
= 사고가 난 뒤에는 만들 수 없는 것이라 미리 쌓아둬야 한다
```

## ⚠️ 해결하는 문제

```도해
대조: 기록을 안 남기면 사고 뒤에 무엇이 안 되나
로그 없이 || 감사 로그로
삭제한 사람 :: 알 수 없다 || 계정이 남음
민감 정보 열람 :: 증명 못 함 || 목록 제출
침입 경로 :: 추정만 한다 || 시간순 확인
= 사고 조사는 그때 남아 있는 기록만큼만 할 수 있다
```

중요한 데이터가 사라졌는데 아무 기록이 없으면 누구를 탓할 수도, 재발을 막을 수도 없다. 개인정보를 누가 조회했는지 물어보는 자리에서 기록이 없다고 답하면 그 자체가 문제가 된다.

감사 로그는 정상적으로 처리된 동작까지 남긴다. 사고는 대개 시스템이 고장 나서가 아니라, 권한을 가진 사람이 정상 절차로 무언가를 했을 때 생기기 때문이다.

## ⚙️ 작동 원리

로그 한 줄에 다음이 다 들어가야 나중에 그 줄만 보고도 상황이 복원된다.

| 항목 | 무엇을 적나 |
|---|---|
| 언제 | 요청이 일어난 시각 |
| 누가 | 계정과 접속 주소 |
| 무엇을 | 대상이 된 자원 |
| 어떻게 | 조회, 수정, 삭제 같은 동작 |
| 결과 | 성공인지 거부인지 |

남기는 자리와 지우는 권한을 나눠 둔다. 기록을 만드는 계정이 그 기록을 고칠 수 있으면 증거로서의 값이 사라진다.

## 💡 실제 사례

- **삭제 추적** — 사라진 데이터가 있으면 그 자원에 대한 삭제 기록을 시간순으로 뽑아 누가 언제 했는지 확인한다.
- **개인정보 열람 보고** — 지난달 주민번호를 조회한 계정 목록을 기록 그대로 제출한다.
- **침입 탐지** — 같은 주소에서 로그인 실패가 반복되다가 성공으로 이어지면 대입 공격을 의심한다.

## 🚫 흔한 오해

- **에러 로그가 있으니 감사 로그는 따로 필요 없다** — 에러 로그는 고장 났을 때만 남는다. 감사 로그는 정상적으로 성공한 조회와 삭제를 남기는 것이고, 사고 대부분은 그쪽에서 일어난다.
- **로그를 남겼으면 그걸로 끝이다** — 남긴 사람이 고칠 수 있는 기록은 증거가 되지 못한다. 남기는 권한과 지우는 권한을 나눠야 값이 생긴다.
- **많이 남길수록 좋다** — 조회 하나까지 전부 남기면 양에 묻혀 정작 볼 줄을 못 찾는다. 무엇을 반드시 남길지 먼저 정해야 한다.

## 🚨 주의사항

- **로그에 민감한 값을 그대로 적지 않는다.** 주민번호를 봤다는 사실을 남기려다 주민번호 자체를 로그에 넣으면 유출 지점이 하나 늘어난다.
- **보관 기간을 미리 정한다.** 정해두지 않으면 필요한 순간에 이미 지워져 있거나, 반대로 지울 근거가 없어 계속 쌓인다.
- **기록을 요청 처리와 분리한다.** 로그 저장이 느려질 때 본 기능까지 같이 느려지면 결국 로그를 끄자는 말이 나온다.

## 📝 정리

Audit Log는 언제 누가 무엇을 어떻게 했고 결과가 어땠는지를 남기는 기록이다. 사고가 난 뒤에는 만들어낼 수 없어서 평소에 쌓아두는 것이고, 남긴 사람이 고칠 수 없어야 증거가 된다.

## ❓ 이해했는지

- 에러 로그를 다 갖고 있는데도 데이터를 지운 사람을 못 찾는 이유는 → 흔한 오해
- 로그를 남기는 계정이 그 로그를 지울 수 있으면 무엇이 무너지나 → 작동 원리
- 주민번호를 조회한 기록을 남길 때 조심할 것은 무엇인가 → 주의사항
