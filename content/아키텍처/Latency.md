# Latency (지연 시간)

## 📝 정의

Latency(지연 시간)는 **요청을 보낸 후 응답을 받기까지 걸리는 시간**입니다. 네트워크, 데이터베이스, API 등 모든 시스템에서 중요한 성능 지표입니다.

### 핵심 개념

- **무엇인가?**: 요청 → 응답까지 걸리는 시간
- **왜 중요한가?**: 사용자 경험 직결 (느리면 이탈)
- **어떻게 측정하나?**: 응답 시간 - 요청 시간

### Latency가 해결하는 문제

**문제 상황**:
```
😱 시나리오: API 응답이 느림
사용자: 검색 버튼 클릭
→ 5초 대기
→ 답답함
→ 앱 종료! 😱
```

**Low Latency의 해결**:
```
✅ 빠른 응답:
사용자: 검색 버튼 클릭
→ 0.1초 응답
→ 쾌적한 경험
→ 만족! ✅
```

**비유**:
- **High Latency** = 우편 (며칠 소요)
- **Low Latency** = 전화 (즉시 응답)

## 📊 Latency 기준

| Latency | 사용자 경험 | 예시 |
|---------|------------|------|
| < 100ms | 즉각 반응 | 로컬 작업 |
| < 300ms | 빠름 | 일반 API |
| < 1s | 허용 가능 | 복잡한 검색 |
| > 1s | 느림 | 사용자 이탈 시작 |
| > 3s | 매우 느림 | 대부분 이탈 |
