# Load Balancing (로드 밸런싱)

## 📝 정의

Load Balancing(로드 밸런싱)은 **들어오는 트래픽을 여러 서버에 분산**시켜, 하나의 서버에 과부하가 걸리지 않게 하는 기술입니다.

### 핵심 개념

- **무엇인가?**: 트래픽을 여러 서버에 골고루 분배
- **왜 필요한가?**: 한 서버에 집중되면 느려지거나 다운됨
- **어떻게 작동하나?**: 요청 → 로드 밸런서 → 여유 있는 서버로 분배

### Load Balancing이 해결하는 문제

**문제 상황**:
```
😱 시나리오: 서버 1대만 사용
1000명 동시 접속 → 서버 1대
→ CPU 100%, 응답 느림
→ 서비스 다운! 😱
```

**Load Balancing의 해결**:
```
✅ 서버 5대로 분산:
1000명 접속 → 로드 밸런서
→ 각 서버에 200명씩 분배
→ CPU 20%, 빠른 응답! ✅
```

**비유**:
- **로드 밸런싱 없음** = 계산대 1개 (긴 줄)
- **로드 밸런싱** = 계산대 5개 (짧은 줄)

## 💡 분산 알고리즘

### 1. Round Robin (라운드 로빈)
```
요청1 → 서버1
요청2 → 서버2
요청3 → 서버3
요청4 → 서버1 (처음부터 반복)
```

### 2. Least Connections (최소 연결)
```
서버1: 10개 연결
서버2: 5개 연결 ← 여기로!
서버3: 15개 연결
```

### 3. Weighted (가중치)
```
고성능 서버: 가중치 3 → 60% 트래픽
일반 서버: 가중치 1 → 20% 트래픽
일반 서버: 가중치 1 → 20% 트래픽
```

### 4. IP Hash
```
사용자 IP 해시 → 항상 같은 서버
→ 세션 유지 가능
```
