# CDN (Content Delivery Network)

## 📝 정의

CDN(콘텐츠 전송 네트워크)은 **정적 콘텐츠를 전 세계 엣지 서버에 분산 저장**해서, 사용자와 가까운 곳에서 제공하는 서비스입니다.

### 핵심 개념

- **무엇인가?**: 전 세계에 콘텐츠 복사본을 배치
- **왜 필요한가?**: 멀리 있는 서버는 느림, 가까운 서버는 빠름
- **어떻게 작동하나?**: 사용자와 가장 가까운 서버에서 제공

### CDN이 해결하는 문제

**문제 상황**:
```
😱 시나리오: 미국 서버만 사용
한국 사용자 → 미국 서버
→ 300ms 지연
→ 이미지 로딩 느림! 😱
```

**CDN의 해결**:
```
✅ 한국 엣지 서버 사용:
한국 사용자 → 한국 CDN
→ 20ms 지연
→ 빠른 로딩! ✅
```

**비유**:
- **CDN 없음** = 미국 창고에서 직배송
- **CDN** = 한국 물류센터에서 배송

## 💡 CDN 동작 방식

```
1. 첫 요청:
   사용자 → CDN (없음)
   CDN → 원본 서버 조회
   CDN → 캐시 저장
   CDN → 사용자에게 전달

2. 이후 요청:
   사용자 → CDN (있음!)
   CDN → 즉시 전달 (빠름)
```
