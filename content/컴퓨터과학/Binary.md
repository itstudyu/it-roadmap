# Binary

## 📝 정의

바이너리(Binary)는 0과 1 두 개의 숫자만으로 정보를 표현하는 이진 수 체계입니다. 컴퓨터는 전자 신호를 ON(1) 또는 OFF(0)로만 인식할 수 있으므로, 모든 정보(숫자, 글자, 이미지, 소리)를 궁극적으로 바이너리로 변환하여 저장하고 처리합니다. 바이너리는 컴퓨터의 기본 언어이며, 모든 디지털 정보의 근본을 이루고 있습니다. 우리가 보는 모든 파일, 네트워크 데이터, 프로그램 실행 코드는 사실 내부적으로는 0과 1의 조합입니다.

> **한 줄 요약**: 바이너리는 0과 1로만 이루어진 이진법 데이터로, 컴퓨터의 기본 언어입니다.

### 비유
- 🔵 **전등 스위치**: 켜짐(1)과 꺼짐(0)으로만 상태를 나타내는 것처럼, 컴퓨터도 전기 신호의 ON/OFF로 모든 정보를 표현합니다.
- 🟡 **모스부호**: 점(·)과 대시(-)의 조합으로 문자를 표현하듯이, 바이너리는 0과 1의 조합으로 모든 정보를 표현합니다.

## 🎯 핵심 개념

### 1. 비트(Bit)와 바이트(Byte)
비트(Bit)는 바이너리 정보의 최소 단위로, 0 또는 1의 값을 가질 수 있습니다. 8개의 비트가 모여 하나의 바이트(Byte)를 이루며, 바이트는 컴퓨터에서 실무적으로 가장 작은 주소 단위입니다. 예를 들어 1바이트는 00000000부터 11111111까지 256가지 값을 표현할 수 있으며, ASCII 문자 인코딩에서는 1바이트로 하나의 문자를 표현합니다. 파일 크기는 킬로바이트(KB), 메가바이트(MB), 기가바이트(GB) 같은 바이트의 배수로 표현됩니다.

### 2. 이진수 변환
10진수를 바이너리로 변환하는 것은 2로 계속 나누는 과정입니다. 예를 들어 10진수 5는 이진수로 101 (1×2² + 0×2¹ + 1×2⁰ = 5)입니다. 반대로 바이너리 101을 10진수로 변환하려면 각 자리의 가중치를 계산하여 더합니다. 컴퓨터 내부에서는 모든 계산과 데이터 처리가 바이너리로 이루어지지만, 사용자 인터페이스에서는 10진수나 다른 진법(16진수)으로 표시하여 가독성을 높입니다.

### 3. 전기 신호로의 구현
컴퓨터의 트랜지스터는 전압 상태로 0(낮은 전압)과 1(높은 전압)을 구분합니다. 메모리, CPU, 저장 장치의 모든 전자 부품은 이 기본 원리를 기반으로 작동합니다. 예를 들어 RAM의 각 메모리 셀은 트랜지스터와 커패시터로 이루어져 있고, 충전 상태(1)와 방전 상태(0)로 정보를 저장합니다. 이 방식은 빠르고 안정적이므로 디지털 컴퓨터의 기본 원리로 채택되었습니다.

## ⚠️ 해결하는 문제

### 문제 1: 보편적인 정보 표현
다양한 종류의 정보(숫자, 문자, 이미지, 소리)를 모두 하나의 형식으로 표현해야 합니다. 바이너리는 모든 정보를 0과 1로 단순화하므로, 어떤 종류의 데이터든 일관되게 저장하고 처리할 수 있습니다. 이는 컴퓨터가 다양한 작업을 통합적으로 수행할 수 있는 기반이 됩니다.

### 문제 2: 전자 회로의 물리적 구현
전자 회로는 전기의 ON/OFF 상태만을 명확하게 구분할 수 있습니다. 만약 10진수 같은 복잡한 진법을 사용한다면, 10개의 서로 다른 전압 수준을 정확히 구분해야 하므로 회로가 복잡하고 오류가 잦을 것입니다. 바이너리는 2개의 상태만 필요하므로 회로를 간단하고 신뢰할 수 있게 만들 수 있습니다.

### 문제 3: 오류 감지 및 수정
바이너리 데이터는 단순한 구조이므로 오류 감지 및 수정 코드(예: 패리티 비트, 해밍 코드)를 쉽게 적용할 수 있습니다. 네트워크 전송, 저장 매체의 오류로 인해 데이터가 손상될 때, 바이너리의 특성을 이용해 오류를 감지하고 복구할 수 있습니다.

## ⚙️ 작동 원리

컴퓨터의 모든 정보는 바이너리로 저장되고 처리됩니다. 사용자가 텍스트를 입력하면 각 문자가 ASCII 또는 UTF-8 같은 인코딩을 통해 바이너리 값으로 변환됩니다. 예를 들어 문자 'A'는 ASCII 65이고, 이는 바이너리로 01000001입니다. 이 바이너리 값이 메모리의 특정 위치에 저장되고, 필요할 때 다시 읽어서 화면에 'A'로 표시합니다. 이미지도 마찬가지로 각 픽셀의 색상(RGB 값)이 바이너리로 인코딩되어 저장되고, CPU가 계산을 수행할 때는 모든 숫자를 바이너리로 변환한 후 연산합니다. 네트워크를 통해 데이터를 전송할 때도 바이너리 형태로 패킷화되어 전송됩니다. 이 모든 과정이 투명하게 이루어지므로 사용자는 바이너리를 의식하지 않고 10진수나 문자로 생각하면서 컴퓨터를 사용할 수 있습니다.

## 📊 비교

| 항목 | 이진법 Binary | 10진법 Decimal | 16진법 Hexadecimal |
|------|-------------|--------------|------------------|
| **사용 숫자** | 0, 1 (2개) | 0-9 (10개) | 0-9, A-F (16개) |
| **기수** | 2 | 10 | 16 |
| **컴퓨터 친화도** | 매우 높음 (하드웨어 기반) | 낮음 (인간 중심) | 높음 (이진수 축약) |
| **표기 예** | 1010 | 10 | A |
| **사용처** | 메모리, 저장소, 논리회로 | 일상 계산, 인간 인터페이스 | 메모리 주소, 색상 코드 |
| **가독성** | 낮음 (자릿수 많음) | 높음 | 중간 (이진수보다 짧음) |
| **계산 복잡도** | 간단 (ON/OFF만) | 중간 | 낮음 |
| **변환 용이성** | 16진수와 직접 변환 가능 | 이진수로 변환 필요 | 이진수와 직접 변환 가능 |

## ✅ 장단점

### 장점
- **하드웨어 구현 용이**: 전자 회로의 ON/OFF 상태와 직접 대응되므로 구현이 간단합니다.
- **오류 감지 용이**: 단순한 구조로 오류를 감지하고 수정하기 쉽습니다.
- **보편적 표준**: 모든 컴퓨터가 바이너리를 기반으로 작동하므로 호환성이 완벽합니다.
- **안정적 신호 전달**: 0과 1만 구분하면 되므로 신호 간섭에 강합니다.
- **빠른 처리**: 단순한 구조로 인해 처리 속도가 빠릅니다.

### 단점
- **인간이 읽기 어려움**: 자릿수가 많아서 가독성이 떨어집니다 (예: 0101110101010).
- **큰 데이터 용량**: 같은 정보를 표현하는데 다른 진법보다 더 많은 자리가 필요합니다.
- **변환 과정 필요**: 사람이 이해하려면 10진수로 변환해야 합니다.

## 💡 실제 사례

### 이미지 파일의 바이너리 표현
PNG 이미지 파일은 바이너리 파일입니다. 파일 내부에는 이미지의 각 픽셀 정보가 바이너리로 저장되어 있으며, 색상 정보도 RGB 각각을 0-255의 숫자로 표현한 후 바이너리로 인코딩합니다. 예를 들어 빨강색(RGB 255, 0, 0)은 바이너리로 11111111 00000000 00000000입니다. 수백만 개 픽셀의 색상 정보가 모두 바이너리로 압축되어 저장되므로, 이미지 편집 프로그램이 이를 읽어 화면에 표시할 수 있습니다.

### 네트워크 패킷 전송
인터넷을 통해 데이터를 전송할 때, 모든 정보는 바이너리 패킷으로 변환됩니다. 웹 페이지의 HTML 텍스트, 이미지, 동영상 모두 바이너리로 변환되어 패킷에 담겨 전송되고, 수신 컴퓨터가 이를 다시 해석하여 보여줍니다. 실시간 화상 통화도 음성과 영상을 바이너리로 인코딩하여 패킷으로 전송하고, 수신측이 바이너리를 다시 소리와 영상으로 복원합니다.

## 🔗 관련 용어

- **비트 (Bit)**: 바이너리의 최소 단위로, 0 또는 1의 값을 가집니다.
- **바이트 (Byte)**: 8비트로 이루어진 정보 저장 단위입니다.
- **16진법 (Hexadecimal)**: 바이너리를 더 간결하게 표현하기 위한 진법으로, 4비트를 1자리 16진수로 표현합니다.
- **인코딩 (Encoding)**: 정보를 바이너리로 변환하는 과정입니다 (예: ASCII, UTF-8).
- **논리회로 (Logic Circuit)**: 0과 1의 입력과 출력으로 작동하는 전자 회로입니다.
