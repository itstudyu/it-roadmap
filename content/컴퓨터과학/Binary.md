# Binary (이진법)

## 📝 정의

Binary는 **0과 1 두 기호만으로 값을 적는 방식**이다.

컴퓨터의 부품은 전압이 높은지 낮은지만 구분한다. 그래서 숫자든 글자든 그림이든 결국 두 값의 나열로 바꿔서 저장하고 계산한다.

### 비유
전등 스위치. 하나로는 켜짐과 꺼짐 둘뿐이지만, 여덟 개를 나란히 놓으면 그 조합이 256가지가 된다.

## 🖼️ 그림으로 보기

```도해
흐름: 글자 A 는 어떻게 0 과 1 이 되나
글자 A :: 키보드로 입력한다
약속표 :: ASCII 에서 A 는 65 번이라고 정해져 있다
변환 :: 65 를 2 로 나눠 가며 01000001 로 바꾼다
메모리 :: 여덟 칸에 전압 높낮이로 저장한다
< 화면 :: 다시 읽어 약속표를 거꾸로 뒤져 A 로 그린다
= 컴퓨터 안에 글자 A 는 없다. 65 번이라는 약속이 있을 뿐이다
```

## ⚠️ 해결하는 문제

```도해
대조: 전자 회로가 10 진수를 쓰면 어떻게 되나
10 단계로 || 2 단계로
전압 판단 :: 열 단계를 잰다 || 높다 낮다뿐
잡음 :: 조금만 흔들려도 || 웬만하면 버틴다
회로 :: 복잡하고 비싸다 || 단순하다
= 값의 종류를 줄이는 대신 자릿수를 늘려 안정성을 산 것이다
```

전선에 흐르는 전압은 온도나 간섭으로 늘 조금씩 흔들린다. 0부터 9까지를 열 개의 전압 단계로 구분하려면 그 흔들림 안에서 단계가 서로 섞인다. 두 단계만 나누면 한참 흔들려도 어느 쪽인지 헷갈리지 않는다.

이 단순함은 다른 데서도 값을 한다. 값이 두 가지뿐이라 전송 중에 뒤집힌 자리를 찾아내는 검사 방식을 만들기 쉽고, 어떤 종류의 데이터든 같은 방식으로 저장하고 옮길 수 있다.

## ⚙️ 작동 원리

각 자리는 오른쪽부터 1, 2, 4, 8배씩 커진다. `101`은 4 더하기 1이라서 5다. 반대로 10진수를 2로 계속 나누고 나머지를 거꾸로 읽으면 이진수가 나온다.

```도해
층: 0 과 1 은 어떤 단위로 묶이나
비트 :: 0 이나 1 하나. 가장 작은 단위
바이트 :: 비트 여덟 개. 256 가지를 나타낸다
문자 :: 영문은 한 바이트, 한글은 UTF-8 에서 세 바이트
파일 :: 바이트가 줄줄이 이어진 것
= 아래로 갈수록 우리가 이름 붙여 쓰는 단위고 위로 갈수록 회로에 가깝다
```

16진법을 자주 쓰는 이유도 여기 있다. 16진수 한 자리가 정확히 비트 네 개라서, 이진수를 네 자리씩 끊어 읽으면 그대로 바뀐다.

## 💡 실제 사례

- **이미지 색** — 빨강은 빨강 255, 초록 0, 파랑 0이고 저장될 때는 `11111111 00000000 00000000`이 된다.
- **파일 크기** — 킬로바이트, 메가바이트는 바이트를 묶어 센 것이다. 같은 글이라도 한글이 많으면 바이트 수가 더 나온다.
- **네트워크 전송** — 텍스트든 영상이든 보내기 전에 비트 나열로 바뀌고, 받는 쪽이 같은 약속으로 되돌린다.

## 🚫 흔한 오해

- **바이너리 파일은 사람이 못 읽는 특별한 형식이다** — 특별한 형식이 아니다. 모든 파일이 0과 1이고, 텍스트 파일은 그 값을 글자 약속표로 해석하기로 정해둔 것뿐이다.
- **1바이트는 항상 한 글자다** — 영문은 그렇지만 한글은 UTF-8에서 세 바이트를 쓴다. 글자 수와 바이트 수는 같지 않다.
- **컴퓨터가 0과 1을 쓰는 건 그게 빨라서다** — 속도가 아니라 구분 때문이다. 전압을 두 단계만 나누면 신호가 흔들려도 어느 쪽인지 틀리지 않는다.

## 📊 비교

| | 2진법 | 10진법 | 16진법 |
|---|---|---|---|
| 쓰는 기호 | 0, 1 | 0~9 | 0~9, A~F |
| 10을 적으면 | 1010 | 10 | A |
| 어디에 쓰나 | 회로, 저장 | 사람이 읽는 곳 | 메모리 주소, 색상 코드 |
| 이진수 변환 | 그 자체 | 나눗셈이 필요 | 네 자리씩 그대로 |

## 📝 정리

Binary는 값을 두 기호로만 적는 방식이고, 컴퓨터가 이걸 쓰는 이유는 전압을 두 단계로 나누면 틀릴 일이 적기 때문이다. 글자든 그림이든 약속표를 거쳐 비트 나열이 되고, 읽을 때 같은 약속으로 되돌린다.

## ❓ 이해했는지

- 같은 글자 수인데 한글 문서가 영문 문서보다 파일이 큰 이유는 → 작동 원리
- 회로가 10진수 대신 2진수를 쓰는 이유를 전압으로 설명하면 → 해결하는 문제
- 이미지 파일과 텍스트 파일은 저장되는 형태가 무엇이 다른가 → 흔한 오해
