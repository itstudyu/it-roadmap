# Big O 표기법 (Big O Notation)

## 📝 정의

Big O는 **데이터가 늘어날 때 시간이 얼마나 늘어나는지 적는 표기**다.

지금 몇 초 걸리는지가 아니라, 데이터가 열 배가 되면 시간이 몇 배가 되는지를 말한다. 컴퓨터 성능이 달라도 이 관계는 바뀌지 않기 때문에 비교 기준이 된다.

### 이름
Big :: 크게 볼 때
O :: 차수(Ordnung)
Notation :: 적는 법
= 붙여 읽으면 "크게 봤을 때의 차수를 적는 법". 잔가지를 버리고 늘어나는 모양만 남긴다

### 비유
연비 표기. "지금 기름이 얼마 남았나"가 아니라 "1리터로 몇 킬로 가나"다. 차에 짐을 더 실었을 때 어떻게 되는지를 알려준다.

### 예
사진 백 장일 때는 잘 열리던 앨범 앱이 오천 장이 되자 열 때마다 한참 멈춰 있는 그 차이다.

### 직접
사진첩에서 최근 백 장짜리 앨범과 전체 사진을 차례로 열어 보라. 뜨는 시간이 장수에 따라 어떻게 달라지는지가 이 표기가 재는 것이다.

## 🖼️ 그림으로 보기

```도해
층: 데이터가 100배로 늘면 시간은 몇 배가 되나
O(1) :: 그대로. 몇 개든 상관없다
O(log n) :: 거의 그대로. 단계가 일곱쯤 늘 뿐이다
O(n) :: 100배. 전부 한 번씩 훑는 것
O(n log n) :: 100배를 조금 넘는다. 좋은 정렬
O(n²) :: 10,000배. 이중 반복문
= 아래로 내려갈수록 데이터가 늘 때 무너진다
```

## ⚠️ 해결하는 문제

```도해
대조: 두 코드 중 무엇이 빠른지 어떻게 아나
실행 시간 재기 || Big O
컴퓨터가 다르면 :: 결과가 달라진다 || 그대로다
데이터가 100배면 :: 다시 재야 안다 || 계산으로 안다
비교 :: 같은 환경 필요 || 코드만 보면 된다
= 지금 빠른 것과 커져도 버티는 것은 다른 질문이다
```

데이터 100건으로 재면 대부분의 코드가 빠르다. 문제는 100만 건이 됐을 때다. O(n)짜리는 1만 배 느려지고 O(n²)짜리는 1억 배 느려진다. 처음에는 둘 다 괜찮아 보였는데 하나만 무너진다.

Big O는 그 차이를 미리 알려준다. 실행해보지 않고도 어느 쪽이 커졌을 때 살아남는지 판단할 수 있다.

## ⚙️ 작동 원리

두 가지를 버린다. 상수와 낮은 차수다.

```
2n + 100  →  O(n)        상수 2와 100 을 버린다
n² + n    →  O(n²)       n 은 n² 에 묻힌다
```

버리는 이유는 n이 커질수록 그것들이 무의미해지기 때문이다. n이 백만이면 n²과 n의 차이가 압도적이라 뒤의 n은 없는 것과 같다.

같은 이유로 **작은 데이터에서는 Big O가 틀린 답을 준다.** O(n²)인 삽입 정렬이 항목 20개에서는 O(n log n)인 퀵 정렬보다 빠르다. 상수가 작기 때문이고, 실제 정렬 라이브러리들이 작은 구간에서 삽입 정렬로 갈아타는 이유다.

## 💡 실제 사례

- **자료구조 선택** — 배열에서 값 찾기는 O(n), 해시 테이블은 O(1)이다. 조회가 많으면 답이 정해진다.
- **중첩 반복문 발견** — 반복문 안의 반복문은 O(n²)이다. 코드 리뷰에서 가장 먼저 보는 신호다.
- **인덱스** — DB 인덱스는 전체 훑기 O(n)을 O(log n)으로 바꾸는 장치다.

## 🚫 흔한 오해

- **O(1)이 항상 O(n)보다 빠르다** — 데이터가 작으면 상수가 큰 O(1)이 더 느릴 수 있다. Big O는 커졌을 때의 이야기다.
- **Big O는 실행 시간이다** — 시간이 아니라 증가율이다. 초 단위 값을 알려주지 않는다.
- **최악의 경우만 뜻한다** — 보통 최악을 적지만 평균과 최선이 다른 경우도 있다. 해시는 평균 O(1), 최악 O(n)이다.

## 🚨 주의사항

- **작은 데이터에서 성급하게 최적화하지 않는다.** 항목 50개짜리 목록을 O(n²)에서 O(n log n)으로 바꾸는 데 쓰는 시간이 아깝다.
- **메모리도 같이 본다.** 시간을 줄이려고 O(n) 메모리를 더 쓰는 거래가 흔하다. 어느 쪽이 부족한지 먼저 확인한다.

## 📝 정리

**"커지면 무엇이 무너지는지 적는 그 표기"** 라고 읽으면 된다. 지금 몇 초 걸리는지가 아니라 데이터가 열 배가 될 때 몇 배가 되는지를 말하고, 상수를 버리기 때문에 작은 데이터에서는 오히려 맞지 않는다.

## 🧒 열 살에게

자동차 광고에 "기름 1리터로 15킬로" 라고 적혀 있지? 그건 지금 기름통에 얼마 남았느냐가 아니라, 갈 길이 두 배로 멀어지면 기름도 두 배가 든다는 걸 알려주는 숫자야. 그래서 아직 출발도 안 했는데 서울에서 부산까지 이 차로 갈 수 있는지 없는지를 미리 계산할 수 있어.

## ❓ 이해했는지

- O(n²) 코드가 O(n log n) 코드보다 빠를 수 있는 상황은 → 작동 원리
- 반복문 안에 반복문을 보면 왜 먼저 의심하나 → 실제 사례
- 데이터가 100배로 늘 때 O(n²)은 몇 배가 되나 → 그림
