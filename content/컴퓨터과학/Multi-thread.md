# Multi-thread (멀티 스레드)

## 📝 정의

Multi-thread는 **한 프로그램 안에서 일을 여러 갈래로 나눠 돌리는 방식**이다.

갈래 하나가 무언가를 기다리는 동안 다른 갈래가 자기 일을 이어간다. 같은 프로그램 안이라 메모리를 함께 쓰고, 그래서 서로의 값을 건드릴 수도 있다.

### 비유
주방의 요리사 여러 명. 한 사람이 물이 끓기를 기다리는 동안 다른 사람이 재료를 썬다. 다만 도마가 하나면 둘이 동시에 쓰려다 부딪힌다.

## 🖼️ 그림으로 보기

```도해
흐름: 파일 다섯 개를 받을 때 갈래를 나누면 무엇이 달라지나
한 갈래로 :: 첫 파일이 끝날 때까지 기다린다
한 갈래로 :: 다 받으면 그때 다음 파일을 시작한다
여러 갈래로 :: 다섯 개를 한꺼번에 시작한다
기다림 :: 각 갈래는 응답을 기다리며 멈춰 있다
< 결과 :: 전체 시간이 가장 느린 하나로 줄어든다
= 기다리는 시간이 겹쳐지는 만큼 빨라진다
```

## ⚠️ 해결하는 문제

```도해
대조: 요청을 하나씩 처리하면 어떻게 되나
한 갈래 || 여러 갈래
두 번째 손님 :: 앞이 끝나야 || 바로 시작
기다리는 동안 :: 아무것도 못 함 || 다른 일을 함
화면 :: 멈춰 보인다 || 계속 움직인다
= 기다림이 많은 일일수록 나눠 돌리는 값이 커진다
```

한 갈래로만 도는 서버는 앞선 요청이 끝나야 다음 요청을 본다. 그 요청이 데이터베이스 응답을 5초 기다리는 중이라면 뒤에 온 사람들도 그 5초를 함께 기다린다. 실제로 계산하는 시간은 얼마 안 되는데 기다리느라 줄이 선다.

갈래를 나누면 그 기다림이 서로 겹친다. 한 갈래가 응답을 기다리며 멈춰 있는 동안 다른 갈래가 자기 일을 진행하기 때문이다. 파일을 받거나 외부 API를 부르는 것처럼 대기가 대부분인 일에서 차이가 크다.

## ⚙️ 작동 원리

스레드들은 같은 메모리를 함께 쓴다. 프로세스를 여러 개 띄우는 것보다 만들고 오가는 비용이 싼 이유이자, 가장 조심해야 할 지점이기도 하다.

두 갈래가 같은 값을 동시에 고치면 결과가 어긋난다. 하나가 읽어서 1을 더하는 사이 다른 하나가 같은 옛 값을 읽으면, 두 번 더했는데 한 번만 올라간다. 그래서 함께 쓰는 값에는 자물쇠를 걸어 한 번에 하나만 손대게 한다.

자물쇠를 많이 걸면 이번에는 서로 기다리느라 느려진다. 나눠서 얻는 이득과 맞물려 잃는 시간이 어디서 뒤집히는지를 가늠하는 것이 설계다.

## 💡 실제 사례

- **웹 서버** 들어온 요청마다 갈래를 하나씩 맡겨 여러 사람을 동시에 응대한다.
- **여러 곳에서 자료 모으기** 사용자 정보, 게시물, 댓글을 각각 다른 갈래로 요청하면 전체 시간이 가장 느린 하나로 줄어든다.
- **화면이 멈추지 않게 하기** 오래 걸리는 작업을 다른 갈래로 보내면 그동안에도 버튼이 눌린다.

## 📊 비교: 어디에 맞고 어디에 안 맞나

| 일의 종류 | 갈래를 나누면 | 이유 |
|---|---|---|
| 파일 받기, 외부 호출 | 크게 빨라진다 | 대부분이 기다리는 시간이라 겹칠 수 있다 |
| 화면 응답 유지 | 도움이 된다 | 오래 걸리는 일을 뒤로 보낼 수 있다 |
| 무거운 계산 | 거의 안 빨라진다 | 계산은 겹칠 수 없고, 한 번에 한 갈래만 코드를 돌리게 막는 언어도 있다 |

## 🚫 흔한 오해

- **스레드를 늘릴수록 빨라진다** — 갈래를 만들고 번갈아 도는 데도 비용이 든다. 어느 지점을 넘으면 전환하느라 쓰는 시간이 늘어 오히려 느려진다.
- **여러 스레드는 진짜로 동시에 돈다** — 코어가 하나면 아주 빠르게 번갈아 도는 것이다. 실제로 겹치는 것은 계산이 아니라 기다리는 시간이다.
- **계산이 오래 걸리니 스레드로 나누면 되겠다** — 기다림이 아니라 계산이 오래 걸리는 일은 나눠도 잘 안 줄어든다. 파이썬처럼 한 번에 한 갈래만 코드를 돌리게 막는 언어에서는 더 그렇다.

## 🚨 주의사항

- **함께 쓰는 값에는 자물쇠를 건다.** 두 갈래가 같은 값을 동시에 고치면 결과가 어긋나고, 이런 오류는 매번 재현되지도 않아 찾기 어렵다.
- **기다릴 시간을 정해둔다.** 응답이 영영 오지 않는 갈래가 있으면 그 자리가 계속 잡혀 있다.

## 📝 정리

Multi-thread는 한 프로그램 안에서 일을 여러 갈래로 나눠 돌리는 방식이다. 기다리는 시간이 겹쳐지는 만큼 빨라지므로 파일 전송이나 외부 호출처럼 대기가 긴 일에 맞는다. 같은 메모리를 함께 쓰기 때문에 공유하는 값은 따로 지켜줘야 한다.
