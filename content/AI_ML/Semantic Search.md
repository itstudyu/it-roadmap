# Semantic Search (의미 검색)

## 📝 정의

Semantic Search는 **단어가 달라도 의미만 비슷하면 찾아주는** 검색입니다. 마치 "육아휴직"을 검색했는데 "양육휴가", "아이 키우기 위한 휴가"도 찾아주는 똑똑한 검색입니다.

### 핵심 개념

- **무엇인가?**: 의미 기반 검색 (단어 매칭이 아닌 뜻 매칭)
- **왜 필요한가?**: 같은 뜻을 다르게 표현해도 찾을 수 있게
- **어떻게 작동하나?**: Embedding으로 의미를 숫자로 바꿔서 비교

## 🤔 왜 Semantic Search가 필요한가?

### 키워드 검색의 한계

**문제 1: 동의어를 모름**
```
사용자: "급여일이 언제죠?"
키워드 검색: ["급여일" 단어 찾기]

문서1: "급여는 매월 25일에 지급합니다" → 못 찾음! ❌
문서2: "임금 지급일은 25일입니다" → 못 찾음! ❌
문서3: "급여일은 25일입니다" → 찾음! ✅

문제: "급여일"이라는 정확한 단어가 있어야만 찾음
```

**문제 2: 다양한 표현을 이해 못함**
```
사용자: "아이 키우려고 쉬고 싶은데요"
키워드 검색: ["아이", "키우다", "쉬다" 찾기]

문서: "육아휴직 규정 - 제32조" → 못 찾음! ❌

문제: "육아휴직"이라는 단어가 질문에 없음
```

**문제 3: 오타에 취약**
```
사용자: "육아휴지" (오타)
키워드 검색: ["육아휴지" 찾기] → 0건 ❌
```

### Semantic Search의 해결

```
사용자: "급여일이 언제죠?"
Semantic Search: [의미 이해]
→ "급여", "임금", "지급일" 모두 비슷한 의미
→ 관련 문서 모두 찾음! ✅

문서1: "급여는 25일" ✅ (유사도: 0.92)
문서2: "임금 지급일은 25일" ✅ (유사도: 0.89)
문서3: "월급 날짜" ✅ (유사도: 0.85)
```

### 전체 흐름


### 단계별 설명

**1단계: 질문을 숫자로**
```
"급여일은?" → Embedding → [0.2, 0.8, 0.5, ...]
(의미를 벡터로 표현)
```

**2단계: 문서들도 숫자로**
```
"급여는 25일" → [0.3, 0.7, 0.6, ...]
"임금 지급일" → [0.2, 0.8, 0.4, ...]
"회의는 월요일" → [0.9, 0.1, 0.2, ...]
```

**3단계: 거리 계산**
```
질문 ↔ 문서1: 거리 0.08 → 유사도 0.92 (매우 가까움!) ✅
질문 ↔ 문서2: 거리 0.11 → 유사도 0.89 (가까움!) ✅
질문 ↔ 문서3: 거리 0.85 → 유사도 0.15 (멀음) ❌
```

**4단계: 결과 반환**
```
Top-2:
1. "급여는 25일" (0.92)
2. "임금 지급일은 25일" (0.89)
```

## 💡 일상적 비유로 이해하기

### Semantic Search = 의미로 길 찾기

**키워드 검색 (내비게이션)**:
```
"강남역 3번 출구"라고 정확히 말해야 찾음
"강남역 세번째 나가는 곳" → 못 찾음 ❌
```

**Semantic Search (사람에게 물어보기)**:
```
"강남역에서 나가는 곳 찾아줘"
→ "3번 출구 말씀하시는 거죠?" ✅
→ 의미를 이해하고 찾아줌!
```

## 🔍 Semantic Search vs Keyword Search

### 비교표

| 특성 | Keyword Search | Semantic Search |
|------|----------------|-----------------|
| 검색 방식 | 단어 매칭 | 의미 매칭 |
| 동의어 인식 | ❌ | ✅ |
| 오타 허용 | ❌ | ✅ (어느 정도) |
| 자연어 이해 | ❌ | ✅ |
| 속도 | 매우 빠름 | 빠름 |
| 정확도 | 낮음 | 높음 |
| 구현 복잡도 | 낮음 | 중간 |
| 비용 | 거의 없음 | 중간 (Vector DB) |

### 언제 뭘 쓸까?

```
Keyword Search 적합:
- 정확한 단어로 검색 ("제32조")
- 코드 검색 (함수명, 변수명)
- 속도가 최우선

Semantic Search 적합:
- 자연어 질문 ("아이 키우려면?")
- 다양한 표현 허용 필요
- 정확도가 중요

P3 권장: Hybrid
→ 70% Semantic + 30% Keyword
→ 정확도와 속도 모두 잡기
```

## 🚀 Semantic Search 최적화

### P3의 Hybrid Search

```
질문: "급여일은?"

1차: Semantic Search (의미)
→ "급여일", "임금 지급일", "월급 날짜" 찾음

2차: Keyword Boost (키워드)
→ "급여일" 정확히 포함된 문서 점수 +30%

최종 결과: 의미도 맞고 단어도 정확한 문서 우선
→ 최고의 검색 품질!
```

### 임계값 설정

```
유사도 0.7 이상: 매우 관련 있음 ✅
유사도 0.5~0.7: 관련 있음 ⚠️
유사도 0.5 이하: 관련 없음 ❌

P3 설정:
→ 0.7 이상만 사용자에게 보여줌
→ Hallucination 방지
```

## 📝 정리

**Semantic Search 핵심 3줄**:
```
1. 단어가 달라도 의미만 비슷하면 찾음
2. Embedding으로 의미를 숫자로 바꿔서 비교
3. RAG의 핵심 = 똑똑한 검색

→ P3 없으면 사용자 만족도 60점
→ P3 있으면 95점!
```

**비유로 기억하기**:
```
Keyword Search = 도서관에서 제목만 보고 찾기
→ "육아휴직"이라는 제목만 찾음

Semantic Search = 사서에게 물어보기
→ "아이 키우기 위한 책" → "아, 육아휴직 책 말씀이시죠?"
→ 의미를 이해하고 찾아줌!
```

**Semantic Search 공식**:
```
질문 Embedding → Vector DB 검색 → 유사 문서 발견

핵심 = Embedding
→ 의미를 숫자로 바꾸는 마법
→ 비슷한 의미 = 비슷한 숫자
→ 거리 계산으로 유사도 측정
```
