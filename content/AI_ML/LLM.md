# LLM (Large Language Model)

## 📝 정의

LLM은 **엄청나게 많은 텍스트를 읽고 학습한 AI**입니다. 마치 수백만 권의 책을 읽은 사람처럼, 거의 모든 주제에 대해 대화하고 글을 쓸 수 있습니다.

### 핵심 개념

- **무엇인가?**: 수십억~수조 개의 연결(파라미터)을 가진 거대 AI 모델
- **왜 필요한가?**: 사람처럼 자연스럽게 대화하고, 다양한 작업을 수행하기 위해
- **어떻게 작동하나?**: 다음에 올 단어를 예측하는 방식으로 학습

## 🤔 왜 LLM이 필요한가?

### 기존 AI의 한계

**규칙 기반 챗봇 (2010년대)**:
```
사용자: "육아휴직 신청하려면?"
봇: [정확히 "육아휴직" 단어 찾기]
→ "육아휴직 규정을 찾았습니다" ✅

사용자: "아이 키우려고 쉬고 싶은데?"
봇: [단어 매칭 실패]
→ "무슨 말인지 모르겠습니다" ❌

문제: 같은 의미를 다르게 표현하면 이해 못함
```

**도메인 특화 AI (2020년 이전)**:
```
번역 AI: 번역만 가능
요약 AI: 요약만 가능
감정 분석 AI: 감정만 분석

→ 각 작업마다 AI를 따로 만들어야 함
→ 새 작업이 생기면? 처음부터 다시 학습
```

### LLM의 혁신

```
하나의 모델로 모든 작업:
- 번역 ✅
- 요약 ✅
- 코딩 ✅
- 분석 ✅
- 대화 ✅
- 글쓰기 ✅

게다가 문맥도 이해:
"그는 돈이 필요해서 은행에 갔다"
→ 금융기관이라고 이해!

"그는 물고기를 잡으려고 은행에 갔다"
→ 강가라고 이해!
```

## 📊 LLM 작동 원리

### 1. 학습 과정


**학습 방식**: 다음 단어 맞히기
```
입력: "날씨가 좋으니 공원에"
LLM 예측: "가자" (90%), "갑시다" (5%), "가요" (3%)...

수조 번 반복하면서 패턴 학습
→ 문법, 의미, 상식 등을 자연스럽게 이해
```

### 2. 사용 과정

```도해
흐름: LLM, 무슨 순서로 오가나
사용자 :: 육아휴직은 몇 년?
LLM :: 일반적으로 1-2년입니다...
```

## 💡 일상적 비유로 이해하기

### LLM = 엄청나게 많이 읽은 사람

```
일반인:
- 책 100권 읽음
- 특정 분야만 알음
- 새로운 주제는 어려움

LLM:
- 인터넷의 절반을 읽음 (수백억 페이지)
- 거의 모든 분야 알음
- 새로운 질문에도 답변 가능

하지만:
- 2023년 이후 일은 모름 (학습 종료일 기준)
- 가끔 착각함 (Hallucination)
- 계산은 약함
```

### LLM의 강점과 약점

| 강점 ✅ | 약점 ❌ |
|--------|--------|
| 자연스러운 대화 | 최신 정보 모름 |
| 다양한 작업 수행 | 가끔 거짓말 (Hallucination) |
| 문맥 이해 능력 | 정확한 계산 약함 |
| 창의적 글쓰기 | 회사별 정보 모름 |

## 🎯 P3 시스템에서의 활용

### P3는 LLM을 어떻게 사용하나?


**핵심**: LLM 단독으로는 회사 규정을 모름
→ RAG로 문서를 찾아서 LLM에게 전달
→ LLM이 문서를 읽고 답변 생성

### 주요 LLM 비교


**P3 권장**:
- 메인: GPT-4 (정확도 최우선)
- 백업: Claude 3.5 (긴 문서 처리)
- 개발: 로컬 Llama (비용 0)

## 🚨 주의사항

### 1. Hallucination (거짓말)

```
문제: LLM이 없는 정보를 지어냄

예시:
Q: "제40조는?"
A: "제40조는 퇴직금에 관한 규정입니다..."
→ 실제로는 제40조가 없음!

해결: RAG 사용
→ 문서에 있는 내용만 참고하도록
```

### 2. 최신 정보 모름

```
GPT-4: 2023년 10월까지 학습
Claude 3.5: 2024년 4월까지 학습

2026년 정보는?
→ 모름!

해결: RAG로 최신 문서 제공
```

### 3. 비용

```
GPT-4: $0.03 / 1,000 tokens (입력)

P3에서 월 10만 건 질문:
→ 약 $3,000/월

절감 방법:
1. 캐싱 (70% 절감)
2. 프롬프트 최적화 (30% 절감)
3. GPT-3.5 혼용 (80% 절감)
```

## 📝 정리

**LLM 핵심 3줄 요약**:
```
1. 엄청나게 많이 읽은 AI (수백억 페이지)
2. 사람처럼 대화하고, 다양한 작업 수행
3. 하지만 최신 정보는 모르고, 가끔 착각함

→ RAG와 함께 사용하면 완벽!
```

**비유로 기억하기**:
```
LLM = 백과사전을 통째로 외운 사람
→ 거의 모든 것을 알지만
→ 2023년 이후는 모름
→ 가끔 기억 착각 (Hallucination)

RAG = 백과사전 + 도서관 사서
→ 최신 책도 찾아줌
→ 정확한 출처 제공
→ 착각 방지
```
