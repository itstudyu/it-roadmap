# Reranking (재순위화)

## 📝 정의

Reranking은 **RAG 검색 결과를 더 정밀한 모델로 재평가**하여 순위를 다시 매기는 기법입니다.

### 핵심 개념

- **무엇인가?**: 검색 결과 재정렬
- **왜 필요한가?**: 1차 검색은 빠르지만 정확도 ↓
- **어떻게?**: Cross-Encoder로 재평가

## 💡 2단계 검색 전략

```
[1차: 벡터 검색 - 빠름]
질문: "육아휴직 기간은?"
→ Top 10 문서 검색 (0.1초)

[2차: Reranking - 정확]
Top 10 문서를 정밀 재평가 (0.5초)
→ 진짜 관련 높은 Top 3만 선택
```

## 🔍 효과

```python
# Reranking 없음
검색 결과: [문서1(0.85), 문서2(0.83), 문서3(0.82)]
→ 문서2가 실제로는 가장 관련 높음

# Reranking 적용
재평가: [문서2(0.95), 문서1(0.70), 문서3(0.45)]
→ 정확한 순위! ✅
```

## 📝 정리

**Reranking = 2차 정밀 검사**
- 1차: 빠른 벡터 검색
- 2차: 정밀 재평가
- 정확도 크게 향상
