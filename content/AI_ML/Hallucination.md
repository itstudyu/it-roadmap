# Hallucination (환각)

## 📝 정의

Hallucination은 **모델이 사실이 아닌 것을 사실처럼 말하는 현상**이다.

없는 논문 제목, 없는 함수 이름, 없는 조항을 자신 있는 말투로 만들어낸다. 거짓말을 하려는 게 아니라, 그럴듯한 다음 단어를 고르는 일을 정직하게 수행한 결과다.

### 비유
시험에서 모르는 문제를 만난 학생이 빈칸을 두는 대신 그럴듯하게 채우는 것. 채워야 한다는 압박만 있고 모른다고 말할 선택지가 없으면 누구나 그렇게 된다.

## 🖼️ 그림으로 보기

```도해
흐름: 없는 논문 제목이 어떻게 만들어지나
사용자 :: "이 주제 논문 알려줘" 라고 묻는다
모델 :: 학습에서 본 제목의 생김새를 떠올린다
모델 :: 이 자리에 올 법한 단어를 하나씩 고른다
모델 :: 저자 이름과 연도도 그럴듯하게 잇는다
< 사용자 :: 형식이 완벽한, 존재하지 않는 논문을 받는다
= 모델에게는 "지어내기" 와 "답하기" 가 같은 동작이다
```

## ⚠️ 해결하는 문제

이 항목은 해결하는 문제가 아니라 **다뤄야 할 문제**다.

```도해
대조: 모르는 것을 물으면 어떻게 되나
대비 없이 || 근거를 붙이면
답 :: 그럴듯하게 지어낸다 || 문서를 인용한다
확인 :: 사람이 일일이 || 출처를 보면 된다
모를 때 :: 모른다고 안 한다 || 못 찾았다고 한다
= 지어내지 못하게 막는 게 아니라, 지어낼 필요가 없게 만드는 쪽이 먹힌다
```

모델은 확률이 높은 문장을 만든다. 확률이 높은 것과 사실인 것은 다른 기준이라, 학습 데이터에 없는 것을 물으면 빈칸을 채우듯 그럴듯한 것을 만든다.

막는 방법은 모델을 다그치는 게 아니라 근거를 주는 것이다. [[RAG]]로 실제 문서를 함께 넣으면 지어낼 자리가 줄어들고, 출처를 붙이게 하면 사람이 확인할 수 있다.

## ⚙️ 작동 원리

어디서 잘 나오는지에 규칙성이 있다.

```도해
층: 어떤 질문에서 환각이 잘 나오나
최신 정보 :: 학습 이후의 일. 아예 모른다
좁은 사실 :: 특정 논문, 조항, 사내 규정
숫자와 인용 :: 형식은 알지만 값은 모른다
일반 상식 :: 여기서는 잘 안 나온다
= 아래로 갈수록 안전하다. 위쪽을 물을 때 근거를 붙여야 한다
```

## 💡 실제 사례

- **없는 라이브러리 함수** 그럴듯한 이름의 함수를 쓴 코드를 준다. 실행해야 없다는 걸 안다.
- **법 조항 인용** 조문 번호와 문구를 만들어낸다. 형식이 정확해서 더 위험하다.
- **인용 출처** 제목, 저자, 연도가 모두 갖춰진 존재하지 않는 문헌을 만든다.

## 🚫 흔한 오해

- **환각은 고칠 수 있는 버그다** — 다음 토큰을 확률로 고르는 구조에서 나오는 성질이라 완전히 없앨 수 없다. 줄이고 검증할 대상이다.
- **"모르면 모른다고 해"라고 지시하면 해결된다** — 도움은 되지만 모델은 자기가 모른다는 것을 모른다. 확률이 낮아도 가장 높은 후보를 고를 뿐이다.
- **큰 모델을 쓰면 사라진다** — 줄어들긴 하지만 없어지지 않는다. 오히려 더 그럴듯해져서 알아채기 어려워진다.

## 🚨 주의사항

- **형식이 정확할수록 의심한다.** 조문 번호, 논문 연도, 함수 시그니처처럼 형식이 뚜렷한 것이 가장 잘 만들어진다.
- **사실 확인이 필요한 곳에는 근거를 강제한다.** 출처를 못 찾으면 답하지 말라는 규칙과 [[RAG]]를 같이 쓴다.

## 📝 정리

Hallucination은 모델이 사실이 아닌 것을 사실처럼 말하는 현상이다. 구조에서 나오는 성질이라 없앨 수는 없고, 근거를 주고 출처를 붙이게 해서 줄이고 확인하는 것이 대응이다.
