# Prompt Engineering (프롬프트 엔지니어링)

## 📝 정의
Prompt Engineering은 **LLM에서 원하는 결과를 얻기 위해 질문을 설계하는 기술**입니다.

### 핵심 개념
- 명확한 지시: 구체적으로 요청
- 예시 제공: Few-shot learning
- 역할 부여: "당신은 전문가입니다"
- 단계별 사고: Chain-of-Thought

## 💡 프롬프트 작성 기법

**나쁜 예**:
```
코드 작성해줘
```

**좋은 예**:
```
Python으로 이미지 리사이즈 함수를 작성해주세요.

요구사항:
- PIL 라이브러리 사용
- 입력: 파일 경로, 새 크기
- 에러 처리 포함
- 주석 추가

예시:
resize_image('input.jpg', 800, 600)
```

## 🎯 주요 기법

### 1. Zero-shot
```python
prompt = "다음 텍스트의 감정을 분석해줘: 오늘 정말 기분 좋은 날이에요!"
# → "긍정적"
```

### 2. Few-shot (예시 제공)
```python
prompt = """
예시:
텍스트: "최고의 제품이에요!" → 긍정
텍스트: "완전 실망했어요" → 부정

이제 분석:
텍스트: "괜찮은 것 같아요" → ?
"""
# → "중립" 또는 "약한 긍정"
```

### 3. Chain-of-Thought
```python
prompt = """
문제: 8명이 피자 3판을 똑같이 나눠먹으려고 합니다. 한 판에 8조각입니다.
한 사람당 몇 조각?

단계별로 생각해봅시다:
"""
# → "1. 전체 조각: 3 × 8 = 24조각
#     2. 1인당: 24 ÷ 8 = 3조각"
```
