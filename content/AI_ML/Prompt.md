# Prompt (프롬프트)

## 📝 정의

Prompt는 **LLM에게 주는 지시문이나 질문**입니다. AI의 출력 품질을 결정하는 가장 중요한 요소입니다.

### 핵심 개념

- **무엇인가?**: LLM 입력 텍스트 (질문 + 지시 + 맥락)
- **왜 필요한가?**: LLM의 동작 방향 결정
- **어떻게 작동하나?**: 프롬프트 → LLM 처리 → 답변 생성

### Prompt가 해결하는 문제

**문제 상황**:
```
😱 나쁜 프롬프트
"요약해줘"
→ 무엇을? 얼마나? 어떤 스타일로? 😱
→ 결과: 애매한 답변

😱 맥락 없는 질문
"이거 언제야?"
→ LLM이 '이거'를 모름 😱
→ 결과: "무엇을 말씀하시는지..."
```

**좋은 Prompt의 해결**:
```
✅ 명확한 프롬프트
"다음 문서를 3줄로 요약하세요. 핵심 내용 위주로:
[문서 내용]"
→ 명확한 지시 + 맥락 ✅
→ 결과: 정확한 요약

✅ 맥락 포함
"첨부한 제32조 육아휴직 조항은 언제부터 적용되나요?"
→ 충분한 맥락 ✅
→ 결과: 정확한 답변
```

## 💡 Prompt Engineering 기법

### 1. Zero-shot

```python
prompt = """
다음 문장의 감정을 분류하세요: 긍정, 부정, 중립

문장: "이 제품 정말 좋아요!"
답변:
"""
# 출력: 긍정
```

### 2. Few-shot

```python
prompt = """
다음 예시처럼 문장의 감정을 분류하세요:

예시 1:
문장: "정말 최고예요!"
답변: 긍정

예시 2:
문장: "실망스럽네요"
답변: 부정

예시 3:
문장: "그냥 그래요"
답변: 중립

이제 분류하세요:
문장: "별로 좋지 않아요"
답변:
"""
# 출력: 부정 (예시로 학습)
```

### 3. Chain-of-Thought (CoT)

```python
prompt = """
문제: 사과 3개가 1,000원이면, 사과 7개는 얼마인가요?

단계별로 생각하세요:
1. 사과 1개 가격 계산
2. 7개 가격 계산
"""
# 출력:
# 1. 1,000 ÷ 3 = 약 333원
# 2. 333 × 7 = 2,331원
# 답: 약 2,331원
```

### 4. System Prompt

```python
from openai import OpenAI
client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "당신은 친절한 고객 서비스 챗봇입니다. 항상 존댓말을 사용하세요."},
        {"role": "user", "content": "주문 취소하고 싶어"}
    ]
)

# 출력: "주문 취소를 도와드리겠습니다. 주문 번호를 알려주시겠어요?"
```

## 🔍 실전 RAG Prompt

```python
def create_rag_prompt(question: str, documents: list[str]) -> str:
    """RAG용 프롬프트 생성"""

    context = "\n\n".join([
        f"문서 {i+1}:\n{doc}"
        for i, doc in enumerate(documents)
    ])

    prompt = f"""
다음 문서를 참고해서 질문에 답하세요.

규칙:
1. 문서에 없는 내용은 "문서에 해당 정보가 없습니다"라고 답하세요
2. 답변 시 출처를 명시하세요 (예: "문서 1에 따르면...")
3. 추측하지 마세요

문서:
{context}

질문: {question}

답변:
"""
    return prompt

# 사용
docs = [
    "제32조: 육아휴직 기간은 최대 2년입니다.",
    "제33조: 육아휴직 중 급여는 지급되지 않습니다."
]

prompt = create_rag_prompt("육아휴직 기간은?", docs)
```

## 📝 정리

**Prompt Engineering = AI 성능 튜닝**
```
나쁜 프롬프트 → 엉뚱한 답
좋은 프롬프트 → 정확한 답
```

**핵심 원칙**:
```
1. 명확하게: 무엇을 원하는지
2. 구체적으로: 형식, 길이, 스타일
3. 맥락 제공: 필요한 정보 모두
4. 예시 활용: Few-shot 학습
```
