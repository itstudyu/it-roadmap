# Public IP vs Private IP (공인 IP vs 사설 IP)

## 📝 정의

공인 IP는 **인터넷 전체에서 유일한 주소**이고 사설 IP는 그 안쪽에서만 통하는 주소다.

IPv4 주소는 약 43억 개뿐인데 인터넷에 연결되는 기기는 그보다 훨씬 많다. 그래서 내부에서는 아무나 겹쳐 쓸 수 있는 사설 IP를 쓰고, 밖으로 나갈 때만 공인 IP로 바꿔 내보내는 방식이 표준이 됐다.

### 비유
회사 대표 전화번호와 내선 번호. 밖에서는 대표 번호만 알면 되고, 내선 번호는 그 건물 안에서만 뜻이 있어서 다른 회사에 같은 번호가 있어도 상관없다.

## 🖼️ 그림으로 보기

```도해
흐름: 집 안 PC 가 인터넷에 나갈 때 주소가 어떻게 바뀌나
내부 PC :: 192.168.1.2 를 출발지로 적어 내보낸다
공유기 :: 출발지를 자기 공인 IP 203.0.113.5 로 바꾼다
공유기 :: 어느 기기가 어느 포트로 나갔는지 적어둔다
웹서버 :: 203.0.113.5 에서 온 요청으로 보고 답한다
< 공유기 :: 적어둔 표를 보고 192.168.1.2 로 돌려준다
= 밖에서는 공유기 주소만 보이고 집 안 주소는 보이지 않는다
```

## ⚠️ 해결하는 문제

```도해
대조: 모든 기기에 공인 IP 를 하나씩 주면 어떻게 되나
전부 공인 IP || 사설 IP 와 NAT
주소 개수 :: 43억이면 부족 || 안에서 재사용
집 안 기기 :: 밖에 그대로 노출 || 기본으로 가려짐
주소 배정 :: 할당 기관 승인 || 내부에서 자유
= 밖으로 나갈 때만 공인 IP 를 하나 빌려 쓰는 방식으로 버티고 있다
```

IPv4가 정한 주소는 약 43억 개다. 집집마다 스마트폰과 PC와 TV가 있는 지금은 기기 하나에 하나씩 나눠줄 수가 없다.

사설 IP는 이 문제를 재사용으로 푼다. 전 세계 모든 집이 192.168.1.2를 써도 그 주소는 각자의 공유기 안에서만 통하므로 서로 부딪히지 않는다. 밖으로 나가는 순간에만 공유기가 자기 공인 IP로 바꿔 내보내니 집 하나에 공인 IP 하나면 충분해진다. 덤으로 밖에서는 내부 주소로 곧장 찾아올 수 없게 된다.

## ⚙️ 작동 원리

사설 IP로 쓸 수 있는 대역은 정해져 있다. `10.0.0.0`부터 `10.255.255.255`까지, `172.16.0.0`부터 `172.31.255.255`까지, `192.168.0.0`부터 `192.168.255.255`까지 세 구간이다. 앞의 것은 규모가 큰 기업망이나 클라우드에서, 마지막 것은 가정과 소규모 사무실에서 주로 쓴다.

주소를 바꾸는 일은 [[NAT]]가 한다. 내부에서 나가는 패킷의 출발지를 공인 IP로 고쳐 적으면서, 어느 내부 기기가 어느 포트를 썼는지 표에 기록해둔다. 응답이 돌아오면 그 표를 보고 원래 기기의 사설 IP로 되돌려 전달한다. 표가 있기 때문에 여러 기기가 공인 IP 하나를 같이 쓸 수 있다.

공인 IP도 종류가 나뉜다. 접속할 때마다 바뀔 수 있는 유동 IP가 가정용 회선의 기본이고, 서버를 돌리려면 항상 같은 고정 IP가 필요하다. 클라우드에서는 서버에 붙였다 뗄 수 있는 고정 공인 IP를 따로 제공한다.

## 📊 비교

| | 공인 IP | 사설 IP |
|---|---|---|
| 유일한 범위 | 전 세계 | 그 조직 안에서만 |
| 인터넷 직접 통신 | 된다 | NAT를 거쳐야 한다 |
| 주소 고갈 | IPv4는 한계에 닿음 | 재사용해서 문제없음 |
| 밖에서 접속 | 바로 된다 | 포트 포워딩이나 VPN 필요 |
| 비용 | ISP나 클라우드에 지불 | 직접 배정, 무료 |

## 💡 실제 사례

- **집 공유기** — ISP에게 공인 IP 하나를 받고, 연결된 기기에는 192.168.1.x 대역을 자동으로 나눠준다.
- **클라우드 VPC** — 10.0.0.0/16 같은 사설 대역을 잡아 서버를 넣고, 인터넷에 나가야 하는 서버에만 공인 IP를 붙인다.
- **집 서버에 밖에서 접속** — 공유기에 포트 포워딩을 걸어 203.0.113.5:8080으로 들어온 요청을 192.168.1.100:8080으로 넘긴다.

## 🚫 흔한 오해

- **사설 IP는 아무 숫자나 골라 쓰면 된다** — 쓸 수 있는 대역이 정해져 있다. 그 밖의 숫자를 내부에 쓰면 같은 주소를 가진 진짜 인터넷 서버로 갈 길이 막힌다.
- **공인 IP는 한번 받으면 계속 같은 주소다** — 가정용 회선은 대개 유동 IP라 재접속하면 바뀔 수 있다. 늘 같은 주소가 필요하면 고정 IP를 따로 받아야 한다.
- **사설 IP를 쓰니까 안전하다** — 밖에서 먼저 찾아오지 못할 뿐이다. 안에서 밖으로 나가는 연결은 그대로 열려 있어서 이미 들어온 악성 코드가 하는 일은 막지 못한다.

## 📝 정리

공인 IP는 인터넷 전체에서 하나뿐인 주소이고, 사설 IP는 정해진 대역 안에서 각 내부망이 겹쳐 써도 되는 주소다. 둘 사이를 NAT가 이어주며 나갈 때 주소를 바꾸고 돌아올 때 표를 보고 되돌린다. 그래서 밖에서 내부 기기로 곧장 들어오려면 포트 포워딩이나 VPN 같은 통로를 따로 만들어야 한다.
