# Public IP vs Private IP (공인 IP vs 사설 IP)

## 📝 정의

**공인 IP(Public IP)**는 인터넷에서 유일하게 식별 가능한 IP 주소로, 인터넷을 통해 직접 접근할 수 있는 주소입니다. **사설 IP(Private IP)**는 특정 조직이나 가정의 내부 네트워크에서만 사용하는 IP 주소로, 인터넷에서는 직접 라우팅되지 않으며 전 세계 어느 곳에서든 동일한 주소 범위를 재사용할 수 있습니다.

전 세계 모든 인터넷 연결 기기에 고유한 공인 IP를 부여하면 IP 주소가 부족해집니다(IPv4는 약 43억 개 한계). 이 문제를 해결하기 위해 내부 네트워크에서는 사설 IP를 사용하고, 인터넷에 나갈 때만 공인 IP로 변환(NAT)하는 방식이 표준이 되었습니다. 가정에서는 공유기가, 기업에서는 방화벽/라우터가 이 변환을 처리합니다.

> **한 줄 요약**: "공인 IP는 인터넷의 집 주소, 사설 IP는 건물 내 방 번호 — 외부에선 건물 주소만 보인다"

**비유**:
- **건물 주소 vs 내선 번호 비유**: 회사 건물의 대표 전화번호(공인 IP)로 전화하면 안내원(NAT/공유기)이 담당자의 내선 번호(사설 IP)로 연결해 줍니다. 외부에서는 내선 번호를 몰라도 됩니다.
- **아파트 주소 비유**: 아파트 동 주소(공인 IP)는 외부에서 알 수 있지만, 각 호수(사설 IP)는 내부에서만 의미가 있습니다.

## 🎯 핵심 개념

### 1. 사설 IP 주소 범위 (RFC 1918)
사설 IP로 사용 가능한 주소 대역은 국제 표준으로 정해져 있습니다:
- **10.0.0.0 ~ 10.255.255.255** (10.x.x.x): 대규모 기업/클라우드 VPC
- **172.16.0.0 ~ 172.31.255.255** (172.16~31.x.x): 중간 규모 네트워크
- **192.168.0.0 ~ 192.168.255.255** (192.168.x.x): 가정/소규모 사무실 (가장 흔함)

### 2. NAT (Network Address Translation)
사설 IP를 사용하는 기기가 인터넷에 나갈 때, 공유기/라우터가 사설 IP를 공인 IP로 변환합니다. 응답이 돌아오면 다시 사설 IP로 변환하여 해당 기기에 전달합니다. 이를 통해 여러 기기가 하나의 공인 IP를 공유할 수 있습니다.

### 3. 공인 IP의 종류
- **고정 IP (Static IP)**: 항상 동일한 IP. 서버 운영에 필요. 비용이 더 비쌈
- **유동 IP (Dynamic IP)**: 접속할 때마다 달라질 수 있는 IP. 가정용 인터넷에 일반적
- **탄력적 IP (Elastic IP)**: AWS에서 제공하는 고정 공인 IP. 서버에 붙였다 뗄 수 있음

### 4. 루프백 주소와 특수 주소
- **127.0.0.1 (localhost)**: 자기 자신을 가리키는 주소. 서버 로컬 테스트에 사용
- **0.0.0.0**: 모든 네트워크 인터페이스. 서버가 어떤 IP에서든 요청을 받겠다는 의미
- **255.255.255.255**: 브로드캐스트 주소. 네트워크 내 모든 기기에 전송

## ⚠️ 해결하는 문제

### 문제 1: IPv4 주소 고갈
전 세계 인터넷 연결 기기 수가 IPv4 주소 수(약 43억)를 훨씬 초과했습니다. 사설 IP를 통해 내부에서는 동일한 주소 범위(192.168.x.x)를 전 세계 모든 가정이 재사용할 수 있어, 이 문제를 실용적으로 해결했습니다.

### 문제 2: 내부 네트워크 보안
사설 IP는 인터넷에서 직접 라우팅되지 않으므로, 내부 기기가 외부 공격으로부터 기본적으로 보호됩니다. 공유기/방화벽이 없으면 외부에서 직접 사설 IP에 접근할 수 없습니다.

### 문제 3: 네트워크 관리 용이성
조직 내부에서 IP 주소 체계를 독립적으로 설계하고 관리할 수 있습니다. 공인 IP 할당 기관의 승인 없이 내부 IP를 자유롭게 배정할 수 있습니다.

## ⚙️ 작동 원리

### 1단계: 내부 기기의 통신 요청
내부 PC(192.168.1.2)가 인터넷의 웹서버에 접속하려 합니다. 패킷의 출발지 주소는 사설 IP(192.168.1.2)입니다.

### 2단계: NAT 변환 (사설 → 공인)
공유기가 패킷을 받으면, 출발지 주소를 자신의 공인 IP(203.0.113.5)로 변환합니다. 어떤 내부 기기가 어떤 포트로 요청했는지 NAT 테이블에 기록합니다.

### 3단계: 인터넷 통신
웹서버는 203.0.113.5에서 온 요청으로 인식하고 응답합니다. 인터넷에서는 내부 사설 IP인 192.168.1.2를 볼 수 없습니다.

### 4단계: NAT 역변환 (공인 → 사설)
응답 패킷이 공유기에 도착하면, NAT 테이블을 보고 원래 어떤 내부 기기(192.168.1.2)에게 전달해야 하는지 확인하여 전달합니다.

## 📊 비교

| 항목 | 공인 IP (Public IP) | 사설 IP (Private IP) | IPv6 |
|------|-------------------|-------------------|------|
| **범위** | 전 세계 유일 | 조직 내에서만 유일 | 전 세계 유일 |
| **인터넷 직접 통신** | 가능 | 불가능 (NAT 필요) | 가능 |
| **주소 고갈 문제** | 있음 (IPv4 한계) | 없음 (재사용 가능) | 없음 (128비트) |
| **보안** | 직접 노출 | 기본 격리됨 | 직접 노출 |
| **IP 대역** | IANA 할당 | 10.x, 172.16-31.x, 192.168.x | 2001:/32 등 |
| **비용** | 유료 (ISP/클라우드) | 무료 (자체 할당) | 유료 (ISP/클라우드) |
| **서버 운영** | 가능 | Port Forwarding 필요 | 가능 |
| **변경 가능성** | 동적 IP는 변경됨 | 고정 가능 | 고정 가능 |

## ✅ 장단점

**공인 IP 장점**:
- 인터넷에서 직접 접근 가능하여 서버 운영에 필수
- 별도 설정 없이 인터넷 통신 가능

**공인 IP 단점**:
- 직접 노출되므로 공격 대상이 될 수 있어 방화벽 필수
- 유료이며 IPv4는 점점 고갈되고 있음

**사설 IP 장점**:
- 인터넷에 직접 노출되지 않아 기본적인 보호 제공
- 주소 고갈 걱정 없이 자유롭게 할당 가능

**사설 IP 단점**:
- 외부에서 접근하려면 Port Forwarding이나 VPN 설정 필요
- NAT로 인해 일부 P2P 통신이나 특수 프로토콜에서 문제 발생 가능

## 💡 실제 사례

### 1. 가정 공유기 환경
가정 공유기는 ISP(KT, SK, LG U+)로부터 공인 IP(예: 203.0.113.5)를 하나 받습니다. 연결된 기기들에게는 192.168.1.x 사설 IP를 자동으로 배정합니다. 스마트폰, PC, TV 등 여러 기기가 하나의 공인 IP를 공유합니다.

### 2. AWS VPC 환경
AWS에서 VPC를 만들면 10.0.0.0/16 같은 사설 IP 대역을 설정합니다. Private Subnet의 EC2는 사설 IP만 가지며 인터넷에 직접 접근 불가능합니다. 인터넷 접근이 필요한 Public Subnet의 서버에는 Elastic IP(공인 IP)를 할당합니다.

### 3. 내부 서버에 외부 접근 허용 (Port Forwarding)
집에서 게임 서버나 NAS를 운영할 때, 공유기에서 Port Forwarding을 설정하여 외부에서 사설 IP의 서버에 접근하게 합니다. 예: 외부에서 203.0.113.5:8080으로 접속하면 공유기가 192.168.1.100:8080으로 포워딩합니다.

## 🔗 관련 용어

- **NAT (Network Address Translation)**: 사설 IP와 공인 IP 사이의 주소 변환 기술
- **DHCP**: 네트워크에 연결된 기기에 자동으로 사설 IP를 배정하는 프로토콜
- **Port Forwarding**: 공인 IP의 특정 포트를 내부 사설 IP로 연결하는 기술
- **Subnet Mask**: IP 주소에서 네트워크 부분과 호스트 부분을 구분하는 마스크
- **CIDR**: IP 주소 범위를 표현하는 방법. 예: 192.168.1.0/24
- **IPv6**: 128비트 주소 체계로 사설 IP 없이도 충분한 주소 공간 제공
- **Elastic IP**: AWS에서 제공하는 고정 공인 IP. 인스턴스에 붙였다 뗄 수 있음
- **VPN**: 사설 IP를 사용하는 내부망에 외부에서 안전하게 접근하는 기술
