# Port (포트)

## 📝 정의

Port는 **한 컴퓨터 안에서 어느 프로그램으로 갈지 가리키는 번호**다.

IP 주소는 어느 컴퓨터인지까지만 알려준다. 그 컴퓨터에서 웹 서버와 데이터베이스가 같이 돌고 있으면 둘을 가릴 것이 없다. 포트 번호가 그 자리를 맡는다.

### 비유
건물 주소와 호수. 주소만으로는 건물 앞까지고, 몇 호인지가 있어야 문 앞에 닿는다.

### 예
웹 주소 끝에 붙는 :8080 같은 숫자가 이 번호다. 평소에는 브라우저가 알아서 붙여줘서 안 보인다.

## 🖼️ 그림으로 보기

```도해
흐름: 요청 하나가 어느 프로그램까지 어떻게 찾아가나
브라우저 :: 주소와 포트를 함께 보낸다
인터넷 :: IP 주소를 보고 그 컴퓨터까지 옮긴다
운영체제 :: 도착한 패킷에서 포트 번호를 읽는다
포트 표 :: 그 번호를 잡고 있는 프로그램을 찾는다
웹 서버 :: 자기 앞으로 온 요청을 받아 처리한다
= IP 는 컴퓨터까지, 포트는 그 안의 프로그램까지 데려간다
```

## ⚠️ 해결하는 문제

```도해
대조: 한 컴퓨터에서 서비스 여러 개를 돌리면 어떻게 되나
포트가 없으면 || 포트가 있으면
프로그램 구분 :: 방법이 없다 || 번호로 가른다
한 대에 서비스 :: 하나만 || 여럿을 함께
접속 방법 :: 컴퓨터마다 다름 || 번호가 정해져 있다
= 컴퓨터 한 대를 여러 창구로 나누는 번호다
```

서버 한 대에는 대개 여러 프로그램이 함께 돈다. 웹 서버, 데이터베이스, 캐시가 같은 IP 주소를 쓰기 때문에, 도착한 패킷을 누구에게 줄지 정할 기준이 필요하다.

포트 번호가 그 기준이다. 자주 쓰는 서비스에는 번호가 관례로 정해져 있어서, 웹 주소를 칠 때 `:80`이나 `:443`을 따로 적지 않아도 브라우저가 알아서 붙인다.

## ⚙️ 작동 원리

번호는 0부터 65535까지 있고 쓰임에 따라 구간이 나뉜다.

```도해
층: 포트 번호는 어떤 구간으로 나뉘나
0 ~ 1023 :: 잘 알려진 번호. 80, 443, 22 등
1024 ~ 49151 :: 등록된 번호. 3306, 5432, 8080 등
49152 ~ 65535 :: 임시 번호. 접속하는 쪽이 그때그때 받는다
= 위쪽은 관례로 굳어 있고 아래로 갈수록 자유롭게 쓴다
```

프로그램이 어떤 포트를 잡으면 그 번호는 그 프로그램 것이 된다. 다른 프로그램이 같은 번호를 잡으려 하면 이미 쓰는 중이라는 오류가 난다. 개발할 때 자주 만나는 오류가 이것이고, 대개 앞서 띄운 프로그램이 아직 살아 있는 것이다.

접속하는 쪽에도 포트가 붙는다. 브라우저는 요청을 보낼 때 임시 번호를 하나 받아서, 돌아오는 응답이 어느 탭 것인지 그 번호로 가린다.

## 💡 실제 사례

- **개발 서버** — 앱을 3000번에, API를 8000번에 띄우면 한 노트북에서 둘을 함께 돌린다.
- **방화벽 규칙** — 22번은 사내에서만, 443번은 어디서나 열어두는 식으로 번호 단위로 허용을 정한다.
- **데이터베이스 접속** — 접속 문자열에 3306이나 5432가 붙는 이유는 그 프로그램이 관례로 그 번호를 잡기 때문이다.

## 🚫 흔한 오해

- **포트는 물리적인 구멍이다** — 실제 단자가 아니라 번호다. 랜선을 꽂는 자리와는 아무 관계가 없다.
- **80번과 443번은 반드시 그 용도로만 써야 한다** — 관례일 뿐이다. 다른 프로그램이 잡아도 되지만, 그러면 접속하는 쪽이 번호를 직접 적어야 한다.
- **포트를 열면 그 프로그램이 열린다** — 방화벽에서 번호를 열어도 그 번호를 잡고 있는 프로그램이 없으면 아무것도 응답하지 않는다.

## 🚨 주의사항

- **1023번 이하는 관리자 권한이 있어야 잡을 수 있다.** 웹 서버를 80번에 띄울 때 권한 오류가 나는 이유가 이것이다.
- **쓰지 않는 포트는 닫아둔다.** 열어둔 번호 하나하나가 바깥에서 두드려볼 수 있는 문이 된다.

## 📝 정리

Port는 한 컴퓨터 안에서 어느 프로그램에게 줄지 가리는 번호다. IP 주소가 컴퓨터까지 데려다주면 포트가 그 안의 창구를 정하고, 한 번호는 한 프로그램만 잡을 수 있다.

## ❓ 이해했는지

- 개발 서버를 띄우려는데 이미 쓰는 중이라는 오류가 났다면 무엇이 일어난 것인가 → 작동 원리
- 웹 서버를 80번에 띄우려는데 권한 오류가 난다면 무엇 때문인가 → 주의사항
- 방화벽에서 8080번을 열었는데도 접속이 안 된다면 무엇을 확인해야 하나 → 흔한 오해
