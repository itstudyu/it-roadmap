# Domain (도메인)

## 📝 정의

Domain은 **숫자 IP 주소에 붙인 사람이 읽는 이름**이다.

`142.250.207.46` 같은 숫자를 외우는 대신 `google.com` 을 친다. 실제 접속은 여전히 숫자로 이뤄지고, 그 사이를 DNS가 이어준다.

### 이름
= 라틴어 dominium(주인이 다스리는 땅)에서 왔다. 등록한 사람이 그 이름 아래를 다스린다

### 비유
회사 이름과 대표번호. 사람들은 이름으로 부르고 기억하지만 실제 연결은 번호로 이뤄진다.

### 예
몇 년 전 즐겨찾기 해둔 사이트에 들어갔더니 엉뚱한 광고 페이지가 뜨는 일이 있다. 이름은 그대로인데 주인이 바뀐 것이다.

### 직접
주소창에 `google.com` 과 `mail.google.com` 을 차례로 열어 보라. 등록한 이름은 같고 앞자리만 붙였는데 나오는 화면은 딴판이다.

## 🖼️ 그림으로 보기

```도해
층: 도메인은 어떤 순서로 읽히나
루트 :: 모든 도메인의 맨 위. 점 하나로 표시된다
최상위 :: `.com`, `.kr` 같은 큰 갈래
2단계 :: `google` 처럼 등록해서 소유하는 부분
서브도메인 :: `mail` 처럼 소유자가 알아서 붙이는 앞자리
= 오른쪽이 위다. 사람이 읽는 방향과 반대로 좁혀 들어간다
```

## ⚠️ 해결하는 문제

```도해
대조: 숫자 주소만 있으면 어떻게 되나
IP 주소만 || 도메인으로
기억 :: 숫자를 왼다 || 이름만 안다
서버 이전 :: 전부 공지 || 레코드만 수정
브랜드 :: 알 수 없다 || 이름이 곧 신호
= 이름과 주소를 떼어놓아야 주소를 바꿔도 이름이 남는다
```

숫자 주소를 직접 쓰면 두 가지가 막힌다. 사람이 외울 수 없다는 것이 첫째고, 서버를 옮겨 주소가 바뀌면 접속하던 사람들이 전부 길을 잃는다는 것이 둘째다.

도메인은 이름과 주소를 떼어놓는다. 이름은 그대로 두고 가리키는 주소만 바꾸면 쓰는 사람은 아무것도 하지 않아도 새 서버로 간다. 이름이 남아 있으니 그 자체가 브랜드가 되기도 한다.

## ⚙️ 작동 원리

도메인은 사는 것이 아니라 기간을 정해 빌리는 것이다. 최상위 도메인마다 등록 정보를 보관하는 기관이 있고, 사용자는 중개 업체를 통해 신청한다. 신청이 받아들여지면 그 기관의 목록에 소유자 정보와 함께 올라간다. 기간이 끝나고 갱신하지 않으면 다시 등록 가능한 상태가 되어 다른 사람이 가져갈 수 있다.

서브도메인은 다르다. 이미 가진 도메인 앞에 이름을 붙이는 것이라 따로 등록하지 않고 DNS 설정만 추가하면 된다. 각 서브도메인은 서로 다른 서버를 가리킬 수 있다.

## 💡 실제 사례

- **서비스 이전** — 처음에는 저렴한 호스팅에 연결해 두었다가 자체 서버로 옮길 때, 도메인은 그대로 두고 DNS 레코드만 새 주소로 바꾼다.
- **서비스별 서브도메인** — 메일, 저장소, 관리 화면을 같은 도메인 아래 다른 앞자리로 나눠 각각 다른 서버에 둔다.
- **지역별 주소** — 나라마다 다른 최상위 도메인을 쓰면서 같은 이름을 유지한다.

## 🚫 흔한 오해

- **도메인을 사면 영원히 내 것이다** — 기간을 정해 빌리는 것이다. 갱신하지 않으면 만료되고 다른 사람이 등록할 수 있다.
- **도메인이 곧 웹사이트다** — 도메인은 이름이고 실제 파일은 서버에 있다. 도메인만 등록해두면 그 주소를 열어도 아무것도 나오지 않는다.
- **서브도메인도 따로 등록해야 한다** — 이미 가진 도메인 아래라면 DNS 설정만 추가하면 된다. 등록 비용이 더 들지 않는다.

## 🚨 주의사항

- **갱신 날짜를 놓치지 않는다.** 만료된 도메인은 짧은 유예 뒤 다른 사람이 가져갈 수 있고 되찾기 어렵다.
- **한 글자만 다른 도메인을 조심한다.** 눈에 거의 같아 보이는 주소가 진짜인 척 만들어질 수 있다.

## 📝 정리

**"주소가 아니라 이름, 그것도 빌린 이름"** 이라고 읽으면 된다. 이름과 주소를 떼어놓기 때문에 서버를 옮겨도 쓰는 사람은 같은 주소를 계속 쓴다. 소유는 기간제라 갱신하지 않으면 다른 사람에게 넘어간다.

## 🧒 열 살에게

가게 이름은 그대로인데 전화번호는 바뀔 수 있지? 이름만 알면 사람들이 계속 찾아오니까 가게는 번호만 조용히 갈아 끼워. 인터넷 이름도 그래서, 가게가 다른 건물로 옮겨도 너는 늘 쓰던 이름을 그대로 쳐.

## ❓ 이해했는지

- 서버를 다른 회사로 옮겼는데 사용자가 아무것도 바꾸지 않아도 되는 이유는 → 해결하는 문제
- mail.google.com 을 새로 쓰려면 등록 기관에 신청해야 하나 → 작동 원리
- 도메인만 등록해두고 아무 설정도 안 하면 그 주소에서 무엇을 보게 되나 → 흔한 오해
