# Intranet (인트라넷)

## 📝 정의

Intranet은 **조직 안에서만 닿는 사설 네트워크**다.

쓰는 기술은 인터넷과 같다. 같은 브라우저로 같은 주소를 치고 같은 프로토콜로 오간다. 다른 것은 그 주소가 조직 밖에서는 열리지 않는다는 점뿐이다.

### 비유
사내 방송. 장비는 바깥 라디오와 같지만 전파가 건물 밖으로 나가지 않는다.

## 🖼️ 그림으로 보기

```도해
흐름: 직원이 사내 포털을 열면 어디를 거치나
사원 PC :: 사내 주소를 브라우저에 입력한다
내부 DNS :: 밖에 없는 사설 IP 주소를 알려준다
방화벽 :: 이 요청이 안에서 온 것인지 확인한다
내부 서버 :: 회사 계정으로 로그인 여부를 본다
< 사원 PC :: 화면을 받는다. 같은 주소는 밖에서 안 열린다
= 인터넷과 같은 기술을 쓰되 닿는 범위만 막아둔 것이다
```

## ⚠️ 해결하는 문제

```도해
대조: 내부 업무 시스템을 인터넷에 그대로 두면 어떻게 되나
공개망에 두면 || 인트라넷에
접근 범위 :: 주소만 알면 됨 || 조직 안에서만
공격 표면 :: 전 세계에 열림 || 내부로 한정
인터넷 장애 :: 업무가 멈춘다 || 내부는 계속
= 잠그는 게 아니라 닿을 수 있는 범위 자체를 줄이는 것이다
```

인사 기록이나 재무 자료를 다루는 시스템을 인터넷에 올려두면 로그인 화면 하나가 전 세계에 노출된다. 로그인을 잘 막아둬도 그 화면 자체를 향한 시도가 끊이지 않고, 취약점 하나가 발견되면 그날부터 전 세계가 그 문을 두드린다.

인트라넷은 문을 잠그는 대신 문이 있는 자리를 줄인다. 밖에서는 주소를 알아도 닿지 않으므로, 밖에서 시도할 수 있는 일 자체가 사라진다.

## ⚙️ 작동 원리

```도해
층: 밖에서 안으로 들어오려면 무엇을 지나나
인터넷 :: 아무나 있는 바깥. 여기서 출발한다
방화벽 :: 어디서 온 요청인지 보고 막거나 통과시킨다
VPN :: 밖에 있는 직원을 안에 있는 것처럼 만들어준다
내부망 :: 사설 IP 와 내부 도메인만 통하는 구역
= 안으로 들어오는 문을 몇 개로 좁혀두는 구조다
```

내부 서버는 밖에서 쓸 수 없는 사설 IP 대역을 쓰고, 내부 DNS 가 `portal.company.internal` 같은 이름을 그 주소로 풀어준다. 인터넷에 있는 DNS 는 이 이름을 모르기 때문에 밖에서는 주소를 알아도 찾아갈 수 없다.

직원 인증은 한 곳에 모아둔다. 회사 계정으로 한 번 로그인하면 사내 시스템 여러 곳을 다시 로그인하지 않고 쓰는 방식이 흔하다.

## 📊 비교: 닿는 범위

| | 인터넷 | 인트라넷 | 엑스트라넷 |
|---|---|---|---|
| 누가 들어오나 | 누구나 | 조직 구성원 | 승인된 외부 협력사 |
| 밖에서 접근 | 그대로 | VPN 을 붙여야 | 정해진 경로로만 |
| 관리 주체 | 각자 | 그 조직 | 그 조직 |

## 💡 실제 사례

- **사원 포털** — 급여 명세와 휴가 신청을 사내 주소에서만 열 수 있게 둔다.
- **진료 기록 시스템** — 환자 기록을 다루는 시스템은 인터넷과 분리된 내부망에만 놓는다.
- **재택 근무** — 집에서는 VPN 을 붙인 뒤에야 같은 사내 주소가 열린다.

## 🚫 흔한 오해

- **인트라넷은 인터넷과 다른 기술이다** — 같은 기술을 쓴다. 브라우저도 HTTP 도 그대로고, 다른 것은 그 주소가 어디까지 닿느냐뿐이다.
- **내부망이니까 보안은 덜 신경 써도 된다** — 안쪽은 서로 믿고 열려 있는 경우가 많아서 한 대만 뚫리면 그대로 번진다. 안에서도 인증과 권한을 나누는 이유다.
- **VPN 을 붙이면 인터넷이 인트라넷이 된다** — VPN 은 밖에 있는 사람을 안쪽에 넣어주는 통로다. 인트라넷은 그 안쪽에 원래 있던 것이고 통로가 인트라넷을 만들지는 않는다.

## 🚨 주의사항

- **VPN 계정 정리가 곧 경계 관리다.** 퇴사자 계정이 남아 있으면 방화벽은 그 사람을 내부 사용자로 본다.
- **실수로 밖에 열리는 경로를 만들지 않는다.** 편의를 위해 내부 시스템 하나를 공개 주소에 붙이면 그 하나가 전체로 들어오는 문이 된다.

## 📝 정리

Intranet 은 인터넷과 같은 기술로 만들되 조직 안에서만 닿게 막아둔 네트워크다. 안전해지는 이유는 잠금이 강해서가 아니라 밖에서 시도할 자리 자체가 줄어들기 때문이다.

- 인터넷 회선이 끊겼는데 사내 결재 시스템은 왜 계속 되나?
