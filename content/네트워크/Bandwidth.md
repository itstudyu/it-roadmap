# Bandwidth (대역폭)

## 📝 정의

Bandwidth 는 **일정 시간에 회선을 지날 수 있는 정보량**이다.

MDN 은 보통 초당 비트 수로 잰다고 적는다 — bps, Mbps, Gbps 가 그 단위다. 회선에 적힌 이 숫자는 실제로 그만큼 나온다는 약속이 아니라 **그 이상은 못 지난다**는 상한이다.

### 비유
수도관의 굵기 — 굵으면 한꺼번에 많이 흐르지만, 물이 집까지 오는 데 걸리는 시간은 그것과 별개다.

## 🖼️ 그림으로 보기

```도해
대조: 회선을 굵게 하면 무엇이 달라지나
좁은 회선 || 굵은 회선
큰 파일 받기 :: 한참 걸린다 || 금방 끝난다
동시에 여럿 :: 서로 밀린다 || 나란히 지난다
남는 여유 :: 늘 꽉 찬다 || 여유가 있다
= 굵기는 한꺼번에 지날 양을 정한다. 오가는 시간은 건드리지 않는다
```

## ⚠️ 해결하는 문제

```도해
대조: 느린 원인을 굵기로만 보면 어떻게 되나
굵기만 볼 때 || 둘을 갈라 볼 때
느린 원인 :: 회선 탓만 한다 || 어느 쪽인지 안다
돈 쓰는 곳 :: 회선을 늘린다 || 왕복을 줄인다
결과 :: 그대로 느리다 || 실제로 빨라진다
= 굵기와 길이를 갈라 재지 않으면 엉뚱한 곳에 돈을 쓴다
```

"느리다"는 말은 두 가지를 한꺼번에 가리킨다. 한꺼번에 얼마나 지나느냐(굵기)와 한 번 갔다 오는 데 얼마나 걸리느냐([[Latency]], 길이)는 서로 다른 값인데, 둘을 구별하지 않으면 회선부터 늘리게 된다.

web.dev 가 첫 화면이 뜨기까지를 **왕복 횟수**로 세는 이유가 이것이다. HTML 하나뿐인 페이지는 최소 한 왕복, 외부 CSS 가 붙으면 최소 두 왕복이고, 그 왕복 한 번을 100ms 로 잡는다. 이 셈에는 파일이 11KB 인지 2KB 인지가 들어가지 않는다 — 굵기를 두 배로 해도 왕복 횟수는 그대로다.

## 📊 비교: 굵기와 길이

| | Bandwidth (굵기) | [[Latency]] (길이) |
|---|---|---|
| 재는 것 | 일정 시간에 지나는 양 | 한 번 갔다 오는 시간 |
| 단위 | bps · Mbps · Gbps | ms |
| 늘리거나 줄이려면 | 회선을 굵게 | 거리를 줄인다 |
| 크게 듣는 곳 | 동영상, 큰 파일 | 요청이 여러 번 오가는 페이지 |
| 안 듣는 곳 | 작은 파일을 여러 번 | 파일 하나가 아주 클 때 |

굵기는 돈으로 늘릴 수 있지만 길이는 그렇지 않다. 그래서 [[CDN]] 은 회선을 굵게 하는 대신 서버를 사용자 가까이 옮긴다 — web.dev 도 CDN 이 빠른 이유를 "원본 서버보다 사용자에 가까워서 왕복 시간이 짧다"로 설명한다.

## 💡 실제 사례

- **동영상 화질 자동 조절** — 회선이 좁으면 낮은 화질로 내려간다. 굵기가 초당 실어 보낼 수 있는 양의 상한이기 때문이다.
- **거점을 가까이 두기** — CDN 은 굵기가 아니라 거리를 줄인다. 같은 회선에서도 왕복 시간이 짧아진다.
- **이미지 용량 줄이기** — 지나갈 양 자체가 줄어드니 그만큼 빨리 끝난다. 다만 요청 횟수는 그대로라 왕복은 줄지 않는다.

## 🚫 흔한 오해

- **대역폭이 크면 빠른 것이다** — "빠르다"가 두 가지를 가리킨다. 한꺼번에 많이 지나는 것과 한 번 갔다 오는 시간이 짧은 것은 다른 값이고, 굵기는 앞쪽만 정한다.
- **100Mbps 회선이면 초당 100MB 를 받는다** — bps 의 b 는 비트다. 8 로 나눠야 바이트가 되니 상한이 12MB 남짓이다.
- **느리면 대역폭부터 늘리면 된다** — 작은 파일을 여러 번 받는 페이지는 거의 안 변한다. 왕복 횟수가 정하는 시간은 회선을 굵게 해도 그대로 남는다.

## 🚨 주의사항

- **bps 와 B/s 를 섞어 읽지 않는다.** 대역폭은 비트로 적고 파일 크기는 바이트로 적어서, 그냥 견주면 8 배가 어긋난다.
- **회선에 적힌 숫자는 상한이다.** 그만큼 나온다는 뜻이 아니라 그 이상은 안 나온다는 뜻이라, 실제로 나오는 양은 따로 재야 한다.

## 📝 정리

Bandwidth 는 일정 시간에 회선을 지날 수 있는 양이고, 관의 굵기에 해당한다. 굵게 하면 큰 파일이 빨리 오지만 한 번 갔다 오는 시간은 그대로여서, 왕복이 여러 번인 페이지는 회선을 늘려도 거의 안 변한다. 무엇이 병목인지 갈라 재는 일이 굵기를 늘리는 일보다 먼저다.

- 100Mbps 회선에서 100MB 파일이 8 초보다 빨리 오지 않는 이유는 → 흔한 오해
