# Tunnel (터널링)

## 📝 정의

Tunnel은 **다른 통신을 통째로 감싸서 실어 나르는 통로**다.

네트워크에는 지나갈 수 있는 길과 막힌 길이 있다. 터널은 막힌 쪽으로 갈 통신을 열린 쪽 통신 안에 넣어 보내고, 받는 쪽에서 다시 꺼내 원래 목적지로 이어준다.

### 비유
짐을 상자에 넣어 택배로 보내는 것. 옮기는 사람은 겉면 주소만 보고, 안에 무엇이 들었는지는 받는 사람이 열어야 안다.

## 🖼️ 그림으로 보기

```도해
흐름: 막힌 길 너머의 DB 에 어떻게 닿나
내 컴퓨터 :: `localhost:3306` 으로 접속한다
SSH 터널 :: 그 통신을 22번 포트 통신으로 감싼다
방화벽 :: 22번은 열려 있으니 그대로 통과시킨다
서버 :: 감싼 것을 풀어 원래 통신을 꺼낸다
내부 DB :: 서버 안쪽에서 3306 으로 이어진다
= 길이 하나만 열려 있어도 그 안에 다른 통신을 실어 보낼 수 있다
```

## ⚠️ 해결하는 문제

```도해
대조: 열린 길이 하나뿐일 때 어떻게 되나
터널 없이 || 터널로
막힌 포트 :: 아예 못 간다 || 감싸서 통과
오가는 내용 :: 그대로 보인다 || 겉만 보인다
내부 서버 :: 닿을 길이 없다 || 안까지 닿는다
= 통신을 다른 통신 안에 넣으면 바깥은 겉포장만 본다
```

회사나 클라우드의 DB는 대개 바깥에서 바로 못 붙게 막아둔다. 22번 포트만 열려 있는 상태에서 3306으로 붙으려 하면 방화벽에서 끊긴다. 그렇다고 DB 포트를 인터넷에 열면 누구나 두드릴 수 있게 된다.

터널은 그 사이를 지나간다. 열려 있는 길로 감싸서 보내고 서버 안쪽에서 풀기 때문에, DB는 여전히 바깥에 닫혀 있는 채로 내 컴퓨터에서는 로컬 포트처럼 쓰인다.

## ⚙️ 작동 원리

```도해
층: 터널 안에서 데이터는 어떻게 겹쳐 있나
바깥 포장 :: 22번 포트로 가는 평범한 SSH 통신
암호 :: 그 속은 암호화되어 열어도 못 읽는다
원래 통신 :: 안에 들어 있는 DB 접속 데이터
= 중간의 장비들은 맨 바깥 한 겹만 보고 옮긴다
```

[[SSH]] 터널은 잇는 방향에 따라 셋으로 갈린다. `-L`은 내 컴퓨터의 포트를 저쪽 서비스로 잇고, `-R`은 반대로 저쪽 서버의 포트를 내 컴퓨터로 잇는다. `-D`는 특정 포트 하나가 아니라 오가는 통신 전체를 서버 쪽으로 흘려보낸다.

터널은 연결이 끊기면 그대로 닫힌다. 오래 유지해야 하면 끊어졌을 때 다시 붙여주는 도구를 같이 쓴다.

## 💡 실제 사례

- **내부 DB 접속** — 바깥에 열려 있지 않은 DB를 중간 서버를 거쳐 로컬 포트처럼 붙여 쓴다.
- **개발 서버 잠깐 공개** — 내 컴퓨터에서 도는 서버를 바깥 주소로 잠깐 열어 다른 사람에게 보여준다.
- **끊기면 다시 잇기** — 터널이 끊어졌을 때 자동으로 다시 붙이는 도구를 걸어두고 오래 쓴다.

## 🚫 흔한 오해

- **터널을 쓰면 통신이 암호화된다** — 감싸는 것과 가리는 것은 다른 일이다. SSH 터널은 감싸면서 암호화까지 하지만, 감싸기만 하고 내용을 안 가리는 방식도 있다.
- **터널은 방화벽을 뚫는 것이다** — 뚫는 게 아니라 이미 열려 있는 길로 지나가는 것이다. 나갈 길이 하나도 없으면 터널도 못 만든다.
- **터널을 열면 내 컴퓨터가 그쪽 네트워크 안으로 들어간다** — 이어지는 건 정해둔 포트 하나다. 네트워크 전체에 들어가 있는 것처럼 만드는 건 VPN이 하는 일이다.

## 🚨 주의사항

- **터널 끝에 무엇이 열리는지 알고 만든다.** `-R`로 내 컴퓨터를 바깥 서버에 이어두면 그 서버에 닿는 사람도 같이 닿을 수 있다.
- **임시 공개용 터널을 켜둔 채 잊지 않는다.** 개발 중인 서버가 인증 없이 인터넷에 계속 열려 있게 된다.

## 📝 정리

Tunnel은 통신을 다른 통신 안에 넣어 열린 길로 실어 보내는 방식이다. 중간 장비는 겉포장만 보고 옮기므로 막힌 포트로도 닿을 수 있고, 이어지는 것은 네트워크 전체가 아니라 정해둔 포트다.

## ❓ 이해했는지

- 방화벽이 22번 포트만 열어뒀는데 3306의 DB에 붙을 수 있는 이유는 → 그림
- 중간에 있는 장비들이 터널 안의 내용을 못 보는 이유는 → 작동 원리
- 터널을 열었을 때 이어지는 범위가 VPN과 어떻게 다른가 → 흔한 오해
