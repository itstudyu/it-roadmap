# TCP (Transmission Control Protocol)

## 📝 정의

TCP는 **데이터를 빠짐없이 순서대로 배달하는 규칙**이다.

인터넷은 데이터를 작은 조각으로 쪼개 보내는데, 조각은 중간에 사라지기도 하고 순서가 뒤바뀌어 도착하기도 한다. TCP는 빠진 조각을 다시 요청하고 순서를 맞춰서 위층에 넘긴다.

### 비유
등기우편. 받았다는 서명을 받아야 배달이 끝나고, 서명이 안 오면 다시 보낸다. 그냥 우편(UDP)은 넣고 나면 도착했는지 모른다.

### 예
와이파이가 약할 때 페이지가 멈춘 채 한참 기다리는 그 시간이 사라진 조각을 다시 받는 시간이다.

## 🖼️ 그림으로 보기

```도해
흐름: 조각 하나가 사라지면 TCP 는 무엇을 하나
보내는 쪽 :: 파일을 조각내고 번호를 붙여 보낸다
받는 쪽 :: 1번 받았다, 2번 받았다고 알려준다
받는 쪽 :: 3번이 안 왔는데 4번이 왔다
받는 쪽 :: 4번은 들고만 있고 3번을 다시 달라고 한다
< 보내는 쪽 :: 3번만 다시 보낸다
받는 쪽 :: 순서대로 맞춰서 위층에 올린다
= 위층에 있는 HTTP 는 조각이 하나 사라졌다는 사실을 끝내 모른다
```

## ⚠️ 해결하는 문제

```도해
대조: 조각이 사라지거나 뒤섞이면 어떻게 되나
TCP 없이 || TCP 로
빠진 조각 :: 그냥 비어 있다 || 다시 요청한다
순서 뒤바뀜 :: 그대로 올라간다 || 맞춰서 올린다
받는 속도 :: 넘치면 흘린다 || 상대에 맞춰 조절
= 네트워크가 못 미더워도 위층은 안 미더운 줄 모르게 만드는 게 TCP의 일이다
```

인터넷의 아래층(IP)은 배달을 보장하지 않는다. 조각을 최선을 다해 보내볼 뿐이고, 라우터가 붐비면 버린다. 그 위에서 파일을 받으면 중간이 비거나 순서가 엉킨 채로 도착한다.

TCP는 조각마다 번호를 붙이고 받았다는 신호를 주고받아 그 문제를 감춘다. 위층에 있는 HTTP는 네트워크가 불안정하다는 사실을 알 필요가 없어진다.

## 🧱 구성


## ⚙️ 작동 원리

주고받기 전에 양쪽이 세 번 인사한다. `SYN`으로 연결하고 싶다고 하면, 서버가 `SYN-ACK`으로 좋다고 답하고, 클라이언트가 `ACK`으로 확인했다고 알린다.

두 번으로 줄이면 서버는 자기 응답이 도착했는지 모른 채 자원을 잡고 기다리게 된다. 세 번째 인사가 그걸 확인해준다.

속도 조절도 TCP가 한다. 처음에는 조금씩 보내다가 잘 도착하면 늘리고, 조각이 사라지기 시작하면 길이 막혔다고 보고 다시 줄인다.

## 💡 실제 사례

- **웹, 이메일, 파일 전송** — 내용이 하나라도 빠지면 안 되는 것은 전부 TCP를 쓴다.
- **영상 통화** — 반대로 UDP를 쓴다. 늦게 도착한 화면 한 장은 다시 받아봐야 쓸모가 없기 때문이다.
- **연결이 끊긴 느낌** — 와이파이가 약할 때 페이지가 멈춰 있는 건 TCP가 사라진 조각을 다시 요청하며 기다리는 중이라서다.

## 🚫 흔한 오해

- **TCP가 빠른 프로토콜이다** — 빠른 게 아니라 확실한 것이다. 확인 신호를 주고받느라 UDP보다 느리고, 그 느림을 받아들이는 대신 빠짐없음을 얻는다.
- **연결이 물리적으로 이어져 있다** — 전용선이 깔리는 게 아니다. 양쪽이 서로의 상태를 기억하고 있을 뿐이라 실제로는 조각들이 매번 다른 길로 간다.
- **TCP를 쓰면 데이터가 안전하다** — 안 빠지는 것과 안 읽히는 것은 다르다. 내용을 가리는 건 TLS의 일이다.

## 📊 비교

| | TCP | UDP |
|---|---|---|
| 연결 | 세 번 인사하고 시작 | 그냥 보낸다 |
| 빠진 조각 | 다시 요청 | 그대로 잃음 |
| 순서 | 맞춰 준다 | 도착한 대로 |
| 어디에 쓰나 | 웹, 파일, 메일 | 영상, 게임, DNS |

## 📝 정리

TCP는 못 미더운 네트워크 위에 미더운 통로를 만드는 규칙이다. 번호와 확인 신호로 빠짐과 뒤섞임을 감추고, 그 대가로 속도를 조금 내준다.

## ❓ 이해했는지

- 조각 3번이 사라지고 4번이 먼저 도착하면 받는 쪽은 무엇을 하나 → 그림
- 세 번 인사를 두 번으로 줄이면 서버 쪽에 무슨 일이 생기나 → 작동 원리
- 와이파이가 약할 때 페이지가 멈춰 보이는 동안 TCP는 무엇을 하고 있나 → 실제 사례
