# Firewall (방화벽)

## 📝 정의

Firewall은 **정해둔 규칙에 따라 통신을 통과시키거나 막는 장치**다.

오가는 패킷의 출발지와 목적지, 포트, 프로토콜을 보고 규칙과 맞춰본다. 규칙이 허락하지 않은 것은 목적지에 닿지 못한다.

### 비유
건물 정문의 경비원. 들어오는 사람마다 신분과 목적을 확인하고 명단에 없으면 돌려보낸다.

### 예
새로 깐 프로그램을 처음 켤 때 네트워크 접근을 허용할지 묻는 창이 뜨는 그 자리다.

## 🖼️ 그림으로 보기

```도해
흐름: 패킷 하나가 방화벽에서 무엇을 겪나
패킷 도착 :: 출발지, 목적지, 포트를 꺼내 본다
상태 확인 :: 이미 열려 있는 연결의 일부인가
규칙 대조 :: 위에서부터 처음 맞는 규칙을 찾는다
결정 :: 통과, 조용히 버림, 거부 응답 중 하나
기록 :: 무엇을 어떻게 처리했는지 남긴다
전달 :: 통과한 것만 목적지로 간다
= 규칙은 위에서부터 읽고 처음 맞는 하나에서 멈춘다
```

## ⚠️ 해결하는 문제

```도해
대조: 서버를 그대로 인터넷에 열어두면 어떻게 되나
방화벽 없이 || 방화벽으로
열린 포트 :: 전부 || 정한 것만
침투 시도 :: 서버가 받는다 || 앞에서 끊긴다
나가는 통신 :: 아무 데나 || 허용한 곳만
= 공격이 닿을 수 있는 면을 줄이는 것이 방화벽이 하는 일이다
```

인터넷에 그대로 놓인 서버에는 쉬지 않고 접속 시도가 들어온다. 원격 접속이나 데이터베이스 포트처럼 알려진 자리를 자동화된 도구가 계속 두드린다. 열려 있는 포트가 많을수록 그중 하나가 뚫릴 여지도 커진다.

방화벽은 필요한 포트만 열고 나머지를 닫는다. 나가는 쪽도 마찬가지다. 안에서 밖으로 나가는 통신을 제한해두면 악성 프로그램이 데이터를 외부로 보내려 할 때 그 자리에서 막힌다.

## ⚙️ 작동 원리

가장 단순한 방화벽은 패킷 하나만 보고 판단한다. 그러면 우리 쪽에서 먼저 요청한 통신의 응답까지도 밖에서 들어온 낯선 접속처럼 보인다.

상태 기반 방화벽은 지금 열려 있는 연결 목록을 들고 있다. 안에서 나간 요청을 기억해두고 그에 대한 응답이 돌아오면 같은 연결로 보고 통과시킨다. 밖에서 먼저 걸어온 연결만 새 접속으로 판단해 규칙을 적용한다.

내용까지 보는 것은 다른 층의 일이다. 웹 포트로 들어오는 요청 자체는 통과시키되 그 안에 든 공격 문자열을 걸러내려면, 애플리케이션 계층에서 내용을 읽는 방화벽이 따로 필요하다.

## 💡 실제 사례

- **서버 앞 접근 제한** — 웹 포트만 열어두고 관리용 접속은 정해진 주소에서만 되게 한다.
- **클라우드 인스턴스** — 어떤 포트로 누가 들어올 수 있는지 목록으로 지정하고, 적지 않은 것은 전부 막는다.
- **웹 공격 차단** — 요청 내용을 읽는 방화벽을 앞에 두고 주입 공격이나 스크립트 삽입 시도를 걸러낸다.

## 📊 비교

| | Firewall | Reverse Proxy |
|---|---|---|
| 자리 | 네트워크 경계 | 서버 앞 |
| 하는 일 | 통과 여부를 정한다 | 요청을 받아 뒤로 넘긴다 |
| 보는 것 | 주소, 포트, 연결 상태 | 요청 내용과 경로 |
| 목적 | 접근 차단 | 분산과 대리 응답 |

## 🚫 흔한 오해

- **방화벽이 있으면 해킹당하지 않는다** — 열어둔 포트로 들어오는 공격은 그대로 통과한다. 웹 서비스를 하려면 웹 포트는 열어둬야 하고, 그 안에서 벌어지는 일은 다른 방어가 맡는다.
- **바이러스도 방화벽이 잡아준다** — 방화벽은 통신을 보는 장치다. 파일 안의 악성 코드를 판별하는 일과는 다르다.
- **밖에서 들어오는 것만 막으면 된다** — 나가는 통신을 안 보면 정보 유출과 악성 프로그램의 외부 연결을 못 막는다.

## 🚨 주의사항

- **규칙 순서가 결과를 바꾼다.** 위에서부터 읽고 처음 맞는 규칙에서 멈추기 때문에, 넓게 허용하는 규칙이 위에 있으면 아래의 차단 규칙은 읽히지도 않는다.
- **암호화된 통신은 내용을 볼 수 없다.** 겉의 주소와 포트만 보인다. 내용을 봐야 한다면 따로 풀어보는 지점을 둬야 한다.

## 📝 정리

Firewall은 오가는 통신을 규칙과 맞춰보고 통과시킬지 정하는 장치다. 필요한 것만 열어 공격이 닿는 면을 줄이는 것이 목적이고, 열어둔 통로로 들어오는 것까지 막아주지는 않는다.
