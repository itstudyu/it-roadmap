# NAT (Network Address Translation)

## 📝 정의

NAT는 **사설 IP를 공인 IP로 바꿔주는 기술**이다.

집이나 회사 안의 기기들은 안에서만 통하는 주소를 쓴다. 그 주소로는 밖에 나갈 수 없으므로, 공유기가 자기 공인 IP로 바꿔 내보내고 돌아온 응답을 원래 기기로 되돌린다. 1994년에 IP 주소 부족을 넘기려고 만든 것이 지금도 거의 모든 가정과 기업 네트워크에서 쓰이고 있다.

### 비유
회사 대표 전화번호. 밖에서는 대표번호 하나만 보이고 안에서는 각자 내선번호를 쓴다. 교환대가 둘 사이를 이어준다.

## 🖼️ 그림으로 보기

```도해
흐름: 집 안 PC 가 보낸 요청은 어떻게 되돌아오나
PC :: 출발지 192.168.1.10 으로 요청을 만든다
공유기 :: 어느 기기가 보냈는지 표에 적어둔다
공유기 :: 출발지를 203.0.113.5 로 바꿔 내보낸다
인터넷 서버 :: 203.0.113.5 로 답을 보낸다
공유기 :: 표를 뒤져 원래 기기를 찾는다
< PC :: 목적지가 자기 주소로 바뀐 답을 받는다
= 밖에서는 공유기 하나만 보이고 안에 몇 대가 있는지는 드러나지 않는다
```

## ⚠️ 해결하는 문제

```도해
대조: 기기마다 공인 IP 를 줘야 한다면 무엇이 달라지나
NAT 없이 || NAT 로
필요한 주소 :: 기기 수만큼 || 집마다 하나
기기 추가 :: 주소를 새로 받음 || 공유기가 준다
외부 노출 :: 전부 직접 보임 || 공유기만 보임
= 주소를 아끼려고 만든 것인데 안을 가려주는 효과가 따라왔다
```

IPv4 주소는 약 43억 개다. 인터넷 초기에는 넉넉해 보였지만 스마트폰과 IoT 기기가 늘면서 기기마다 하나씩 주는 방식으로는 감당이 안 됐다. 집집마다 노트북, 스마트폰, 프린터, TV 가 각자 공인 IP를 받아야 한다면 주소는 금방 바닥난다.

NAT는 밖으로 나가는 주소를 하나로 모아 이 문제를 미룬다. 집 한 채에 공인 IP 하나면 안에 기기가 몇 대든 상관없다. IPv6로 완전히 옮겨갈 때까지의 임시 방편으로 시작했는데, 아직 그 자리에 있다.

## ⚙️ 작동 원리

바꾸는 방향에 따라 이름이 둘이다.

```도해
층: NAT 는 무엇을 바꾸나
SNAT :: 나갈 때 출발지를 공유기 주소로
DNAT :: 들어올 때 목적지를 내부 기기로
NAT 테이블 :: 어느 기기의 어느 연결인지 적어둔 표
= 표에 적힌 연결만 되돌아올 수 있다. 밖에서 먼저 못 들어오는 이유가 이것이다
```

SNAT는 안에서 밖으로 나가는 요청의 출발지를 바꾼다. 192.168.1.100 인 기기가 접속을 시도하면 공유기가 출발지를 자기 공인 IP인 203.0.113.5 로 바꿔 내보낸다. 상대 서버는 203.0.113.5 에서 온 요청으로 알고 그 주소로 답한다.

DNAT는 반대다. 밖에서 온 요청의 목적지를 안쪽 기기로 바꾼다. 회사가 웹 서버를 운영할 때 외부 사용자는 회사 공인 IP로 접속하지만, 라우터가 그 요청을 192.168.1.50 으로 넘긴다. 포트 포워딩이 이 방식을 쓴 것이다.

공유기는 나간 연결을 표에 적어둔다. 응답이 오면 표를 뒤져 원래 기기로 되돌리고, 표에 없는 것은 되돌릴 곳을 모르므로 버린다.

## 📊 비교: NAT vs IPv6

| | NAT | IPv6 |
|---|---|---|
| 주소 | 사설 IP를 공인 IP로 변환 | 기기마다 고유 주소 |
| 동작 위치 | 라우터, 방화벽 | 네트워크 계층 자체 |
| 밖에서 접속 | 포트 포워딩이 필요 | 그냥 된다 |
| P2P 통신 | STUN, TURN 이 필요 | 그대로 된다 |
| 방화벽 | 안 막아도 어느 정도 가려짐 | 따로 세워야 한다 |

## 💡 실제 사례

- **집 공유기** — 노트북, 스마트폰, TV가 공인 IP 하나로 인터넷에 나간다. ISP는 그 집에 주소 하나만 준다.
- **회사 웹 서버** — 외부 요청을 게이트웨이가 받아 내부의 192.168.0.50 으로 넘긴다. 서버 자체는 밖에 노출되지 않는다.
- **화상 통화 연결 실패** — 양쪽 다 NAT 뒤에 있으면 서로 먼저 들어갈 수 없어서 STUN이나 TURN 서버를 거쳐야 붙는다.

## 🚫 흔한 오해

- **NAT가 방화벽이다** — 밖에서 못 들어오는 건 막아서가 아니라 되돌릴 주소를 몰라서 생기는 부수 효과다. 나가는 연결과 그 응답은 아무것도 검사하지 않는다.
- **공인 IP가 같으면 같은 컴퓨터다** — 한 집, 한 회사, 한 카페의 기기 수십 대가 같은 공인 IP로 보인다. 밖에서는 안에 몇 대가 있는지 구분할 수 없다.
- **IPv6로 바꾸면 NAT는 그냥 필요 없어진다** — 주소를 아끼려는 이유는 사라지지만, 덤으로 얻던 가림막도 같이 사라진다. 방화벽을 따로 세워야 한다.

## 🚨 주의사항

- **밖에서 접속해야 하는 서비스는 포트 포워딩을 따로 연다.** 안에서 서버를 띄웠는데 밖에서 안 보이면 대개 이것이 빠져 있다.
- **동시 연결 수에 한도가 있다.** 공유기가 표에 적어둘 수 있는 만큼만 유지되므로, 기기가 많으면 표가 먼저 찬다.

## 📝 정리

NAT는 사설 IP를 공인 IP로 바꿔 여러 기기가 주소 하나를 나눠 쓰게 하는 기술이다. 나간 연결을 표에 적어뒀다가 돌아온 응답을 원래 기기로 되돌린다. 밖에서 먼저 들어올 수 없는 것은 그 표에 아무것도 없기 때문이고, 필요하면 포트 포워딩으로 길을 낸다.
