# VPN (Virtual Private Network)

## 📝 정의

VPN은 **공용 인터넷 위에 암호화된 전용 통로를 내는 기술**이다.

인터넷은 여러 사람이 같이 쓰는 길이라 오가는 내용이 중간에서 보인다. VPN은 기기에서 나가는 통신을 통째로 암호화해 VPN 서버까지 보내고, 거기서부터 목적지로 이어준다.

### 비유
불투명한 봉투. 우체국 직원은 봉투가 오갔다는 것만 알고 안에 무엇이 적혔는지는 모른다.

## 🖼️ 그림으로 보기

```도해
흐름: VPN 을 켜면 내 요청은 어디를 거쳐 가나
내 기기 :: 보낼 데이터를 나가기 전에 암호화한다
카페 와이파이 :: 오가는 것은 보이지만 읽지는 못한다
VPN 서버 :: 암호를 풀어 원래 요청을 꺼낸다
웹사이트 :: VPN 서버의 IP 에서 온 요청으로 본다
< VPN 서버 :: 응답을 다시 암호화해 돌려보낸다
= 중간에서 알 수 있는 것은 "VPN 서버와 통신했다" 까지다
```

## ⚠️ 해결하는 문제

```도해
대조: 공용 와이파이에서 그냥 접속하면 어떻게 되나
VPN 없이 || VPN 으로
가로챈 사람 :: 내용을 읽는다 || 암호만 본다
ISP 가 보는 것 :: 방문한 사이트 || 접속했다는 것
사이트가 보는 IP :: 내 실제 IP || VPN 서버 IP
= 같은 길로 가되 안이 안 보이는 겉포장을 씌우는 것이다
```

카페나 공항의 무료 와이파이는 누구나 붙을 수 있고 오가는 내용을 가리지 않는다. 같은 와이파이에 있는 사람이 통신을 잡아 아이디나 카드 번호를 꺼내갈 수 있다. 회선을 제공하는 쪽이나 회사 관리자도 어떤 사이트에 다녀왔는지 볼 수 있는 자리에 있다.

VPN을 켜면 나가는 통신이 전부 암호화된다. 같은 길로 가지만 중간에서는 봉투 겉면만 보이고, 도착지 입장에서는 VPN 서버가 보낸 것으로 보인다. 회사가 VPN을 두는 이유도 같다. 집에서 붙어도 사무실 안에 있는 것처럼 내부 서버에 닿게 하려는 것이다.

## ⚙️ 작동 원리

```도해
층: VPN 은 무엇을 켜켜이 쌓아 만드나
인증 :: 누가 붙는지 먼저 확인한다
키 교환 :: 양쪽이 같은 암호 열쇠를 나눠 갖는다
터널 :: 그 열쇠로 감싼 통로가 선다
트래픽 :: 기기에서 나가는 통신이 전부 그 안으로 들어간다
= 아래는 위가 있어야 선다. 인증과 키 교환이 먼저인 이유다
```

암호화 자체는 AES-256 같은 방식으로 한다. 그 위에서 어떻게 주고받을지를 정하는 것이 프로토콜이고, 오래된 PPTP부터 널리 쓰이는 OpenVPN, 끊겼다 붙을 때 빠른 IKEv2, 가볍게 설계된 WireGuard까지 여러 가지가 있다.

목적지에서 보이는 IP가 VPN 서버 것으로 바뀌는 것은 암호화의 결과가 아니라 요청이 그 서버를 거쳐 나가기 때문이다. 다른 나라 서버를 고르면 그 나라에서 접속한 것으로 보이는 것도 같은 이유다.

## 💡 실제 사례

- **원격 근무** — 집에서 회사 VPN에 붙으면 사무실 안에 있는 것처럼 내부 파일 서버와 시스템에 닿는다.
- **공용 와이파이** — 카페나 공항에서 켜두면 같은 와이파이에 있는 사람이 통신을 잡아도 읽지 못한다.
- **지역 제한** — 다른 나라의 서버를 거치면 사이트는 그 나라에서 접속한 것으로 인식한다.

## 🚫 흔한 오해

- **VPN을 켜면 완전히 익명이 된다** — 가려지는 상대는 회선 사업자와 접속한 사이트까지다. VPN 제공자는 누가 어디로 갔는지 볼 수 있는 자리에 있고, 그쪽이 기록을 남기면 그대로 남는다.
- **VPN을 켜면 해킹당하지 않는다** — 오가는 길을 가리는 기술이다. 비밀번호가 새거나 악성 파일을 내려받는 일은 VPN과 상관없이 그대로 일어난다.
- **VPN을 쓰면 인터넷이 빨라진다** — 오히려 느려진다. 암호를 씌우고 푸는 시간에 서버를 한 번 더 거치는 거리까지 붙어서 보통 10~30% 떨어진다.

## 📊 비교

| | VPN | 프록시 |
|---|---|---|
| 암호화 | 기본으로 한다 | 보장하지 않는다 |
| 적용 범위 | 기기에서 나가는 전부 | 설정한 앱만 |
| 보이는 IP | 서버의 IP | 서버의 IP |
| 속도 | 10~30% 떨어진다 | 덜 떨어진다 |

## 🚨 주의사항

- **연결이 끊긴 순간을 대비한다.** 터널이 끊기면 통신이 평소 경로로 그냥 나가므로, 그때 인터넷을 같이 끊는 기능을 켜둔다.
- **VPN 제공자의 기록 정책을 본다.** 안 보면 감시하는 상대를 회선 사업자에서 VPN 업체로 옮긴 것에 그친다.

## 📝 정리

VPN은 기기에서 나가는 통신을 암호화해 VPN 서버까지 보내고 거기서 목적지로 이어주는 기술이다. 중간에서는 내용이 안 보이고 도착지에서는 서버의 IP만 보이지만, VPN 제공자는 그 안을 볼 수 있는 자리에 있다.
