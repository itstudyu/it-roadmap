# SDK (Software Development Kit)

## 📝 정의

SDK는 **한 플랫폼에서 개발하는 데 필요한 것을 묶어 놓은 꾸러미**다.

라이브러리만 들어 있는 게 아니다. 부를 수 있는 함수를 정해 놓은 API 규격, 그 규격을 설명한 문서, 컴파일러와 디버거와 에뮬레이터(실제 기기를 흉내 내 컴퓨터에서 돌려보게 하는 프로그램) 같은 도구가 함께 온다.

### 비유
요리 도구 세트. 칼과 냄비만이 아니라 불 조절기와 레시피 책까지 한 상자에 들어 있다.

### 예
안드로이드 앱을 만들어 보려고 개발 도구를 깔 때 한참을 내려받게 되는 그 덩어리가 이것이다.

## 🖼️ 그림으로 보기

```도해
흐름: SDK 함수를 하나 부르면 어디까지 내려가나
내 앱 :: 사진을 찍어달라고 SDK 함수를 부른다
SDK :: 그 요청을 플랫폼이 아는 형태로 바꾼다
운영체제 :: 카메라 드라이버를 실제로 움직인다
카메라 :: 사진을 찍어 데이터를 올려 보낸다
< 내 앱 :: 사진 한 장을 결과로 받는다
= 드라이버를 다루는 코드를 내가 쓰지 않아도 되는 이유다
```

## ⚠️ 해결하는 문제

```도해
대조: 플랫폼 기능을 직접 다루면 어떻게 되나
SDK 없이 || SDK 로
기능 하나 :: 규격부터 읽는다 || 함수 하나 호출
테스트 :: 실기기가 필요 || 에뮬레이터로
플랫폼 갱신 :: 직접 따라간다 || 버전 올리면 끝
= 속사정을 감춰 주는 대신 그 플랫폼에 묶인다
```

플랫폼마다 구조와 규칙이 다르다. GPS 값 하나를 받으려 해도 그 플랫폼이 정한 규격을 읽고, 권한을 어떻게 받는지 알아내고, 돌아오는 형식을 맞춰야 한다. 기기가 없으면 돌려볼 수도 없다.

SDK 는 그 과정을 함수 뒤로 감춘다. 위치 API 를 부르면 몇 줄로 값을 받고, 에뮬레이터가 있어서 실기기 없이 확인한다. 플랫폼이 갱신되면 SDK 버전을 올리는 것으로 대부분 따라간다.

## 🧱 구성

```도해
층: 내 코드와 하드웨어 사이에는 무엇이 있나
내 앱 :: 내가 쓴 코드
SDK 라이브러리 :: 플랫폼 기능을 함수로 감싸 놓은 것
플랫폼 API :: 운영체제가 정해 놓은 실제 규격
드라이버 :: 하드웨어를 직접 다루는 자리
= 한 층 아래를 몰라도 되게 만드는 것이 SDK 가 서 있는 이유다
```

## ⚙️ 작동 원리

내가 부르는 것은 맨 위의 두 층뿐이다. SDK 라이브러리가 아래 규격에 맞춰 요청을 만들어 넘기고, 결과를 다시 내가 다루기 쉬운 형태로 바꿔 돌려준다.

완성한 앱을 플랫폼이 이해하는 형태로 바꾸는 컴파일러도 대개 SDK 안에 있다. 그래서 SDK 는 개발 중에만 쓰는 게 아니라 내보내는 단계까지 걸쳐 있다.

## 📊 비교: SDK vs API vs 라이브러리 vs 프레임워크

| | SDK | API | 라이브러리 | 프레임워크 |
|---|---|---|---|---|
| 범위 | 도구, 코드, 문서까지 | 부르는 규격만 | 코드 모음 | 앱 전체 구조 |
| 묶이는 정도 | 그 플랫폼에 묶인다 | 없다 | 선택 사항 | 높다 |
| 예 | Android SDK | REST API | NumPy | Django |

## 💡 실제 사례

- **Android SDK** — 위치 API 를 불러 몇 줄로 GPS 값을 받고, 에뮬레이터로 실기기 없이 돌려본다.
- **AWS SDK** — HTTP 요청을 직접 짜는 대신 메서드 호출로 스토리지나 DB 를 다룬다.
- **에뮬레이터 테스트** — 기기를 사기 전에 화면 크기와 OS 버전을 바꿔가며 미리 확인한다.

## 🚫 흔한 오해

- **SDK 와 API 는 같은 말이다** — API 는 부르는 규격이고 SDK 는 그 규격을 구현한 코드에 도구와 문서까지 얹은 상자다. SDK 안에 API 가 들어 있다.
- **SDK 를 쓰면 앱이 가벼워진다** — 내가 쓸 코드가 줄어드는 것이지 결과물이 작아지는 건 아니다. 안 쓰는 기능까지 딸려 와서 용량이 커지기도 한다.
- **SDK 만 깔면 어느 플랫폼에서든 돌아간다** — SDK 는 특정 플랫폼용으로 만들어진 것이다. 다른 플랫폼으로 옮기면 그쪽 SDK 를 새로 배워야 한다.

## 📝 정리

SDK는 한 플랫폼에서 개발하는 데 필요한 라이브러리와 도구와 문서를 묶어 놓은 꾸러미다. 플랫폼의 속사정을 함수 뒤로 감춰서 내가 써야 할 코드를 줄여준다. 감춰 주는 대가로 그 플랫폼에 묶인다.
