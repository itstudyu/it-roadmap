# IDE (Integrated Development Environment)

## 📝 정의

IDE는 **개발에 쓰는 도구를 한 화면에 모아둔 프로그램**이다.

편집기, 디버거, 터미널, 버전 관리가 따로 놀면 하나를 확인할 때마다 창을 바꿔야 한다. IDE는 그것들을 같은 창에 붙여두고 서로 연결해 둔다.

### 비유
공구를 전부 벽에 걸어둔 작업대. 톱을 쓰려고 창고까지 다녀오지 않아도 손 닿는 데 다 있다.

## 🖼️ 그림으로 보기

```도해
흐름: 오류 하나를 IDE 안에서 어떻게 잡나
편집기 :: 치는 도중에 빨간 줄이 먼저 뜬다
중단점 :: 의심 가는 줄에 표시를 찍는다
실행 :: 그 줄에서 프로그램이 멈춘다
변수 창 :: 멈춘 순간의 값들이 그대로 보인다
한 줄씩 :: 다음 줄로 넘기며 값이 언제 틀어지는지 본다
@ 편집기 :: 고치고 다시 돌린다. 창을 바꾼 적이 없다
= 확인과 수정 사이가 끊기지 않는 것이 IDE 가 파는 것이다
```

## ⚠️ 해결하는 문제

```도해
대조: 편집기 하나만 놓고 개발하면 무엇이 번거로운가
에디터만 || IDE 로
오류 확인 :: 실행해야 안다 || 치는 중에 뜬다
값 들여다보기 :: print 를 넣는다 || 멈춰서 본다
도구 전환 :: 창을 계속 바꾼다 || 한 화면에서
= 확인에 드는 시간이 줄어야 고치는 데 시간을 쓸 수 있다
```

편집기만 있으면 코드가 맞는지는 돌려봐야 안다. 값이 이상하면 `print`를 넣고 다시 돌리고 로그를 보고 지운다. 한 번 확인할 때마다 이 왕복이 붙는다.

IDE는 그 왕복을 줄인다. 문법 오류는 타이핑하는 중에 표시되고, 값은 실행을 멈춘 자리에서 바로 들여다본다. 터미널과 Git이 같은 창에 있으니 확인하려고 다른 프로그램을 띄우지 않는다.

## ⚙️ 작동 원리

```도해
층: IDE 는 내 코드를 어디까지 들여다보나
편집기 :: 글자 그대로. 친 대로 화면에 뜬다
분석기 :: 어떤 이름이 무엇을 가리키는지까지 안다
디버거 :: 실행을 세워 그 순간의 값까지 본다
= 글자만 보면 이름 바꾸기가 문자열 치환이고, 뜻까지 보면 다른 변수를 안 건드린다
```

자동완성이 그럴듯한 후보를 내놓는 건 분석기가 지금 위치에서 쓸 수 있는 이름과 타입을 알기 때문이다. 이름 바꾸기가 안전한 것도 같은 이유다. 글자가 같아도 다른 변수면 건드리지 않는다.

디버거는 실행을 중단점에서 세워두고 그 시점의 변수를 보여준다. 한 줄씩 넘기며 값이 어느 줄에서 틀어지는지 좁혀갈 수 있다.

## 💡 실제 사례

- **여러 폴더를 한 창에** — 백엔드와 프론트엔드를 같이 열어두고 터미널을 나눠 각각 돌린다.
- **이름 바꾸기** — 변수 이름을 한 곳에서 고치면 쓰이는 곳이 전부 따라 바뀐다.
- **Git 연동** — 바뀐 파일과 변경 전후를 사이드바에서 보고 그 자리에서 커밋한다.

## 🚫 흔한 오해

- **IDE는 기능 많은 텍스트 에디터다** — 글자를 담아두는 것과 코드를 이해하는 것은 다르다. IDE는 어떤 이름이 무엇을 가리키는지 알고 있어서, 이름 바꾸기가 문자열 찾아 바꾸기와 달리 엉뚱한 곳을 건드리지 않는다.
- **IDE를 쓰면 터미널은 몰라도 된다** — 버튼으로 되는 건 내 컴퓨터 안에서다. 서버에 접속하거나 CI 설정을 고칠 때는 같은 일을 명령으로 해야 한다.
- **무거운 IDE가 항상 낫다** — PyCharm은 메모리를 2~4GB 쓴다. 작은 스크립트 하나 고치는 데 그 값을 치를 이유는 없다.

## 📊 비교

| | IDE | 텍스트 에디터 |
|---|---|---|
| 자동완성 | 코드를 분석해서 낸다 | 나온 단어를 다시 보여준다 |
| 디버깅 | 창 안에 있다 | 따로 붙여야 한다 |
| 무게 | 메모리를 많이 쓴다 | 가볍다 |
| 어디에 맞나 | 오래 붙잡을 프로젝트 | 한두 파일 빠른 수정 |

## 🚨 주의사항

- **처음 켠 IDE는 그대로 쓸 수 없다.** 인터프리터 경로와 린터(돌려보지 않고 코드의 문제를 짚어주는 검사기)를 잡아줘야 자동완성과 오류 표시가 제대로 나온다.
- **확장을 무한정 늘리지 않는다.** 켜지는 시간과 메모리가 그만큼 늘고, 저사양 장비에서는 편집기보다 느려진다.

## 📝 정리

IDE는 편집, 실행, 디버깅, 버전 관리를 한 창에 모아 확인과 수정 사이의 왕복을 없앤 프로그램이다. 자동완성과 이름 바꾸기가 되는 것은 코드를 실제로 분석하기 때문이고, 그 분석 값이 메모리와 켜지는 시간이다.

## ❓ 이해했는지

- 변수에 언제 이상한 값이 들어갔는지 `print` 없이 어떻게 찾나 → 그림
- IDE의 이름 바꾸기가 문자열 찾아 바꾸기와 다른 점은 → 작동 원리
- IDE만 쓰다가 서버에 접속했을 때 막히는 이유는 → 흔한 오해
