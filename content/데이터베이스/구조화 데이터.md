# 구조화 데이터

## 📝 정의

구조화 데이터는 **정해진 형식과 규칙에 따라 조직화된 데이터**입니다. 표(테이블) 형태로 저장되며 각 열이 명확한 의미를 가집니다.

### 핵심 개념

- **무엇인가?**: 엑셀처럼 행과 열로 정리된 데이터
- **왜 필요한가?**: 검색, 분석, 관리가 쉬움
- **어떻게 작동하나?**: 스키마 정의 → 데이터 입력 → SQL로 조회

### 구조화 데이터가 해결하는 문제

**문제 상황**:
```
😱 시나리오 1: 비구조화 데이터
고객 정보가 텍스트 파일에 뒤죽박죽
→ "김철수, 010-1234-5678, 서울"
→ 검색 불가능! 😱

😱 시나리오 2: 일관성 없음
나이를 "25"로도, "스물다섯"으로도 입력
→ 집계 불가능
→ 분석 불가! 😱
```

**구조화 데이터의 해결**:
```
✅ 테이블 구조:
| name   | phone         | city |
|--------|---------------|------|
| 김철수  | 010-1234-5678 | 서울 |

→ SQL로 쉽게 검색
→ 집계 가능! ✅
```

**비유**:
- **비구조화** = 서랍에 아무렇게나 넣음
- **구조화** = 정리함에 분류해서 보관

## 📊 구조화 vs 비구조화

| 유형 | 구조화 | 반구조화 | 비구조화 |
|------|--------|---------|---------|
| **형태** | 테이블 | JSON, XML | 텍스트, 이미지 |
| **예시** | SQL DB | NoSQL | 문서, 동영상 |
| **검색** | 쉬움 | 중간 | 어려움 |
| **분석** | 쉬움 | 가능 | 어려움 |

## 💡 구조화 데이터 예시

```sql
-- 구조화된 고객 테이블
CREATE TABLE customers (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    age INT,
    email VARCHAR(255),
    created_at TIMESTAMP
);

-- 쉬운 검색
SELECT * FROM customers WHERE age > 30;

-- 쉬운 집계
SELECT AVG(age) FROM customers;
```
