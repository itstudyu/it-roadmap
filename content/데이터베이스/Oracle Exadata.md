# Oracle Exadata

## 📝 정의

Oracle Exadata는 **오라클 데이터베이스에 최적화된 고성능 하드웨어 시스템**입니다. 데이터베이스와 스토리지를 통합하여 극한의 성능을 제공합니다.

### 핵심 개념

- **무엇인가?**: 오라클 DB 전용 슈퍼컴퓨터
- **왜 필요한가?**: 초대용량 데이터, 초고속 처리 필요
- **어떻게 작동하나?**: DB 서버 + 스토리지 서버 통합 최적화

### Exadata가 해결하는 문제

**문제 상황**:
```
😱 시나리오 1: 쿼리가 너무 느림
일반 서버에서 대용량 집계
→ 1시간 소요
→ 실시간 분석 불가! 😱

😱 시나리오 2: 스토리지 병목
DB 서버는 빠른데 디스크 I/O 느림
→ 성능 저하
→ 투자 낭비! 😱
```

**Exadata의 해결**:
```
✅ Smart Scan 기술:
필요한 데이터만 스토리지에서 필터링
→ 네트워크 부하 10배 감소
→ 쿼리 10배 빠름! ✅

✅ Flash Cache:
자주 쓰는 데이터 → SSD에 캐싱
→ I/O 100배 빠름
→ 실시간 분석 가능! ✅
```

**비유**:
- **일반 서버** = 일반 PC (범용)
- **Exadata** = 슈퍼컴퓨터 (특화)

## 📊 주요 기능

### 1. Smart Scan
```sql
-- 10억 건 중 100만 건 조회
SELECT * FROM orders WHERE amount > 10000;

-- 일반 DB: 10억 건 모두 전송 → DB 서버에서 필터링
-- Exadata: 스토리지에서 100만 건만 전송 → 10배 빠름
```

### 2. Hybrid Columnar Compression
```
원본: 1TB
압축: 100GB (10배 압축)
→ 저장 비용 절감 + 쿼리 빠름
```
