# CSV (Comma-Separated Values)

## 📝 정의

CSV는 **쉼표로 값을 나눈 표 데이터 텍스트 파일**이다.

줄 바꿈이 행을 나누고 쉼표가 열을 나눈다. 규칙이 이것뿐이라 특별한 프로그램 없이도 열리고 만들 수 있다.

### 비유
손으로 적은 장부. 한 줄에 한 건씩 쓰고 항목 사이는 쉼표로만 띄어 놓는다.

## 🖼️ 그림으로 보기

```도해
흐름: 텍스트 한 덩어리가 어떻게 표가 되나
첫 줄 :: 열 이름을 쉼표로 나열한다
둘째 줄 :: 값을 같은 순서로 나열한다
읽는 쪽 :: 쉼표를 만나면 다음 칸으로 넘긴다
읽는 쪽 :: 따옴표 안의 쉼표는 값으로 본다
읽는 쪽 :: 줄 바꿈을 만나면 다음 행으로 넘긴다
= 규칙이 이것뿐이라 어디서나 열리고, 담을 수 있는 것도 이것뿐이다
```

## ⚠️ 해결하는 문제

```도해
대조: 표를 프로그램마다 다른 형식으로 주고받으면 어떻게 되나
전용 형식 || CSV
여는 도구 :: 만든 앱만 || 거의 다 열림
파일 크기 :: 서식까지 담김 || 값만 담긴다
직접 열기 :: 전용 뷰어 필요 || 메모장으로
= 서식을 버리는 대신 어디서나 열리는 것을 얻는다
```

표 데이터를 주고받을 때 형식이 저마다 다르면 받는 쪽은 그 프로그램을 갖고 있어야 한다. 버전이 다르면 열리지 않는 일도 생긴다.

CSV는 그냥 텍스트다. 서식과 수식과 시트 구분을 전부 버린 대신, 표 프로그램부터 스크립트까지 무엇으로든 읽을 수 있다.

## 💡 실제 사례

- **대량 등록** — 담당자가 표 프로그램에서 내보낸 CSV를 그대로 올려 수백 건을 한 번에 등록한다.
- **분석 입력** — 데이터베이스에서 뽑은 조회 결과를 CSV로 저장해 분석 도구에 바로 넣는다.
- **내려받기 버튼** — 조회 화면 결과를 CSV로 내려받게 해두면 사용자가 알아서 가공한다.

## 🚫 흔한 오해

- **쉼표로 자르면 되니까 읽는 코드는 직접 짜도 된다** — 값 안에 쉼표나 줄 바꿈이 들어 있으면 직접 짠 코드는 대개 거기서 깨진다. 따옴표 처리 규칙 때문에 라이브러리를 쓴다.
- **표 프로그램에서 열리니까 엑셀 파일이다** — 서식도 수식도 시트도 없는 텍스트다. 열었다가 저장하면 원래 있던 그런 것들이 사라진다.
- **CSV면 어디서나 똑같이 읽힌다** — 구분자가 쉼표가 아닌 파일도 있고, 인코딩이 다르면 한글이 깨진다. 형식이 하나로 못 박혀 있지 않다.

## 📊 비교

| | CSV | JSON |
|---|---|---|
| 담는 모양 | 표 하나 | 중첩된 구조 |
| 크기 | 값만 담아 작다 | 키가 매번 붙어 크다 |
| 사람이 읽기 | 표 프로그램에서 편하다 | 구조가 눈에 보인다 |
| 맞는 데이터 | 같은 모양이 반복되는 것 | 항목마다 모양이 다른 것 |

## 🚨 주의사항

- **값에 쉼표가 있으면 따옴표로 감싼다.** `"Smith, John"` 처럼 감싸지 않으면 한 값이 두 칸으로 잘린다.
- **인코딩을 맞춘다.** 저장한 인코딩과 여는 인코딩이 다르면 한글이 전부 깨진다.

## 📝 정리

CSV는 줄 바꿈으로 행을, 쉼표로 열을 나누는 텍스트 형식이다. 규칙이 적어서 거의 모든 도구가 읽지만 중첩된 구조나 서식은 담지 못한다.

## ❓ 이해했는지

- 값 안에 쉼표가 들어 있는 파일을 직접 자르는 코드로 읽으면 무엇이 잘못되나 → 흔한 오해
- 표 프로그램에서 CSV를 열어 저장했더니 수식이 사라졌다면 왜 그런가 → 해결하는 문제
- 항목마다 들어 있는 필드가 다른 데이터를 CSV로 담기 어려운 이유는 → 비교
