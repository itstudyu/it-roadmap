# TTL (Time To Live)

## 📝 정의

TTL은 **데이터가 유효한 시간**입니다. 만료되면 자동으로 삭제됩니다.

### 핵심 개념

- **무엇인가?**: 자동 만료 시간
- **왜 필요한가?**: 오래된 데이터 자동 정리
- **단위**: 초 (seconds)

## 💡 사용 예시

```python
import redis
r = redis.Redis()

# TTL 1시간
r.setex('session:user123', 3600, 'active')

# TTL 1일
r.setex('faq:급여일', 86400, '매월 25일')

# TTL 확인
ttl = r.ttl('session:user123')  # 3600초 (1시간)
```

## 🔍 캐시 무효화

```
시간 0초: 데이터 저장 (TTL 3600초)
시간 1800초: 데이터 아직 유효
시간 3600초: TTL 만료 → 자동 삭제
시간 3601초: 캐시 미스 → DB 재조회
```

## 📝 정리

**TTL = 유통기한**
- 3600 = 1시간
- 86400 = 1일
- 만료 시 자동 삭제
