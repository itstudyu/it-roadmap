# Apache (아파치 웹 서버)

## 📝 정의

Apache는 **HTTP 요청을 받아 웹 페이지를 돌려주는 오픈소스 서버**다.

브라우저가 주소를 보내면 누군가는 그 주소에 맞는 파일을 골라 돌려줘야 한다. 그 일을 하는 프로그램을 웹 서버라고 하고, Apache는 그중 오래 쓰여온 쪽이다.

### 비유
건물 안내데스크. 몇 호를 찾는지 말하면 그 방으로 안내하고, 없는 호수를 대면 없다고 알려준다.

## 🖼️ 그림으로 보기

```도해
흐름: 주소를 치면 Apache 는 무엇을 하나
브라우저 :: GET /about.html 을 보낸다
Apache :: 어느 VirtualHost 담당인지 고른다
Apache :: DocumentRoot 아래에서 파일을 찾는다
Apache :: 그 폴더의 .htaccess 규칙을 적용한다
< Apache :: 찾은 내용을 응답으로 돌려준다
= 요청 하나를 파일 하나로 바꿔주는 것이 웹 서버가 하는 일이다
```

## ⚠️ 해결하는 문제

```도해
대조: 웹 서버 없이 파일만 두면 어떻게 되나
웹 서버 없이 || Apache 로
외부 접근 :: 열 방법이 없다 || 80 포트로 연다
도메인 여러 개 :: 서버도 여러 대 || 설정으로 나눈다
접근 제한 :: 직접 짜야 한다 || 규칙으로 건다
= 파일을 인터넷에 내놓는 데 필요한 일들을 한 프로그램이 맡는다
```

디스크에 HTML 파일이 있다고 해서 남이 볼 수 있는 것은 아니다. 포트를 열고, 들어온 주소를 해석하고, 어떤 파일을 어떤 형식으로 돌려줄지 정하는 과정이 그 사이에 있다.

Apache는 그 과정을 설정 파일로 다룬다. 도메인마다 다른 폴더를 물려주는 것도, 특정 폴더만 잠그는 것도 코드가 아니라 설정으로 정한다.

## ⚙️ 작동 원리

설정은 범위가 넓은 것부터 좁은 것 순으로 겹친다.

```도해
층: 요청 하나가 어느 설정까지 훑고 지나가나
VirtualHost :: 어느 도메인 담당인지. 서버 전체 설정
Directory :: 그 폴더에 걸린 규칙. 아래를 열지 말지 정한다
.htaccess :: 폴더마다 두는 파일. 요청마다 다시 읽는다
= 아래로 갈수록 좁은 범위를 덮어쓴다. .htaccess 가 마지막이다
```

`VirtualHost`는 하나의 서버가 여러 도메인을 받을 수 있게 한다. 같은 IP로 들어온 요청이라도 어떤 도메인으로 왔는지에 따라 다른 `DocumentRoot`를 보게 된다.

`.htaccess`는 폴더에 놓아두는 설정 파일이다. 서버 설정과 달리 요청이 올 때마다 다시 읽히기 때문에, 서버를 재시작할 권한이 없는 사람도 자기 폴더의 규칙을 바꿀 수 있다.

## 💡 실제 사례

- **한 대에 여러 사이트** 도메인마다 VirtualHost를 만들어 서버 한 대에 사이트 여러 개를 올린다.
- **폴더 단위 잠그기** 관리자 페이지가 있는 폴더에만 접근 제한을 걸고 나머지는 그대로 연다.
- **주소 바꾸기** 옛 주소로 들어온 요청을 새 주소로 넘기는 규칙을 .htaccess에 적어두고 서버는 건드리지 않는다.

## 🚫 흔한 오해

- **Apache 가 웹사이트를 만들어준다** — 만들지 않는다. 이미 있는 것을 요청에 맞춰 골라 돌려줄 뿐이고, 화면을 만드는 건 그 뒤에 붙은 코드다.
- **설정 파일을 고치면 바로 반영된다** — 서버 설정은 다시 읽혀야 적용된다. 고치자마자 반영되는 건 요청마다 읽는 .htaccess 쪽이다.
- **Nginx 보다 느리니 쓸 이유가 없다** — 느리다는 건 같은 조건에서 잰 처리량 얘기다. 폴더마다 설정을 따로 두는 방식이 필요하거나 이미 그 위에 얹혀 있는 것이 많으면 계속 쓰인다.

## 📝 정리

Apache는 들어온 HTTP 요청을 받아 어떤 내용을 돌려줄지 정하는 웹 서버다. VirtualHost로 도메인을 나누고, Directory와 .htaccess로 폴더마다 규칙을 건다. 화면을 만드는 일은 하지 않고 오가는 길만 맡는다.

## ❓ 이해했는지

- 서버 한 대에 도메인 두 개를 붙였을 때 요청이 서로 다른 폴더로 가는 이유는?
- 설정을 고쳤는데 사이트가 그대로라면 어디를 먼저 확인해야 하나?
- 서버를 재시작할 수 없는 사람이 자기 폴더의 접근 규칙을 바꾸려면 어떻게 하나?
