# VPS (Virtual Private Server)

## 📝 정의

VPS는 **물리 서버 한 대를 쪼개 나눠 쓰는 가상 서버**다.

기계는 여럿이 함께 쓰지만 각자 자기 운영체제와 루트 권한과 IP를 갖는다. 공유 호스팅보다 자유롭고 전용 서버보다 싸서 그 둘 사이를 메운다.

### 비유
공유 오피스 건물의 개별 사무실. 건물과 전기와 복도는 함께 쓰지만 사무실 문은 각자 잠근다.

## 🖼️ 그림으로 보기

```도해
흐름: VPS 하나가 만들어져 손에 들어오기까지 무엇을 거치나
호스팅사 :: 물리 서버에 하이퍼바이저를 올린다
주문 :: 고객이 OS 와 CPU, 메모리, 디스크를 고른다
생성 :: 하이퍼바이저가 자리를 떼어 OS 를 깐다
주소 :: 그 VPS 만 쓰는 IP 를 붙인다
< 전달 :: IP 와 루트 접속 정보를 고객에게 넘긴다
고객 :: SSH 로 들어가 원하는 것을 설치한다
= 여기서부터 관리는 전부 고객 몫이 된다
```

## ⚠️ 해결하는 문제

```도해
대조: 옆 고객에게 트래픽이 몰리면 무엇이 달라지나
공유 호스팅 || VPS
내 사이트 :: 같이 느려짐 || 영향 적음
루트 권한 :: 없다 || 있다
설치 자유 :: 정해진 것만 || 원하는 대로
= 격리가 있으면 옆집 사정이 내 성능을 정하지 않는다
```

공유 호스팅은 물리 서버 한 대에서 수백 개 사이트가 함께 돈다. 옆 사이트에 트래픽이 몰리면 내 사이트도 같이 느려지고, 루트 권한이 없어서 필요한 소프트웨어를 깔 수도 없다.

반대쪽 끝인 전용 서버는 기계 한 대를 혼자 쓴다. 성능과 자유는 가장 좋지만 월 수백 달러가 든다. 이제 시작하는 곳에는 과한 값이다.

VPS는 그 사이에 있다. 하이퍼바이저가 기계를 나눠 각자에게 독립된 OS와 정해진 몫의 CPU, 메모리, 디스크를 준다. 물리 서버 비용은 여러 고객이 나눠 내므로 전용 서버의 십분의 일 수준이 된다.

## ⚙️ 작동 원리

```도해
층: 세 가지 호스팅은 어디가 다른가
공유 호스팅 :: 서버 하나에 OS 하나. 계정만 나눈다
VPS :: 하이퍼바이저 위에 OS 를 여러 개 올린다
전용 서버 :: 물리 서버 한 대에 고객 하나
= 가운데만 OS 가 나뉘어 있다. 루트 권한이 갈리는 지점이 여기다
```

하이퍼바이저는 각 VPS의 몫을 지킨다. CPU는 할당된 만큼만 시간을 받고, 메모리는 정해진 양을 넘으면 스왑(모자란 만큼을 디스크로 밀어내기)하거나 프로세스가 죽는다. 디스크 입출력과 네트워크 대역폭에도 제한이 걸리는 경우가 많다.

호스팅사는 대개 실제 용량보다 많이 판다. 물리 메모리가 64GB인 서버에 16GB짜리 VPS를 여덟 개 올려 128GB를 파는 식이다. 모두가 동시에 최대치를 쓰지는 않는다는 가정 위에 서 있고, 이것을 오버커밋이라고 한다.

## 📊 비교: 공유 호스팅 vs VPS vs 전용 서버

| | 공유 호스팅 | VPS | 전용 서버 |
|---|---|---|---|
| 함께 쓰는 고객 | 수백 | 수십 | 없음 |
| 루트 권한 | 없다 | 있다 | 있다 |
| 월 비용 | $5~20 | $20~100 | $300~1000 |
| 관리 책임 | 호스팅사 | 사용자 | 사용자 |
| 확장 | 어렵다 | 쉽다 | 더 큰 장비로만 |

## 💡 실제 사례

- **작게 시작하기** — 월 5달러짜리로 열고 사용자가 늘면 CPU와 메모리를 올린다. 서버를 옮기지 않고 늘릴 수 있다.
- **환경 분리** — 개발, 스테이징, 운영을 VPS 세 대로 나눈다. 테스트에서 무엇을 하든 운영에 닿지 않는다.
- **역할 분리** — API 서버와 데이터베이스를 각각 다른 VPS에 둔다. 한쪽이 멈춰도 다른 쪽은 살아 있다.

## 🚫 흔한 오해

- **VPS는 내 전용 서버다** — 기계는 다른 고객들과 함께 쓴다. 나뉘어 있는 것은 OS와 할당된 몫이지 물리 장비가 아니다.
- **호스팅사가 알아서 관리해준다** — 호스팅사가 주는 것은 자리까지다. OS 패치, 보안 설정, 백업, 모니터링은 전부 고객이 한다.
- **할당받은 만큼은 늘 그대로 나온다** — 호스팅사가 오버커밋을 하기 때문에, 같은 기계의 VPS들이 동시에 몰아 쓰면 약속된 것보다 낮게 나올 수 있다.

## 🚨 주의사항

- **백업은 스스로 잡아둔다.** 데이터가 날아가도 호스팅사가 대신 되살려주지 않는다.
- **켜자마자 접근 범위부터 좁힌다.** 루트 권한과 공인 IP가 함께 붙어 있어서 설정 하나가 잘못되면 밖에서 바로 닿는다.

## 📝 정리

VPS는 물리 서버 한 대를 하이퍼바이저로 나눠 각자에게 독립된 OS와 루트 권한을 주는 호스팅이다. 공유 호스팅의 제약과 전용 서버의 비용 사이를 메운다. 자유를 얻은 만큼 패치와 백업과 보안이 전부 사용자 몫으로 넘어온다.
