# Windows (윈도우)

## 📝 정의
Windows는 **Microsoft의 운영체제**입니다. 가장 널리 사용되는 데스크톱 OS입니다.

### 핵심 특징
- GUI: 그래픽 인터페이스
- 호환성: 많은 소프트웨어
- 사용성: 초보자 친화적

## 💡 주요 버전

- Windows 10
- Windows 11
- Windows Server (서버용)

## 🎯 특징

```
장점:
- 직관적인 GUI
- 많은 프로그램 지원
- 게임에 유리

단점:
- 유료
- 보안 취약점 많음
- 서버로는 Linux보다 덜 선호
```

## 📊 Windows 기본 도구

```
- 탐색기: 파일 관리
- CMD/PowerShell: 명령줄
- 작업 관리자: 프로세스 관리
```
