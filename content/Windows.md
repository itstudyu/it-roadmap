# Windows (윈도우)

## 📝 정의

Windows는 **마이크로소프트가 만든 데스크톱 운영체제**다.

프로그램과 하드웨어 사이에 서서 창과 파일과 장치를 프로그램에 내준다. 데스크톱에서 가장 널리 쓰이고, 서버용으로 나온 Windows Server가 따로 있다.

### 비유
건물 관리인. 입주자가 전기와 수도를 직접 끌어오지 않고 관리인에게 요청해서 쓴다.

## 🖼️ 그림으로 보기

```도해
흐름: 아이콘을 두 번 누르면 Windows 는 무엇을 하나
탐색기 :: 두 번 눌린 파일이 무엇인지 본다
Windows :: 디스크에서 실행 파일을 읽어 온다
Windows :: 메모리에 자리를 잡고 프로세스로 만든다
Windows :: 창 하나를 화면에 띄워준다
프로그램 :: 그 창 안에 자기 화면을 그린다
작업 관리자 :: 목록에 프로세스가 하나 늘어난다
= 프로그램은 하드웨어를 직접 만지지 않고 늘 Windows 를 거친다
```

## ⚠️ 해결하는 문제

```도해
대조: 운영체제가 없으면 프로그램은 무엇을 해야 하나
OS 없이 || Windows 로
화면 그리기 :: 직접 제어 || 창을 받아 씀
파일 저장 :: 디스크 직접 || 경로만 주면 됨
새 장비 :: 프로그램 수정 || 드라이버만
= 하드웨어가 바뀌어도 프로그램이 그대로 도는 이유가 이것이다
```

운영체제가 없으면 프로그램이 그래픽 카드와 디스크와 키보드를 직접 다뤄야 한다. 장비가 바뀌면 프로그램을 고쳐야 하고, 두 프로그램이 같은 장비를 동시에 쓰려 하면 서로 부딪힌다.

Windows는 그 사이에 선다. 프로그램은 창을 열어달라거나 파일을 읽어달라고 요청만 하고, 실제 장비를 다루는 일은 Windows와 드라이버(장비마다 다른 다루는 법을 운영체제에 알려주는 프로그램)가 맡는다. 그래서 그래픽 카드를 바꿔도 게임을 다시 설치할 필요가 없다.

## ⚙️ 작동 원리

파일을 열 때 프로그램은 그것이 디스크의 몇 번째 자리에 있는지 알 필요가 없다. 경로만 주면 Windows가 찾아서 열어준다. 프린터도 마찬가지로 프로그램은 인쇄해달라고만 하고, 그 기종을 아는 것은 드라이버 쪽이다.

사람이 Windows 를 직접 만지는 자리는 셋이다.

- **탐색기** — 파일과 폴더를 눈으로 보고 옮긴다.
- **작업 관리자** — 지금 도는 프로세스와 자원 사용량을 본다.
- **CMD 와 PowerShell** — 그 두 가지를 글로 적어 시킨다.

화면으로 하는 일은 대부분 명령줄로도 할 수 있다. 어느 쪽으로 시키든 파일을 실제로 찾고 프로세스를 만드는 것은 Windows 이고, 사람은 시키는 방식만 고른 것이기 때문이다.

버전은 데스크톱용인 Windows 10과 Windows 11이 있고, 서버용 Windows Server가 그 옆에 따로 있다. 같은 이름을 쓰지만 쓰는 자리가 다른 갈래다.

## 📊 비교: Windows vs Linux

| | Windows | Linux |
|---|---|---|
| 값 | 유료 | 대개 무료 |
| 주로 쓰는 자리 | 데스크톱, 게임 | 서버 |
| 다루는 방식 | 화면 중심 | 명령줄 중심 |
| 프로그램 | 데스크톱용이 많다 | 서버용이 많다 |

## 💡 실제 사례

- **사무실 PC** — 문서와 메일 프로그램이 Windows를 먼저 지원하는 경우가 많아 기본 선택이 된다.
- **PC 게임** — 게임 대부분이 Windows에서 돌아가도록 만들어져 나온다.
- **한 회사 안의 두 갈래** — 사무용 PC는 Windows로 두고 서비스를 돌리는 서버는 Linux로 두는 구성이 흔하다.

## 🚫 흔한 오해

- **Windows는 프로그램의 한 종류다** — 프로그램을 돌리는 바탕이다. 브라우저나 오피스는 그 위에서 도는 것이고 층이 다르다.
- **데스크톱에서 제일 많이 쓰이니 서버에도 제일 낫다** — 쓰는 자리가 다르다. 서버 쪽에서는 Linux가 더 많이 선택된다.
- **Windows Server는 Windows 11 다음 버전이다** — 버전 순서가 아니라 용도가 다른 갈래다. 데스크톱용은 10과 11이고 서버용은 따로 나온다.

## 📝 정리

Windows는 프로그램과 하드웨어 사이에 서서 창과 파일과 장치를 내주는 운영체제다. 프로그램이 장비를 직접 다루지 않아도 되게 만들어서 하드웨어가 바뀌어도 프로그램은 그대로 돈다. 데스크톱에서 가장 많이 쓰이고 서버용은 갈래가 따로 있다.
