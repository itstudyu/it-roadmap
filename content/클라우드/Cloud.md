# Cloud (클라우드)

## 📝 정의
Cloud(클라우드)는 **인터넷을 통해 컴퓨팅 자원을 제공하는 서비스**입니다. 서버, 스토리지, 데이터베이스 등을 직접 구매하지 않고 필요할 때 사용합니다.

### 핵심 개념
- 온디맨드: 필요할 때 즉시 사용
- 종량제: 사용한 만큼만 비용
- 확장성: 자유롭게 증설/축소

## 💡 클라우드 서비스 모델

**IaaS (Infrastructure as a Service)**:
```
가상 서버, 스토리지, 네트워크 제공
예: AWS EC2, Azure VM
→ 서버를 직접 관리
```

**PaaS (Platform as a Service)**:
```
애플리케이션 실행 플랫폼 제공
예: Heroku, Google App Engine
→ 코드만 배포
```

**SaaS (Software as a Service)**:
```
완성된 소프트웨어 제공
예: Gmail, Dropbox, Notion
→ 바로 사용
```

## 🎯 주요 클라우드 제공자

**AWS (Amazon Web Services)**:
- 가장 큰 시장 점유율
- 200개 이상의 서비스
- Lambda, EC2, S3, RDS

**Azure (Microsoft)**:
- 엔터프라이즈 시장 강세
- Windows 통합 우수
- Azure Functions, VM, Blob Storage

**GCP (Google Cloud Platform)**:
- 빅데이터, AI/ML 강점
- Kubernetes 원조
- Cloud Functions, Compute Engine

## 📊 클라우드 vs 온프레미스

| 특성 | 클라우드 | 온프레미스 |
|------|---------|-----------|
| 초기 비용 | 낮음 | 높음 (서버 구매) |
| 운영 비용 | 사용량 기반 | 고정 (전기, 인건비) |
| 확장성 | 즉시 | 서버 구매 필요 |
| 관리 | 제공자가 | 직접 |
