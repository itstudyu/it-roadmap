# Managed Service (관리형 서비스)

## 📝 정의

관리형 서비스는 **운영 일감을 제공자가 대신 맡는 서비스**다.

AWS는 RDS를 "관리형 데이터베이스 서비스. 대부분의 관리 작업을 자기가 책임진다" 고 적으면서 백업·소프트웨어 패치·장애 감지·복구를 자기 몫으로 나열한다. Azure SQL Database 문서도 업그레이드·패치·백업·모니터링 같은 관리 기능 대부분을 사용자 개입 없이 처리한다고 적는다.

### 이름
Managed :: 대신 돌봐 주는
Service :: 빌려 쓰는 것
= 붙여 읽으면 "대신 돌봐 주는 빌림". 무엇을 빌리느냐가 아니라 누가 돌보느냐가 이름이다

### 비유
세탁소. 세탁기를 사서 고쳐 쓰는 대신 옷만 맡기고 찾아오지만, 세제와 온도는 내가 못 고른다.

### 예
새벽마다 돌리던 백업 스크립트가, 관리형으로 옮기고 나니 그 스크립트째로 없어지는 그 순간이다.

## 🖼️ 그림으로 보기

```도해
대조: 같은 데이터베이스를 직접 굴리면 무엇이 달라지나
직접 운영 |=| 관리형
패치·백업 :: 내가 새벽에 한다 || 제공자가 한다
장애 복구 :: 내가 깨어나야 한다 || 자동으로 넘어간다
손댈 폭 :: 무엇이든 고친다 || 열어준 것만 고친다
= 운영 일감을 넘기는 대신 손댈 수 있는 폭을 내주는 맞바꿈이다
```

## ⚠️ 해결하는 문제

```도해
대조: 운영 일감을 아무도 안 맡으면 어떻게 되나
아무도 안 맡으면 || 제공자가 맡으면
패치 :: 미뤄지다 뚫린다 || 정해진 창에 돈다
백업 :: 있는 줄 알았다 || 자동으로 쌓인다
사람 :: 새벽 당번이 는다 || 당번이 필요 없다
= 운영은 없앨 수 있는 일이 아니라, 파는 쪽에 맡길 수 있는 일이다
```

데이터베이스 하나를 직접 굴리면 붙어 오는 일이 길다. 설치, 운영체제 패치, 소프트웨어 패치, 백업, 복구 연습, 대기 장비. AWS 문서는 가상 머신 위에서 직접 굴릴 때의 약점을 "사용자 실수에 더 노출된다" 로 적는다 — 손으로 갱신하다가 서비스를 멈추고, 무엇이 바뀌었는지 찾느라 몇 시간을 쓰는 쪽이다.

관리형은 그 목록을 통째로 파는 쪽에 넘긴다. 대신 넘긴 만큼 손댈 수 있는 폭이 줄어든다. 이 맞바꿈을 알고 고르는 것이 이 단어를 아는 것이다.

## 💡 실제 사례

- **데이터베이스를 고를 때** — 백업·패치·장애 복구를 내가 할지 제공자에게 맡길지가 첫 갈림길이다.
- **가상 머신에서 갈아탈 때** — 옮기기만 해도 운영체제와 소프트웨어 패치가 통째로 제공자 칸으로 넘어간다.
- **느린 질의를 잡을 때** — 관리형이라도 질의는 내가 고친다. 성능 도구로 문제 질의를 찾는 일이 사용자 몫이다.

## 🚫 흔한 오해

- **관리형을 쓰면 운영할 게 없다** — AWS 문서는 질의 튜닝을 사용자가 소유하는 일로 못 박는다. 느린 질의는 관리형이 고쳐 주지 않는다.
- **관리형이면 언제나 그게 정답이다** — 손댈 폭을 내주는 맞바꿈이다. Azure 문서는 백업이 자동으로 관리되어 아무도 직접 접근할 수 없다고 적는다.
- **관리형이니 내 책임도 없어진다** — 책임 공유 모델은 그대로다. 데이터·계정·권한은 어느 형태에서도 사용자 칸에 남는다.

## 🚨 주의사항

- **성능은 여전히 내 일이다.** AWS 문서는 질의 성능이 설계·데이터 크기·질의 패턴에 좌우된다며 감시와 튜닝을 사용자가 소유한다고 적는다.
- **패치 시각을 골라 둔다.** Azure 문서는 유지 관리 창을 예측 가능한 일정으로 잡을 수 있게 하고, 앱에 재시도 로직이 있으면 대개 티가 안 난다고 적는다.
- **못 하는 일이 생긴다.** 백업 파일에 직접 손대야 하거나 밑바닥을 만져야 하는 요구가 있으면 관리형이 답이 아니다.

## 📝 정리

**"운영 일감을 파는 쪽에 넘긴 빌림"** 이라고 읽으면 된다. 패치·백업·장애 복구가 제공자 칸으로 넘어가고, 그 대신 손댈 수 있는 폭과 밑바닥 접근을 내준다. 넘어가지 않는 것은 언제나 같다 — 내 데이터, 내 계정, 그리고 내가 쓴 질의의 성능이다.

## 🧒 열 살에게

빨래를 세탁소에 맡기면 알아서 빨고 개어 주지? 대신 세제를 뭘 쓸지, 몇 도로 빨지는 네가 못 골라. 편해지는 만큼 네 마음대로 할 수 있는 게 줄어드는 거야.

## ❓ 이해했는지

- 손댈 수 있는 폭을 내주고 대신 얻는 것은 무엇인가 → 그림
