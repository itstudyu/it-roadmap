# Egress Cost (아웃바운드 요금)

## 📝 정의

Egress Cost는 **밖으로 나가는 데이터에 붙는 요금**이다.

저장한 양과 켜 둔 시간은 자원 목록에 그대로 보이지만, 나간 양은 목록에 없다. 그래서 이 항목은 설계할 때가 아니라 청구서가 온 뒤에 발견되는 일이 잦다.

### 이름
Egress :: 밖으로 나감
Cost :: 무는 값
= 붙여 읽으면 "나가는 값". 계산기가 들어오는 문이 아니라 나가는 문에 달려 있다

### 비유
받을 때는 돈을 안 내지만 부칠 때마다 무게만큼 값을 무는 택배 요금이다.

### 예
사진을 올릴 때는 아무 말이 없다가, 그 사진이 수만 번 내려받아진 달에 청구서가 튀는 그 자리다.

## 🖼️ 그림으로 보기

```도해
대조: 같은 1기가라도 들어올 때와 나갈 때는 무엇이 다른가
들어올 때 |=| 나갈 때
요금 :: 대체로 없다 || 용량만큼 붙는다
설계 영향 :: 거의 없다 || 구조를 바꾼다
줄이는 법 :: 딱히 없다 || 덜 내보낸다
= 계산기는 들어오는 문이 아니라 나가는 문에 달려 있다
```

## ⚠️ 해결하는 문제

```도해
대조: 나가는 값을 세지 않으면 무엇이 어긋나나
안 세면 || 세어 두면
청구 예측 :: 달마다 놀란다 || 미리 계산된다
자원 배치 :: 아무 데나 둔다 || 가까이 붙인다
인기가 늘면 :: 손해가 커진다 || 값을 미리 안다
= 나가는 쪽에만 값이 붙는다는 걸 알면 설계가 달라진다
```

저장 값과 계산 값은 자원을 만드는 순간 눈에 보인다. 나가는 값은 쓰는 사람이 늘어야 늘고, 늘어난 뒤에 알게 된다. 잘 만든 서비스일수록 이 항목이 커지는 것이 이 요금의 얄궂은 점이다.

그래서 "이 데이터가 어디를 건너 나가나" 를 먼저 그려 둔다. 데이터를 계산 쪽으로 끌어오는 대신 계산을 데이터 쪽으로 보내는 선택, 자주 나가는 것을 이용자 가까이 미리 놓아 두는 선택이 전부 여기서 나온다.

## ⚙️ 작동 원리

값이 붙는 자리는 인터넷 출구만이 아니다. Azure 문서는 리전을 벗어나는 데이터에는 전송 요금이나 대역폭 요금이 붙는다고 적는다. 가상 망끼리 이어 붙인 구간도 마찬가지다 — Azure 는 피어링 연결을 지나는 트래픽에 들어오는 쪽과 나가는 쪽 모두 요금이 붙는다고 적는다. 클라우드 안에서만 오간다고 공짜가 아니다.

줄이는 방법의 뼈대는 하나다. **같은 것을 두 번 내보내지 않는 것.** CloudFront 문서는 가장자리에서 이용자에게 나가는 양에 값을 매기고, AWS 원본에서 CloudFront 로 들어가는 구간은 값을 매기지 않는다고 적는다. 파일이 가장자리 캐시에 남아 있는 동안은 원본까지 가지 않으므로, 원본에서 나가는 몫이 줄어든다.

누가 낼지도 고를 수 있다. S3 는 원래 버킷 주인이 저장 값과 전송 값을 다 물지만, Requester Pays 를 켜면 내려받는 쪽이 요청 값과 내려받기 값을 문다. Google Cloud Storage 도 요청에 청구 프로젝트를 달면 요청자 쪽 프로젝트로 청구가 넘어간다. 공개 데이터셋을 여는 쪽이 쓰는 방법이다.

## 💡 실제 사례

- **앞에 가장자리 캐시를 세운다** — 자주 나가는 파일을 가장자리가 대신 내보내면 원본에서 나가는 양이 줄어든다. AWS 원본에서 CloudFront 로 들어가는 구간에는 값을 안 매긴다.
- **계산을 데이터 옆으로 옮긴다** — 큰 저장소를 다른 리전으로 통째로 끌어오는 대신, 그 리전에서 계산하고 결과만 가져온다.
- **요청자가 내게 한다** — 공개 데이터셋은 버킷 주인 대신 내려받는 쪽이 전송 값을 물도록 설정할 수 있다.

## 🚫 흔한 오해

- **인터넷으로 안 나가면 공짜다** — 리전을 벗어나면 붙고, 가상 망을 이어 붙인 구간을 지나는 것만으로도 양쪽에 붙는다.
- **올리는 데이터에도 같은 값이 붙는다** — 이 요금은 나가는 방향에 매긴다. 청구서를 키우는 것은 넣은 양이 아니라 내보낸 양이다.
- **가장자리 캐시만 붙이면 전송비가 사라진다** — 가장자리에서 이용자에게 나가는 양에는 여전히 값이 붙는다. 원본에서 나가는 몫이 줄어들 뿐이다.

## 📝 정리

**"나가는 쪽에만 달린 계산기"** 라고 읽으면 된다. 리전을 벗어나거나 가상 망을 건너기만 해도 붙으므로, 인터넷으로 안 나간다고 공짜가 아니다. 줄이는 길은 덜 내보내는 것 하나뿐이라 캐시를 앞에 세우거나 계산을 데이터 옆으로 옮긴다.

## 🧒 열 살에게

택배를 받을 때는 네가 돈을 안 내지? 그런데 네가 상자를 부칠 때는 무게만큼 돈을 내야 해. 밖으로 내보내는 쪽에만 값이 붙는다고 생각하면 돼.

## ❓ 이해했는지

- 인터넷으로 한 번도 안 나갔는데 전송 요금이 붙는 일은 왜 생기나 → 흔한 오해
- 같은 파일을 이용자 가까이 미리 놓아 두면 무엇이 줄어드나 → 작동 원리
- 저장한 양은 그대로인데 이번 달 청구서만 커지는 이유는 무엇인가 → 그림
