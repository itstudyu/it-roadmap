# OS (Operating System)

## 📝 정의
OS(운영체제)는 **하드웨어와 소프트웨어를 관리하는 시스템 소프트웨어**입니다.

### 핵심 역할
- 하드웨어 관리 (CPU, 메모리, 디스크)
- 프로그램 실행
- 파일 시스템
- 사용자 인터페이스

## 💡 주요 OS

**Desktop**:
- Windows
- macOS
- Linux

**Mobile**:
- Android
- iOS

**Server**:
- Linux (Ubuntu, CentOS)
- Windows Server

## 🎯 OS 기능

```
프로세스 관리
→ 여러 프로그램 동시 실행

메모리 관리
→ RAM 할당/해제

파일 시스템
→ 파일 저장/읽기

입출력 관리
→ 키보드, 마우스, 프린터
```
