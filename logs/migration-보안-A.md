# 이행 기록 — 보안-A (17편)

대상: API Key · API Token · Audit Log · Bastion Host · CA · CSRF · Certificate ·
Cookie · DAC · DMZ · Encryption · IAM · IPSec VPN · JWT · MFA · OAuth · PII

검사 결과: **17편 실패 0건 · 경고 0건** (`--strict` 로도 0건)

---

## 1. 확인 질문에 "→ 답이 있는 자리" 달기 (17편)

17편 모두 화살표가 없었다. 전편에 달았고, **화살표 뒤의 섹션을 실제로 열어
답이 거기 있는지 하나씩 확인했다.** 질문 셋이 서로 다른 섹션을 겨누게 맞췄고,
끝의 물음표는 본보기 두 편(DNS·HTTP)과 같게 뗐다.

| 노트 | 겨눈 자리 셋 |
|---|---|
| API Key | 작동 원리 · 흔한 오해 · 주의사항 |
| API Token | 작동 원리 · 흔한 오해 · 주의사항 |
| Audit Log | 흔한 오해 · 작동 원리 · 주의사항 |
| Bastion Host | 흔한 오해 · 해결하는 문제 · 작동 원리 |
| CA | 흔한 오해 · 비교 · 작동 원리 |
| CSRF | 그림 · 흔한 오해 · 작동 원리 |
| Certificate | 작동 원리 · 흔한 오해 · 주의사항 |
| Cookie | 그림 · 흔한 오해 · 작동 원리 |
| DAC | 해결하는 문제 · 흔한 오해 · 작동 원리 |
| DMZ | 해결하는 문제 · 그림 · 흔한 오해 |
| Encryption | 흔한 오해 · 작동 원리 · 해결하는 문제 |
| IAM | 그림 · 실제 사례 · 흔한 오해 |
| IPSec VPN | 흔한 오해 · 작동 원리 · 비교 |
| JWT | 작동 원리 · 해결하는 문제 · 흔한 오해 |
| MFA | 그림 · 흔한 오해 · 작동 원리 |
| OAuth | 그림 · 작동 원리 · 흔한 오해 |
| PII | 그림 · 흔한 오해 · 작동 원리 |

### 답이 노트에 없어서 바꾼 것 (1건)

- **Cookie** — "HttpOnly 를 걸면 어떤 공격이 막히나"
  답으로 기대하는 이름(XSS)이 **본문 어디에도 없다.** 🔗 관련 용어의
  `[[XSS]] — 스크립트로 쿠키를 훔쳐가는 공격. HttpOnly 가 막는다` 한 줄이 전부인데
  관련 용어는 답이 있을 수 있는 자리가 아니다. 억지로 작동 원리를 짚으면
  "자바스크립트가 못 읽는다" 까지만 나오고 질문이 물은 공격 이름은 안 나온다.
  **"서버는 요청 사이를 기억하지 않는데 다음 페이지에서 나를 알아보는 건 무엇 덕분인가 → 그림"**
  으로 바꿨다. 그림의 `= 서버가 기억하는 게 아니라 브라우저가 매번 들고 오는 것이다` 가 답이다.

### 답은 있는데 셋이 한 자리로 몰려서 바꾼 것 (5건)

같은 섹션을 두 번 짚으면 확인이 안 된다. 아래는 답이 노트 안에 있긴 하지만
다른 질문이 이미 그 자리를 겨누고 있어 바꾼 것들이다.

- **API Key** — "조회 전용 Key를 따로 만드는 이유는" (답이 작동 원리인데 1번이 그 자리)
  → **"실수로 Key를 저장소에 올렸다. 그 커밋을 지우면 되는가 → 주의사항"**.
  주의사항의 "지운 커밋에도 남아 있어서, 삭제가 아니라 재발급이 답이다" 가 답이다.
- **CA** — "주소창에 자물쇠가 떠 있는데도 사기 사이트일 수 있는 이유는" (흔한 오해, 1번과 겹침)
  → **"자물쇠만으로는 그 회사가 실재하는지 알 수 없다. 조직까지 확인하는 등급은 무엇인가 → 비교"**.
  DV / OV / EV 표가 그대로 답이라 접혀 있던 비교 칸이 처음으로 쓰인다.
- **CSRF** — "공격자가 훔쳐 가는 것이 정보가 아니라면 무엇을 노리는 것인가" (흔한 오해, 2번과 겹침)
  → **"공격자가 만든 페이지가 CSRF 토큰 값을 읽어내지 못하는 이유는 → 작동 원리"**.
  "다른 출처의 페이지가 우리 서버의 응답 내용을 읽는 걸 브라우저가 막기 때문이다" 가 답이다.
- **DAC** — "퇴사자의 접근을 한 번에 끊을 수 있는 이유가 무엇인가" (해결하는 문제, 1번과 겹침)
  → **"같은 테이블을 조회해도 사람에 따라 결과가 다르게 나올 수 있는 이유는 → 작동 원리"**.
  "판단 기준은 계정 하나가 아니라 역할과 대상의 조합이다" 가 답이다.
- **IPSec VPN** — "본사와 지점을 잇는 방식은 개인이 접속하는 방식과 무엇이 다른가" (작동 원리, 2번과 겹침)
  → **"프로그램을 깔지 않고 브라우저만으로 붙게 하려면 어떤 방식을 골라야 하나 → 비교"**.
  IPSec VPN / SSL·TLS VPN 표의 "설치" 줄이 답이다.

DMZ 3번은 자리는 맞았지만 문구가 "DMZ 안의 서버가 **내부망에서** 가장 위험한" 이라
DMZ 를 내부망 안으로 읽히게 해서 "전체 구조에서" 로 고쳤다.

## 2. 흐름의 `<` 감사 — 8편에서 떼고 2편은 고쳐 남겼다

물음은 하나였다. **누가 누구에게 답을 주는가.**

**뗀 것 (8편)** — 마지막 마디가 응답이 아니라 그냥 마지막 일이었다.

| 노트 | 뗀 줄 | 왜 응답이 아닌가 |
|---|---|---|
| Audit Log | `조사자 :: 계정과 시간으로 걸러 그 줄을 찾는다` | 사고 뒤의 별개 행동이다. 사용자에게 돌아가는 것이 없다 |
| Bastion Host | `배스천 :: 세션이 끝날 때까지 기록을 남긴다` | 기록은 남기는 일이지 돌려주는 일이 아니다 |
| CA | `브라우저 :: 믿는 기관 목록에 있으면 자물쇠를 띄운다` | 첫 마디가 관리자다. 관리자에게 돌아가는 것이 없다 |
| CSRF | `은행 서버 :: 로그인한 본인의 요청으로 보고 송금한다` | 요청이 도착한 끝점이다. 이 그림의 요점은 도착이지 응답이 아니다 |
| Certificate | `브라우저 :: 다 맞으면 자물쇠를 띄우고 암호화를 시작한다` | 앞 세 마디도 브라우저다. 브라우저는 어디로도 떠난 적이 없다 |
| DMZ | `DB 서버 :: 내부망에 있고 웹 서버 요청만 받는다` | "어디까지 들어오나" 를 묻는 그림의 가장 깊은 지점이다 |
| Encryption | `원문 :: 원래 내용으로 돌아온다` | 상태가 제자리로 온 것이지 누가 답을 준 것이 아니다 |
| OAuth | `앱 :: 토큰으로 프로필만 읽는다` | 진짜 되돌아오는 자리는 "구글 :: 일회용 코드를 앱에 돌려준다" 인데, 그 뒤에 다시 나가는 마디가 두 개 더 있어 `<` 를 옮기면 난간이 거짓말을 한다 |

**고쳐 남긴 것 (2편)** — 응답은 실제로 돌아오는데 줄이 그 말을 안 하고 있었다.

- **API Key** `통과하면 실행하고, 쓴 만큼 기록한다` → `통과하면 실행해 돌려주고 쓴 만큼 센다`
- **DAC** `누가 무엇을 조회했는지 기록에 남긴다` → `결과를 돌려주면서 누가 무엇을 봤는지 남긴다`
  (DAC 는 가운데 서 있어서 결과가 이쪽으로 되돌아 나간다. 그 말을 넣었다)

**그대로 둔 것 (6편)** — API Token(401 로 거절) · Cookie(로그인된 화면을 받는다) ·
IAM(맞으면 파일, 아니면 403) · IPSec VPN(사내에서 온 요청처럼 응답한다) ·
JWT(사용자에게 통과) · MFA(로그인 거부). 전부 답이 요청한 쪽으로 돌아간다.

`@` 는 한 편도 넣지 않았다. 이 17편에 순환하는 개념이 없다.

## 3. 대조 ✕ 칸 자기검사 — 1편

- **JWT** ⚠️ 해결하는 문제의 `세션 방식 || JWT 방식` 에서 왼쪽 칸에
  `즉시 로그아웃 :: 지우면 끝` 이 있었다. 세션 쪽의 **명백한 장점**이다.
  이 그림은 접히지 않는 자리 바로 아래에서 2초 만에 "세션은 나쁜 것" 이라는 그림을 심는데,
  같은 노트의 🚫 흔한 오해 셋째 줄이 지우려는 오해가 정확히 그것이다.
  칸 이름 줄만 **`세션 방식 |=| JWT 방식`** 으로 바꿨다. `= 저장소를 없애는 대신
  강제 로그아웃을 잃는 거래다` 는 원래부터 중립이라 그대로 뒀다.

나머지 대조는 전부 "있고 없고" 라 `||` 가 맞다(Key 없이 · 비밀번호로 · 로그 없이 ·
배스천 없이 · 보증 없이 · 막지 않으면 · 인증서 없이 · 쿠키 없이 · 직접 접속 ·
DMZ 없이 · 평문 저장 · IAM 없이 · VPN 없이 · 비밀번호만 · 비밀번호 공유 · 보호 없이).
왼쪽에 장점으로 읽힐 줄이 없는지 한 줄씩 봤다.

## 4. 그림 자리 감사 — 1편

- **PII** 의 대표 그림이 `흐름: 사용자가 적어 넣은 주민번호는 어디까지 가나`
  (입력 → 감지 → 차단 → 마스킹 → 저장 → 조회) 였다. 이건 PII 를 **다루는 절차**지
  PII 가 **무엇인지**가 아니다. 그림만 보고는 정의 첫 문장("특정 개인을 알아낼 수 있는 정보")
  을 복원할 수 없고, 이 노트가 가장 공들여 말하는 **조합**이 그림에 없다.
  📊 비교의 직접·간접 식별자 표를 대조 도해로 올렸다.

  ```
  대조: 어떤 값이 개인을 알아내게 만드나
  직접 식별자 |=| 간접 식별자
  ...
  = 항목 하나가 아니라 조합이 사람을 가리키는 순간부터 PII 다
  ```

  둘 다 PII 라 우열이 없어서 `|=|` 를 썼다. 밀려난 흐름은 지웠는데,
  그 여섯 마디가 말하던 것(수집·전송·저장·접근·로그)은 ⚙️ 작동 원리의 층이
  이미 같은 순서로 담고 있어 사라진 사실이 없다.

다른 16편은 그림만 보고 정의 첫 문장이 복원된다. 특히 API Key(식별·권한·사용량이
한꺼번에 붙는다) · CA(서버가 아니라 서명한 기관을 믿는다) · JWT(토큰이 스스로를 증명한다)
는 그림의 `=` 줄이 정의를 거의 그대로 되뇐다.

## 5. 층 반증 테스트 — 5편에서 걸렸다

**이웃 둘을 맞바꿔도 그림이 안 틀리면 층이 아니다.**

- **Cookie** `층: 쿠키에 붙는 옵션은 무엇을 막나` (Secure / HttpOnly / SameSite / Max-Age)
  — 넷은 나란한 옵션이라 순서에 뜻이 없다. Secure 와 HttpOnly 를 맞바꿔도 아무것도 안 틀린다.
  **대조로 바꿨다** — `옵션 없이 || 옵션을 붙이면`. "있고 없고" 라 `||` 가 맞다.
  대조에 안 들어간 Max-Age 는 본문 한 줄로 옮겼다(그림에만 있는 사실을 만들지 않으려고).
- **Encryption** `층: 무엇을 지키려느냐에 따라 어떤 방식을 쓰나` (대칭키 / 비대칭키 / 해시)
  — `= 셋 중 ...` 으로 시작하는 집합어가 그대로 신호였다. 대칭키와 비대칭키를 맞바꿔도 멀쩡하다.
  이 노트가 실제로 가르는 축은 **되돌릴 수 있느냐**라, `암호화 |=| 해시` 대조로 다시 세웠다.
  밀려난 AES · RSA · SHA-256 은 바로 아래 본문 문단에 넣었다.
- **IAM** `층: 권한은 어디에 붙어 있나` (사용자 / 그룹 / 역할 / 정책)
  — 그룹과 역할은 형제라 맞바꿔도 안 틀린다. 그냥 나열이었다.
  `층: 권한은 실제로 어디에 적혀 있나`(사용자 → 그룹·역할 → 정책)로 **축을 다시 세웠다.**
  이제 정책을 위로 올리면 그림이 틀린다.
- **DMZ** `층: 어느 방향까지 열어두나` — 네 방향의 나열이라 3·4번을 맞바꿔도 안 틀렸다.
  `층: 어느 방향이 얼마나 열려 있나` 로 바꾸고 **열린 정도 순서**로 다시 세웠다
  (내부망→DMZ · 인터넷→DMZ · DMZ→내부망 · 인터넷→내부망). 이제 자리를 바꾸면 기울기가 깨진다.
- **MFA** `층: 인증 요소는 어떤 종류로 나뉘나` — 세 칸이 나란해서 순서가 없었다.
  본문이 이미 "말해줄 수 있는 것 / 뺏어야 넘어간다 / 몸에 붙어 있다" 라는 기울기를 갖고 있어서
  `층: 인증 요소는 뺏기가 얼마나 어려운가` 로 축을 드러냈다. `=` 줄에 "아래로 갈수록 뺏기 어렵다" 를
  더하고 원래의 "서로 다른 칸에서 둘을 골라야 MFA 다" 는 남겼다.

**그대로 둔 층 (6편)** — CA(루트→중간→서버 인증서) · Certificate(같은 사슬) ·
DAC(인증→인가→감사) · IPSec VPN(응용→전송→인터넷→링크) · JWT(헤더→페이로드→서명) ·
PII(수집→전송→저장→접근→로그). 전부 이웃을 맞바꾸면 그림이 틀린다.

## 6. 선행 용어 — 2편

- **API Key** / **API Token** 의 ⚙️ 작동 원리가 "해시" 를 설명 없이 쓰고 있었다.
  두 노트 다 관련 용어에 해시가 없어서 **반 구절로 풀었다** —
  `해시(되돌릴 수 없는 지문 값)로 바꿔 저장한다`,
  `해시(되돌릴 수 없는 지문 값으로 바꾸는 것)해서 넣어두고`.

Encryption · PII 는 [[Hash]] 가 이미 관련 용어에 있어 그대로 뒀다.
도해 마디 이름 중에 노트 밖에서 배워야 하는 말은 없었다.

## 안 한 것

- `@` 를 넣지 않았다. 17편에 한 바퀴 도는 개념이 없다. 있지도 않은 순환을 만들지 않았다.
- 제목 · 파일명 · 폴더를 건드리지 않았다.
- 없는 사실을 새로 쓰지 않았다. 채운 자리는 전부 같은 노트의 다른 섹션에 이미 있던 말이다.
